# 分层威胁评估试验与回退记录（2026-09-21）

## 结论
候选曾接入默认审计原生战斗阶段及真实 Worker 路径进行实测，但**没有证实百舰整体性能获得稳定改善，更没有解决百舰卡顿**。**最终决定：已撤回本轮生产代码改动；当前默认路径不启用本轮分层预测。此前已有的多船优化不受影响。**首轮较好的数字不能单独作为结论。当前实现是原版分层节拍启发的 Web 适配，不是完整 BasicShipAI/D 移植。

原版证据、编码前边界及实现说明见 [来源审计](threat-cadence-source-audit-2026-09-21.md)。没有改运动/碰撞频率、炮塔跟踪、实体数量、渲染质量。

## 对照方法
编码前冻结当前源码图；每组仅替换本轮修改文件，公共资源、初始种子3534、舰队编成一致。候选源码图272模块在回退前与工作区核对，无漂移。默认 CombatSession、真实4 Worker、无头 Chromium/D3D11；不占用桌面或输入。
- 固定步：100艘攻势，240步，前60步预热，后180步统计。交替同渲染进程两个 iframe；simulationVisual 包含模拟及视觉更新；total 另含 render/gl.finish。**这些 ms 不是实际 FPS。**
- 真实rAF：同100舰场景，60步预热后每次15秒墙钟；默认 FixedTimestepScheduler，分别记录FPS和TPS。无gl.finish，不含React HUD/音频，不代表玩家所有硬件/场景。ABBA/BAAB顺序复测。
- 本轮改变的是决策采样语义，不能要求旧/新战斗全状态相同；要求相同 live world 的即时防御相同，以及新串行/新Worker的状态一致。

## 候选已验证（不代表保留到默认路径）
- 2931项断言：900组同世界完整参考比对，独立武器 horizon 不改变即时伤害、盾幅能、实际伤害、朝向；实际弹丸/光束保留完整 horizon。
- 新光束、致命弹丸、引导弹/解除武装/禁碰撞/寿命、突然近端武器、相位启动窗口、失效/重置与确定性错峰。900步固定场景只做39次全域武器重算（非游戏总工作量减少95.7%的声明）。
- 排散前强制live确认；系统同一步加幅能会扩大最终排散检查 horizon；未提供确认回调则拒绝排散。
- 未审计/已关闭 envelope、自定义 reader/系统/modifier、异常 horizon 回退完整评估。即使自定义 reader 返回相同标量，权限变化仍使旧提案失效。
- defense 全部状态通过既有标量codec；丢弃、重试、异常后回滚一致。Frame显式携带并验证分层权限，read-only owner不猜测权限。
- 最终候选源码100舰新串行/真实4 Worker运行240步，8次全状态检查一致（audited-parity.json）。前一候选还验证24舰和24艘奥德赛/典范混编；最终权限收紧后未重跑混编，不能混称最终版混编验收。
- 现有combat AI 24项、system movement intent 12项通过；tsconfig.app类型检查和改动范围oxlint通过。
- 回退前候选源码100舰默认Worker teardown：实际commit后在pending tick时dispose，提案被丢弃、权威tick不增加、Worker剩余0、GL错误0。
- 普通 /?view=combat 入口无头 smoke：tick31 ready、暂停不推进、护盾/战术图/清输入命令通过，无页面错误。
- 不宣称全仓所有测试通过；此前已知 projectile-lifecycle fixture 的 localMuzzles 问题不在本轮修复范围。
