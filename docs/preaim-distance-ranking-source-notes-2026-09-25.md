## 当前差异 / 有界候选
当前 preAim 对每个非友军先算完整欧氏距离，再做资格/射程/拦截判断。还没有找到一个有效预瞄点时，最近距离为 Infinity；此时大量最终无效的候选也执行除法和平方根。历史 CPU 采样显示 preAim 是重要子热点，但不是本轮新鲜性能结论。

新增调用私有距离排序器，保存本候选原时序读取的两个坐标差，不保存目标/舰船状态：
- 仍先读取 origin.distanceTo 方法，再读取 other.pos；原生方法内仍按原顺序读取 Math.hypot、x/y。
- 原生范数、无限排序上界、两分量绝对值不超过 MAX_VALUE/2：范数必定有限，所以可以先执行原有资格/拦截判断，仅成功时才用已捕获差值计算完全相同的范数。不能成功后重读位置。
- 有限排序上界：分量下界已足以证明原范数 >= 上界时可拒绝；其余继续同一精确范数。NaN/无穷/溢出/下溢必须保持旧比较结果。
- 自定义 distanceTo 或 Math.hypot 不延迟、不跳过，保留调用、receiver、返回值、异常及 getter 读取顺序。未注册的动态位置仍实时读取；若后续回调改变位置，用旧时刻差值正好对应旧路径先算出的距离。
- 每次 preAim 独占排序器；可重入调用不共享临时数据。指定目标优先、顺序、平局、RNG、射程、精度、频率、实体数量及友伤检查完全不变。
- 不启用旧 batch、不缓存跨武器/跨帧目标状态、不改变舰船逐步更新可见性。
