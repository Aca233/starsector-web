# 万有引力号 · 技能与武器一体化操作方案 v1

状态：玩法设计稿，未实装、未生图、未编译配装、未做平衡实测。2026-09-29。
本稿覆盖本次聊天前面的零散武器/技能提案，目标由“更多操作”收敛为“操作方便，但引力用途多、选择有后果”。
名称沿用用户“万有引力号”；原作身份与舰体美术尚未确定。本稿是Web玩法设计，不能当成《三体》原作能力考据。

## 1. 目标与边界

- 一句话定位：通过区域牵引改变敌舰阵型，通过引力武器利用这个阵型；全向爆斥用于解围，但会主动放弃正在维持的攻击场。
- 基础操作只用F、G和常规武器组/左键；右键护盾、移动、排散与暂停保持原习惯。F/G只是默认技能槽标签，遵循玩家自定义绑定。
- 不加第三技能键、长按/双击区分、战斗姿态切换、独立引力能量条或必记连招。
- 首版只有一个本舰投射引力井。限制的是同时维持的场，不是受影响敌舰数量。
- 武器离开技能也能正常使用；联动提供弹道/覆盖形态选择，不用“有标记就伤害翻倍”的纯数值套路。
- 不做真实黑洞、无条件穿盾、持续无敌反弹罩、自动夺取敌弹所有权、无限加速或无限硬控。
- 本轮只交方案，不改现有舰船、不用临时贴图上线新舰。

## 2. 默认操作

| 操作 | 始终一致的意义 | 反馈 |
| --- | --- | --- |
| F（技能槽1） | 就绪时在鼠标地面位置放井；有效维持期间再按F仅收回，不瞬移引力中心 | 投射范围、作用圆、预计影响对象；再次按键提示“收回” |
| G（技能槽2） | 以本舰为中心释放全向爆斥，永远不改为远程引力井爆炸 | 以本舰为中心的波前预告；提示“将终止引力井” |
| 组1＋左键 | 手动发射潮汐主炮；瞄准自身引力井时自动显示展开弹道预览 | 普通狭窄命中/抵达引力井后展开的差别在开火前可见 |
| 组2 | 弹弓副炮默认自动；玩家可按既有武器组机制接管 | 自动选择直射或可行的借井曲射 |
| 组3 | 近防自动工作，可按既有武器组机制关闭 | 正在偏转的威胁有短暂标识，不充满HUD |
| 右键、V | 原护盾与排散 | 不改变含义 |

先验证指令被接受，再扣能、取消旧场或生成新事件。G因幅能不足/禁用而失败时，不能先把F的场删掉。
不支持在维持期间免费拖拽整个引力井；避免“鼠标瞬移敌人”。重新部署必须收回并经历正常恢复。

## 3. F：区域引力井（万象天引式）

### 作用

在指定世界坐标短暂聚场，维持期间让作用区内多艘敌舰与敌方战机产生朝向中心的外力。
不修改玩家输入，不强制贴中心、不冻结转向，不直接伤害舰体。

- 小舰位移明显，但能通过提前横移/离开边缘逃脱。
- 大舰受整舰质量与推进抵抗影响，不会翻飞；仍应在撤退/站位上受到可测量的影响。
- 中心使用软化半径，靠自然惯性与碰撞分离形成松散目标群，不把舰船压到同一个像素。
- 场在激活点固定；舰体可继续移动、开盾、开副炮。超过维持距离则自然退场，不无限跨地图放井。
- 默认只对敌方舰船施加强制位移。友方舰体获得场形补偿，不强拉玩家队友；这是明确的玩法化敌我补偿，不是严格自然引力模拟。
- 相位中、已撤退、已停泊等不具有效实体碰撞的舰船不受力。模块舰按母体装配的质量/运动统一处理，不能逐模块分配整份控制力，也不能扯散附件。

### 弹体作用

- 敌方导弹和实体弹丸受到有限横向偏折，不删除、不重置寿命、不转换阵营。
- 友方普通炮弹默认不被无意改道；本舰带联动声明的引力弹弓弹丸可主动接入本舰的井。
- 光束不参与实体弹丸偏转；敌方护盾拦截引力弹丸的规则不改变。
- 舰船受力与弹体偏转分开预算。海量小子弹不能吃光拉舰功率，海量弹幕也不能被一口气无损清空。

### 消耗与退出

初始探针值：聚场0.6秒、最多维持4秒、退出后恢复12秒；激活3%最大幅能，维持每秒2%，使用硬幅能作为强控成本。数值仅供首轮调试。
主动收回、G成功激活、过载、排散、失去能力、死亡/撤退或超出维持距离均退场；不返还已付出的费用。不得留下独立永久场。

## 4. G：全向爆斥（神罗天征式）

始终以本舰为中心。短促聚场后，波前向外推进；每个有效对象在一次激活中最多获得一次径向冲量。

- 一次可推开多艘近身敌舰、冲散战机、偏转迎面弹幕；没有单目标限制。
- 按距离衰减，越近越有力；重舰位移较小。不能把任何体型都弹出屏幕。
- 推开不等于无敌：技能不关闭实体碰撞、不取消已命中的伤害，不拦光束，也不覆盖波前离开后的新来袭攻击。
- 不误伤/推走友舰。本舰仍可在波前推进期间遭到侧后方或远程火力攻击。
- 成功启动后终止本舰F井，不能同时聚拢敌舰又维持全向弹幕屏障。
- 已发射的本舰弹弓弹丸获得有限向外加速/脱离轨道，保持原伤害、原射程计程和原阵营。可以抢救一批来不及命中的弹丸，但不保证它们因此击中目标。
- 为方便操作，首版不提供方向扇区模式，也不把按住/点按G做成两种行为。

初始探针值：前摇0.25秒、波前推进0.45秒、恢复10秒、12%最大幅能硬幅能成本。两套技能各自恢复，但共享原有幅能风险；G必须取消F是核心取舍，不再叠加第二套隐藏共享CD。

## 5. 一套武器，三种职责

### 5.1 L固定「双极潮汐炮」：点杀或展开剪切

主炮是一对嵌入舰艏的引力投射器，形成短时差分引力作用；不是普通激光换名称。
正常射击为较窄的潮汐脉冲：护盾承压、装甲受损，并产生小幅有限的扭转冲量，不能每发都硬控。

**与F联动：**玩家瞄准自己的引力井，脉冲实际抵达井的有效区域后，利用井作为第二施力端，在井内展开一次短时范围剪切。

- 控制者只需要把鼠标瞄到井上，不另切模式，不自动劫持瞄准；打别处仍是普通主炮。
- 是单体威力换覆盖形态：一发有固定伤害/冲量总预算；多个目标按覆盖与命中顺序消耗预算，不给每个目标复制满额伤害。
- 先经过正常碰撞和护盾处理。若脉冲在抵达井前被护盾/实体完全耗尽，则不会凭空在盾后展开。
- 展开不消耗/重建引力井；仍是正常主炮装填与幅能成本，不强迫“放井后只能打一次”的固定连招。
- 井在脉冲到达前已关闭时，弹体按当前位置与方向继续普通生命周期，不凭空爆发，不把伤害转移到旧场位置。
- 持续装甲输出低于同档纯攻击主炮；收益来自聚拢后的覆盖和有限姿态扰动。

初始几何不冻结：射程必须能从真实舰艏炮口覆盖F投射区域；蓄能/装填以能够在一个4秒控场窗口内作一次明确开火决策为目标，不能靠几十发常驻扭转。

### 5.2 M可转「轨道弹弓炮」：自动借井曲射

通过发射阵列的短程引力梯度加速重质弹丸。无F时正常直射，保证技能空窗也能战斗。
当“借本舰引力井”确有可行拦截路径时，火控把弹丸沿井的侧缘送入弧线，再射向目标。

- 不需要玩家选择左弯/右弯；侧别由炮口、井和目标实际几何决定，预测路径在手动接管时可见。
- 可以改变入射角、利用盾弧空隙；不是自动命中背甲，也不能隔着实体转弯穿过去。
- 曲射是实际速度方向改变，渲染、碰撞、命中与射程计程共用路径。最大转弯率、加速与飞行总距离受限。
- 一发弹丸最多接入一次本舰井，不能靠多井重复绕圈充能。离井之后保留脱离时惯性，不无限追踪。
- G解除当前牵引并给在波前内的弹丸一次径向冲量，可形成撤退时的压制齐射；不额外增加伤害。
- 以持续压盾/迫使转向为主，装甲效率受限，和潮汐主炮形成分工。

### 5.3 S可转「偏轨阵列」：自动拨开来袭弹体

向低质量来袭实体施加短促侧向引力，使其错过预计碰撞点。

- 根据预计命中时间而非单纯距离选择威胁，按阵列能量/刷新周期顺序处理，不能每帧遍历所有弹体并全部拨走。
- 重型高速弹丸需要更高功率且可能偏转不足；光束无效；导弹出场后可能重新捕获目标。
- 偏转不改所有权/伤害标记、不回收弹药，不伪装成直接销毁。
- 默认配装保留少量常规近防补刀，避免“导弹绕了一圈又回来却没人能击毁”。S槽同档可换，不强制把全部小槽塞成引力阵列。

**首版删去坍缩锚雷与额外主动武器。**它们与F重复，而且增加弹药、布雷和施放管理；以后证明确有不同用途再加。

## 6. 玩家实际会用的三种简单打法

1. **攻阵：**F放在敌群侧后方 → 弹弓副炮自动压盾/借井曲射 → 主炮瞄井做覆盖，或瞄离井的单舰做点杀。
2. **救队友：**F拉偏追击群而不是追着单舰点名 → 自己靠近接应 → 必要时G把近身威胁推开，接受F结束的代价。
3. **脱离：**继续副炮压制 → G推开近敌并解开弹道束缚 → 普通移动撤出。若正在等主炮抵达井，提前G会失去展开机会；允许为保命牺牲这一发的联动。

不要求固定F→主炮→G：站位安全时保留F更有收益，被围时应果断G，单舰目标则可能完全不值得开F。

## 7. 平衡约束

- 强控输出以整舰惯性和本舰场总负载分配；不能“只选一艘”假装平衡，也不能因范围多出一架飞机让大舰受力忽然归零。
- 受力用平滑分配、近中心软化与外部速度/角速度改变量上限；所有对象保持原推进/盾/武器操作能力，不替换输入为强制定身。
- 多个同队引力舰作用同一对象时，按同一外力汇总阶段处理并封顶，不能更新顺序影响结果或叠成无限控制。
- 不用物理碰撞凭空结算额外撞击伤害。宿主未有相关规则时，聚拢的收益只是位置和武器覆盖。
- 光束、远程消耗、范围外侧击、高机动提前脱离、在F/G恢复期接近都是明确反制。
- 护盾为普通防御，不增加“引力盾”第三技能。船体持续火力/追击机动必须给控场预算让路；对照同部署成本纯火力舰，不得控制和输出都全面更强。
- 在同体型/同DP验证以前，不冻结部署点、HP、护盾效率或声称数值已平衡。

## 8. 槽位/配装草案（待舰体图与生产编译）

暂按重型控制巡洋舰排布：1L固定内置主炮、4M可转混合副炮位、6S能量近防位，共11处武器安装；0XL不是漏档，四档体系不要求每船都用齐。坐标/射界必须依据正式舰体标定后才能冻结。

- **控场默认：**1L潮汐炮＋4M轨道弹弓炮＋4S偏轨阵列＋2S常规近防。多目标布局与弹幕应对强，对光束/重装甲的持续火力弱。
- **直击分支：**1L潮汐炮＋2M轨道弹弓炮＋2M直接能量火力＋2S偏轨＋4S常规近防。空窗输出/击毁导弹能力更好，借井曲射与多弹偏转覆盖减少。

M混合槽只放同档动能/能量，S与L遵守同档换装；主炮若固定绑定，需在改装界面明确显示且纳入预算。基础舰体不烘入默认配装。OP、幅能预算、承座、炮口和合法性尚未通过编译，不能当可用配装交付。
不额外加舰载机或模块，直到舰体定位与结构有实际理由。

## 9. 已核实宿主入口与缺口

### 现有证据（只代表接口存在）

- `src/engine/runtime/SystemBindings.ts`：默认技能槽F/G/H，可重绑；保留移动/防御/武器组键。
- `src/engine/extensions/ship-systems/Loadout.ts`：舰体可带多个战术系统，右键防御独立。
- `src/engine/simulation/ShipSystem.ts`：已有IN/ACTIVE/OUT/COOLDOWN、指令边沿activationInput.point/origin/velocity/facing/target。
- `src/engine/extensions/ship-systems/Types.ts`：世界能访问ships/projectiles，onAdvance逐帧推进，advanceAI扩展；小行星接口只读，不冒称可直接拖动环境。
- `src/engine/extensions/weapon-effects/Types.ts`：存在命中、环境命中、逐武器推进入口；接口存在不等于引力弹体生命周期和成功出射事务已实现。
- `src/network/display/LanShipProjection.ts`、`NativeRecordRestore.generated.ts`：有既有状态投影/恢复边界；不会自动收录新增场状态。

### 必须新增/确认

1. 权威引力场状态、友军补偿规则、整舰/模块归属、外力汇总时序与封顶；固定模拟步长下结算，不直接在渲染里改速度。
2. F再次激活的主动收回语义；G接受后的原子式退F与单次波前对象去重。
3. 轨道弹丸有限修正/脱离/途中失场、射程按实际路径累计、弹道求解与碰撞一致。
4. 潮汐脉冲抵达井后才展开、同一发固定总预算、盾/环境耗尽、中断时无幽灵伤害。
5. 阵列威胁筛选与偏转预算，不用删除弹体替代拦截。
6. HUD预览/失败原因、系统及武器自动决策、单舰/双舰实例隔离。
7. Worker权威与画面状态编码、快照恢复/回滚支持边界、对象清理；不能靠WeakMap就声称联网支持。
8. 正式舰体/武器/启动维持退出视觉与资源闭包；先确定轮廓与安装，再用用户指定生图渠道制作，禁止占位图上线。

## 10. 验收与阶段

下一步是无占位的权威规则验证，不先堆彩图/大范围粒子：

- F同时影响多艘，随整舰负载平滑变化；一艘大舰仍有可测量影响；模块不分离。
- 导弹能被偏转而非删除，离场仍有原所有权与完整生命周期；光束/友舰按契约不受力。
- 主炮直击、真正抵达井后展开、途中被盾/环境耗尽、到达前失场四类行为完整。
- 弹弓直射/曲射可测量不同入射角，碰撞/实际行程/渲染匹配；不能重复借井或无限追踪。
- G能影响多艘并每对象只结算一次，失败不退F，成功退F后的在途弹体继续存在。
- 怠速/过载/排散/死亡/撤退/重启全部清理；不同FPS与主线程/专用Worker结果可对照。
- 三种打法分别测试，不以必须按固定连招为前提；至少涵盖小舰群、同DP混编、光束远程、重型主力、导弹饱和、双引力舰叠加。
- 平衡不仅看胜负：统计幅能支出、位移、目标失去输出的时长、拦截后重新来袭、主炮单体/多体实际总伤害、操作次数与失败原因。

当前P1/P2方案；身份/多图参考、舰体结构、正式素材、实现、自然实战、多人及独立包安装均未完成。
