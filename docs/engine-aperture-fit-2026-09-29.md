# 喷口贴合修整 · 2026-09-29

状态：原 APERTURE / 内腔补绘方案已撤销。五艘扩展舰已切回原版绘制与独立原始尾焰素材，并完成逐舰纹理包络标定。以下早期章节为历史试验，以文末“当前最终接入”及折锋任务书为准。

## 原版证据 → 当前问题 → 本轮选择

- 本机0.98a-RC8资源 `graphics/fx/engineglow32.png` / `engineflame32.png`；反编译 `combat/entities/G.java:248–375` 以喷口局部坐标、原版纹理与多截面叠加产生尾焰。原版 width 是整片纹理包络，不是可见发光口径；原版素材与默认渲染保持不动。
- 对 engineglow32 实测：32行中主要alpha只在12–23行，亮部偏向第17–18行。现有自制舰把图片喷口宽度填成包络width，叠层后形成“宽口细针”，纹理非居中还带横向视觉偏差。
- 实际查看折锋、休伯利安、女王两动力舱、烛渊及罗西南特正式舰体图。女王动力舱原锚点位于喷管内部，重新按每个椭圆出口标定；主干逻辑应急引擎没有真实出口，不额外画火。
- 设计页 `ShipStage.tsx` 原先用固定蓝色CSS径向渐变，忽略引擎风格，只画根舰不画动力模块，与实际推进表现脱节。原版桌面实机待用户许可，本轮不冒充原版实机核对。

## 视觉契约

舰体/动力模块 → 权威引擎推力和失效状态 → 当前插值姿态与真实喷口 → 模拟视觉时钟 → 原版纹理裁取有效横截面 → 外部喷流 → 舰体遮挡 → 仅已标定内腔的局部发光 → 停机淡退、毁舰不画。

Web自制舰显式声明 APERTURE：独立可见口径，不改变原width相关的动力/生命规则；口部保持贴合，强度变化主要表现为短喷流延展和流动亮度，而不是口部缩成针。HIDDEN仅隐藏逻辑引擎，不删除其权威动力。未声明的原版/外部舰、导弹与现有RCS仍走原生路径。

设计页共用同一GPU贴合绘制函数与口径/颜色；静态怠速预览不冒充加速，隐藏页面/离屏暂停并释放卸载资源。亚顿之矛继续既有场推进，不增加传统外喷。

## 首版记录：冷态内腔与出口连接（由下方复看修正替代）

- 折锋两个主喷口 `depth=8, inset=4`，两个辅口 `depth=2.4, inset=1.2`。这是按该舰正式图标定的值，不是所有舰默认值。

## 用户复看后的修正（2026-09-29，已接入并受控核对）

上一版内腔取 flame 根部拉伸为光块，外段高强度轮廓形成尖长火舌；冷态船图底边再把两段切断。坐标正确并不等于视觉成立。本次只对有明确开口档案的折锋改为穿过开口的连续原版流束，降低轮廓权重、缩短外段；不移动物理出口，不改其他舰的未标定表现。参考 G.java 的多层流束和低强度轮廓，而不是把 flame 轮廓当主要光源。验收仍使用同一受控生产渲染与真实设计页。


修正结果：
- 仅带 `mouth` 档案的出口切换为完整连续流束：起点位于实测内腔后缘，强光区经过出口，外段自然延续。原外段分支跳过这些口，避免重复叠加；不是在断口上再贴一块灯。当前只有折锋使用该档案，其它舰未改。
- 移除该路径里的截断 flame 根部、横向亮条和高不透明度尖火轮廓；复用原版 engineglow 多尺度六层流束，并按纹理实际有效横截面映射口径。外段长度为原 APERTURE 表现的0.64倍，不改变实际动力。
- 第一版连续流束仍出现细针，定向修正横截面/层宽；接着在整舰1.4倍视图和局部视图中核对，而非只在极近距离调亮。
- 战斗和设计页共享当前实现；两者均传入各自明确的视觉时钟。零推力不绘制，姿态使用实际喷口变换。
- 本次 TypeScript、三处改动代码 lint、折锋六状态及三设计页的既有定向场景通过。最新 flow-next 与 full 的实际像素hash不同，未把静态图片当动画证据。新增 `web_zhefeng-whole.png` 为受控满推整舰视图；不是自然交战截图。
- 最新满推/旋转/怠速及整舰图已目视检查；无页面错误。玩家审美仍未确认，不将本次修正称为最终美术定稿，原版实机/自然飞行链路等未验边界保持不变。

## 当前最终接入：真原版素材 + 按喷口标定（2026-09-29）

用户反馈“怎么这么细”后查明：公共 engineglow32 和 engineflame32 并非原版图，而是同名AI替换图。原版 engineglow32 的alpha覆盖32行，AI图只覆盖11–24行，旧文按后者测得的横截面不应被标作“原版”。因此仅还原绘制代码不足以恢复外观。

- 以新路径 `graphics/fx/native_ship_engines/` 保存本机安装中的engineglow32、engineflame32、hit_glow；与源文件SHA256相同，来源登记为原版保留资源，不伪称生成素材，也不覆盖其它工作的共享资源。
- NATIVE仅选择这组已核实素材和原版绘制；`envelopeWidth`是纹理包络适配，折锋48/12，休伯利安/烛渊原物理宽×1.55，女王×1.5，罗西南特46.5。长度仍为原规格；原动力/健康分摊不变。辉光不随包络放大。
- 怠速、满推、流动下一帧、转向、熄火和旧窄条资源对照均有真实WebGL提交；五舰实际设计页及亚顿无火焰路径通过。主线程/Worker各96项，画面无GL错误；实际查看了折锋整舰、休伯利安和女王舰尾。
- 设计页与战斗使用同一原版绘制入口。保留亚顿场推进及无出口逻辑引擎HIDDEN。
- 折锋同时接入用户指定的四根圆柱喷管；原U形候选未接入。所有验收都是受控Web环境，不冒充自然飞行和原版实机对照。
