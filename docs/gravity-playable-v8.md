# 万有引力号 · 实验引力战列舰 v8

2026-09-30，工程可试玩版。舰体沿用用户最终选定的第一版浅蓝灰图；主武器改为真实潮汐攻击。最终强度与手感仍待玩家试玩。

## 开始试玩

设计页搜索“万有引力”，应用“潮汐攻坚”或“引力控场”，进入模拟器部署。已有自定义配装继续保留；旧方案名称不会被自动重写。主控武器为第 1 组的内置潮汐投射器。

| 操作 | 效果 | 代价与限制 |
| --- | --- | --- |
| 左键按住 | 捕获一个实体，准星移动拖锚；对敌舰持续施加 1200 能量伤害/秒 | 射程 1450，舰体捕获 0.22 秒，弹体 0.08 秒，最长保持 5 秒；释放后恢复 1 秒并需松键再抓 |
| F | 准星处固定重力井，聚拢敌舰、实体弹和可移动障碍 | 650 半径、1700 放置/维持距离；0.25 秒建立，持续 7 秒，启动 900 幅能、维持 250/秒、冷却 8 秒；再按收回 |
| G | 消耗当前井，在固定位置产生一次潮汐坍缩，保留左键连接 | 0.45 秒预警；中心最高 3200、边缘 800 能量伤害，按实际接触距离衰减；1800 幅能、8 秒冷却，没有井不可用 |
| 右键 | 从本舰向四周推出敌舰和实体弹，成功后释放抓取对象，保留 F | 0.1 秒建立、0.4 秒扩张、1050 半径；2800 幅能、8 秒冷却；每个对象每波最多一次冲量，不额外附加爆炸伤害 |

捕获费用 60。牵引维持按目标质量消耗，基准 350/秒，质量倍率限制在 0.75–2；敌舰潮汐攻击另外消耗 600/秒。纸面伤害不是穿盾或无视装甲的船体伤害。

普通友舰、友弹不受井、坍缩或排斥误伤。左键主动抓过的友舰可用右键推出；友舰、弹体和障碍不承受直接潮汐伤害。固定障碍成为反牵锚，移动障碍和残骸通过真实动量运动。重舰按质量抗拉；距离、遮挡、相位、排散、过载、停机与撤退会打断适用连接/场。排斥无法推走光束，不赋予无敌。

先用 F 聚拢，再以左键牵住高威胁目标，选择 G 的时机兑现伤害；右键留作近身解围或反投。坍缩前目标仍能离开、调整盾弧或利用掩体；投送物体保留实际方向和动量，不自动返航。

## 舰体与配装

60 DP / 280 OP，船体 28000、装甲 1400、速度 70，基础幅能 24000、耗散 1500。无盾、相位、航空或独立舰体模块。1 内置 XL、0L、4 可换 M 能量、6 可换 S 混合位；XL 是 Web 扩展档位。固定场设备画在舰体中，内置位仍参与正常武器损伤。

- 潮汐攻坚：4 质量校准炮、2 偏转阵列、4 双联近防，45 排散器、45 电容器，174/280 OP。
- 引力控场：4 质量校准炮、4 偏转阵列、2 双联近防，45 排散器、45 电容器，180/280 OP。

常规自卫炮纸面输出共 480 DPS；引力本身是主要攻击。空余 OP 供继续配装；S/M 位按实际类型同档换装，固定 XL 不可移除。基础配装不虚构插件。

## 画面与验收范围

旧的激光连接和三层蓝环已移除。真实战斗画面在引力影响处折射：牵引有空间剪切和稀疏流迹，井有向内收束，G 有预警收缩及实际伤害事件锁定的闪光，右键扭曲沿权威波前传播。时钟来自模拟；暂停不继续演出，关闭效果层会移除引力反馈。场推进没有化学尾焰。

当前证据：主线程和实际 Dedicated Worker 各 59 项生产规则检查一致；两套配装界面装配、刷新保存和模拟器启动通过；正式 WebGL 状态图及 45 秒 AI 基础作战通过；新特效通过抗锯齿画布、原分辨率/0.75 渲染比例、暂停像素一致和关闭效果检查。新特效录屏位于 `artifacts/gravity/v8/gravity-effects-v8.webm`。

受控检查使用真实舰体轮廓。1 秒满装甲目标先损失约 386.94 装甲，不能将 1200 DPS 宣称为 1200 船体伤害；已展开全向盾实际增加 1200 硬幅能。G 同一装配根每次只伤一次，正常经过盾弧、装甲和有效遮挡。完整实战中损伤计入战果，过杀不计入真实船体损伤。

未验：最终平衡、真人长局、真人多人端到端，以及旧宿主自动安装新规则。快照编码/显示恢复通过不代表真人联机完成。

## 素材与单舰包

本机原作版本由 `../starsector-core/starsector.log` 首行核实为 0.98a-RC8；实际查看 Aurora、Apogee、Paragon 正式贴图，借鉴哑光装甲、机械凹槽和小面积指示灯。新舰是原创 Web 内容，不是原版等价复刻。运行源图 `output/imagegen/gravity-battleship-v8/gravity-native-v8.png`：894×1759 RGBA；缩放 0.38，世界尺寸 339.72×668.42，碰撞半径 331，alpha 外轮廓 277 点。挂点和闭合场驱动位置见 `gravity-battle-art.json`。S/M 武器沿用已生成且独立标定的 v6 图集资产。

开发包包含本舰数据、4 武器、2 配装、5 张原创运行图与专属规则源码，依赖已编译 v8 引力能力的宿主。原版效果和炮弹图、声音由宿主提供，不重新分发；本包不依赖另一艘原创舰，不包含生涯开发代码，也不是 Java 原版模组。JSON 导入器不能执行新 TypeScript 规则；本工作区已内置同 ID，直接选舰，勿重复导入。
