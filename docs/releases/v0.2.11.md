# Starsector Web v0.2.11

本次正式版本整合 v0.2.10 之后的非生涯模式源码、工具及文档。生涯源码、HTML 入口、服务、专用测试／导入工具、新 HUD 字体和专用资源全部排除；本地未完成生涯文件保持原样。保留已有发布范围门禁及 Windows 换行兼容修复，不跳过失败的检查。

## 联机与性能

- LAN / Steam 共用纯显示副本接收路径，显示数据与权威模拟构造分离，保留严格字段校验、旧端拒绝与完整状态回退。
- 接入 Steam 独立运动数据报、实际消费回执门控和有界预算；视觉／战斗组件继续为显式 opt-in，不强行开启实验路径。
- 普通房主完整二进制状态只上传一次，中继根据接收方实际组件消费资格派生去弹丸版，避免重复大状态编码／上传。
- 优化共享捕获及显示恢复热路径。48 舰冻结源码离线对照中，本轮副本 apply 平均 20.92 → 17.98 ms（减少约 14%），P95 25.96 → 24.11 ms；完整编码和最终副本状态一致。最大 apply 延迟未改善；结果不代表真实公网延迟、渲染 FPS 或长期房间容量。
- 整合战斗 AI 威胁计算、渲染读取／实体投影及诊断修正；被性能门禁否决的试验仍未启用。

## Web 加载与界面

- 无损图片编码采用更小且通过像素／元数据核验的 WebP；原始资源与音频保留，生产输出不携带被替换图片的双份副本。
- 优化原版菜单字体加载、PNG 压缩与首页 WOFF2 子集，保留完整字体回退。
- 区分并补齐舰船技能、无人机及诱饵效果说明，技术实现说明独立展示，不将相同兜底描述当作实际效果。
- 构建与打包增加资源完整性校验；CI 显式安装 Python / Pillow 图片编码依赖。

## 兼容与发布

- 联机协议 **30**；房主、客机、中继需要统一升级，不能混用旧版本。
- Windows 普通便携版、Steam 便携版、Electron 安装版及 ZIP 由同一发布提交生成，附带更新清单；正式版在全部门禁通过且附件完整后公开。
- 原生 Steam 跨账号／跨网络和长期容量仍未全面验证，不承诺通用稳定 60 Hz／60 FPS。
- Steam 默认开发 AppID 仍是 480，本次 GitHub 正式 Release 不等于 Steam 商店发行或已配置正式 AppID。
