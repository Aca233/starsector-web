# 不可变舰体插件查询热路径（2026-09-24）

## 修改前证据与范围

本机 Starsector 0.98a-RC8：`starsector-core/data/hullmods/VastBulk.java:9–12` 将结构/引擎伤害倍率设为零；`data/hullmods/hull_mods.csv:195` 定义 vastbulk。`decompiled/starfarer_obf/com/fs/starfarer/combat/ai/private.java:233–282` 按可见性、合法性、距离/射界等筛选目标。此次不改变插件效果、目标资格、相位/碰撞状态、计算顺序或精度，仅避免相同不可变名单的重复成员查询；没有 UI 改动/原版实机补验。

## 真实 Worker 剖析

`artifacts/fleet-cpu-20260924/profile/serial.cpuprofile` 来自 headless Edge 153 的生产 local Worker；200 Onslaught、180 步预热后采样 90 步。模拟调用栈累计采样约 5532 ms，武器控制 update 约 2535 ms，fleet planner 约 623 ms；hasVastBulk 自身约 206 ms。包含时间不能叠加；profiler 结果仅用于定位，不用于宣称加速。

## 有界实现方案

仅将 `Ship.hasVastBulk` 的两个数组 includes 查询换成等价 helper：保留两次 `this.spec` 读取及短路顺序，每次仍读取实际 includes 方法。只缓存项目自己登记的深不可变、稠密、普通原型数据数组；不缓存舰船状态。普通/浅冻结/可变名单、洞数组、非普通原型、自定义方法仍走当前方法调用。原生 includes 被替换后也必须走实时调用，恢复后才复用已验证缓存。

缓存只存查询结果，不改共享对象/数组所有权、不冻结调用者数据。复用前一轮已接受的多核成本保护，不扩大 native batch 资格。

## 验证计划

在既有 simulation-hotpaths 场景中追加：正负查询、名单修改/替换、浅冻结配置的可变子数组、数组/方法 getter、spec 双读与短路、自定义 includes 的 this/参数/调用次数、注册的洞数组、原型方法替换恢复。随后一次 typecheck / scoped lint / 该既有场景；真实 Worker 对冻结当前基线的 100/200 舰配对，比较有效显示区/声音/权威快照/隐藏火控 RNG，并独立判断整体均值与 P95。不以单个 getter 或 profiler 的改善冒充模拟提速。

## 首轮验收发现的调度回归（修正前补记）

200 舰元数据候选模拟均值改善约 4.9%，但 100 舰整体回归：旧版 tick 62 退出亏损多核，候选直到 tick 199 才退出，测量窗口包含 42 个新增慢批次。没有删掉这些样本或把该轮宣称成功。原因是成本保护的串行 EMA 混有开局冷启动成本，试跑后每 8 次才以 0.1 权重更新一次，无法及时反映当前串行成本。

补充有界修正：仅本地启用“新鲜串行探针”模式；24 步初始暖机仍用于是否值得试跑，试跑后的第一个完整串行步替换旧冷启动比较基线，随后用 0.5 EMA；至少 3 个串行探针且 12 个真实并行样本后才可判亏损。阈值 1.15×+0.5ms、频率、60 秒迟滞、逐步权威模拟保持不变。LAN 默认构造参数不启用这一模式。针对该实测失败补充冷/热样本和有利并行的预算测试，再做真实通道复验。

另外补上 helper 的初始化类型判定：若模块载入时 includes 已被换成非函数，不能在初始化就提前抛错；实际调用仍走原生语义的 TypeError/当前方法。

## 长窗口的第二个具体失败与修正

第一版 fresh-probe + 元数据在 200 舰长窗口里 tick 49 正确退休，但 60 秒到期后于 tick 289/291 再次启动/计算同一类亏损工作，直到 tick 312 再退出，使 P95 变差。原始失败保留在 `final-ba200/result.json`，不是最终通过结果。

本地重试增加工作量条件：60 秒只是最短冷却，之后只有舰队数量改变或串行成本 EMA 较上次暖态基线增长至少 25% 才重试。条件只用于新的试跑；一旦获准，仍完成最少样本比较，不因历史基线中途取消试跑。低成本/小舰队/硬件/资格检查、完整模拟、盈利 Worker、取消及重置仍保留，LAN 默认模式不变。条件有明确取舍：相同规模/相同总串行成本但内部热点构成变化时，可能延后重新发现多核收益；用避免周期性卡顿换取稳定性，而非承诺永远选到最快策略。

## 最终验收状态

保留稠密不可变插件查询及本地暖探针/工作量驱动重试；最终200舰长窗口模拟均值62.662→59.678ms、Worker往返P95 104.190→96.295ms，660次逐tick对照和22次完整权威/隐藏状态对照通过。原失败样本均保留，详细版本区别、测试及取舍见 `immutable-hullmod-query-performance-2026-09-24.md`。
