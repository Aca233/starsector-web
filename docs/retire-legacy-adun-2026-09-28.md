# 删除旧版亚顿之矛（2026-09-28）

## 修改前范围确认
- 旧版：`web_spear_of_adun`，26槽单体安装架构验证舰（v05）；`SpearOfAdunPack.ts`，旧 `WEB_ADUN_SOLAR_FORGE`。
- 保留新版：`web_spear_of_adun_ark`，核心+FORE/PORT/STARBOARD/AFT五段、13武器、4航空甲板和新版共享太阳能技能。
- 本次是按用户要求移除Web原创旧舰，不是还原原版玩法/界面；不改原版资源或战斗数值。
- 旧/new武器使用独立ID，已装在其他船上的旧军械可能仍有效；新版还在用 `AdunFXAssets` 等共享资源。因此不按 `adun` 文件名前缀批量删目录，不删用户下载的源模型、历史素材/制作记录。

## 实施计划
1. 从实际注册、设计舰体字典和装配方案移除旧舰，旧系统从运行注册移除。旧开发源只作为历史制作资料保留，不再由运行入口导入。
2. 保留独立四档军械注册（不依赖旧舰包），避免破坏其他船的既有配装；共用特效继续可用。
3. 读取方案库时只识别这一确切旧舰ID。遇旧舰草稿/保存项，先为完整原始JSON写浏览器备份，再排除旧舰，原草稿为旧舰时打开新版空白默认草稿；不将旧26槽武器强行塞进新13槽。其它舰船方案原样解码保留。备份失败则沿用写保护，不覆盖原数据；其它未知舰体仍报错，不能宽泛吞数据。
4. 一次类型检查、改动文件lint、现有方舟场景的针对性规则/资源检查；隔离无头UI/Worker验证目录仅剩新版、旧库加载不崩、新舰可模拟。不开用户桌面，不碰5173/5174，不提交/发布。
