# 万有引力号 · 可玩工程版 v6

2026-09-30。已接入本工作区的 Starsector Web：正式舰体、四种武器、四键引力行为、两套合法配装、AI、HUD 与正式 WebGL 反馈。定位是无盾引力辅助实验巡洋舰。本舰属于原创扩展，移动残骸与固定锚反牵也属于扩展规则；不声称是原版等价实现。

## 开始试玩

在舰船设计界面搜索“万有引力”，选择万有引力号，再从“装配方案”选护航救援或阵地控场，确认后进入模拟战斗。模拟器的配装列表也可直接选择这两套方案。牵引器在默认第 1 武器组；切换武器组后，左键按宿主正常武器组规则开火。

| 输入 | 当前实现 | 组合用途 |
| --- | --- | --- |
| 左键按住 | 对一个真实对象建立牵引，鼠标移动拖锚；松手保留动量 | 抓友舰救援、抓实体弹反投、移动掩体；真正固定障碍反牵本舰 |
| F | 准星处建立固定引力井；再按收回 | 先布阵，吸引敌人或调整自家标定弹轨迹 |
| G | 消耗已有 F 井，从远端锚点扩张排斥波；保留当前牵引 | 聚拢后拆阵，或一边抓取一边在远端释放 |
| 右键 | 本舰强全向排斥，成功时松抓，独立于 F | 近身解围，主动推送刚抓住的友舰或实体弹 |

右键成功后必须松开左键才能重新抓取；启动失败保留牵引与 F。没被抓住的友舰及普通友弹豁免；普通推偏敌弹不改变所有权。只有成功手动捕获弹体才接管归属并停止原制导，原寿命、引信、飞行预算、耐久和已有伤害继续生效。

## 当前数值与装备

巡洋舰 / 25 DP / 165 OP；质量 3000，船体 10000，装甲 900，速度 85，基础幅能 8500 / 耗散 550，无护盾、相位或舰载机。闭合场推进器隐藏化学尾焰，以实际推力驱动场光反馈。

| 项目 | 当前工程基线 |
| --- | --- |
| 内置 L 牵引器 ×1 | 射程 1050；船/环境捕获 0.32 秒、弹体 0.08 秒；最多持有 2.8 秒；释放恢复 1.1 秒；维持 330 幅能/秒 |
| M 标定炮 ×4，可替换 | 能量槽、动能伤害；每发 180，间隔 1.5 秒，射程 1150；自家弹可有限借井曲射，保留真实碰撞 |
| S 混合槽 ×6，可替换 | 有限偏轨器与双管常规近防；偏轨消耗幅能与预算，不接管弹体、不删除弹幕 |
| F 固定引力井 | 半径 520，放置距离 1400；建立 0.35 秒、持续 6 秒；启动 240 + 维持 180/秒；冷却 7 秒 |
| G 远端排斥 | 半径 520；启动 450；冷却 6 秒；消耗当前井 |
| 右键全向排斥 | 半径 820；建立 0.12 秒，扩张 0.65 秒；启动 900；冷却 11 秒 |

护航救援：4 标定炮 + 2 偏轨器 + 4 近防，30 排散器、25 电容器，139/165 OP。
阵地控场：4 标定炮 + 4 偏轨器 + 2 近防，同样 30 排散器、25 电容器，145/165 OP。

重舰按整舰质量抵抗；模块不被拆走。场、牵引、偏轨对同一物体共享限幅。光束与已结算爆炸不受力。残骸随实际位置进行炮弹遮挡、避让及多边形碰撞；碰撞只按相对速度结算有限伤害，不凭空增加爆炸。固定物体通过明确 `gravityFixed` / `GRAVITY_FIXED` 标识区分，不把“当前速度为零”当作固定。

## 素材与验证

本轮按用户“直接调用生图”的要求使用内置生图工具。运行舰体保留认可的原图 RGB，采用生图得到的透明蒙版；四种武器采用本轮生成的透明素材。`scripts/prepare-gravity-art.py` 只裁切、标定并导出，不重画舰体。资产在 `public/game-assets/graphics/gravity/`，标定在 `src/engine/content/gravity-art.json`，来源归档在 `output/imagegen/gravity-armory-v6/`。

- 类型检查与相关改动文件 lint 通过。
- `artifacts/gravity/rules-check.json`：主线程和真实 Dedicated Worker 各 147 项；包括保留的 86 项历史引力回归与 61 项 v6 整舰/武器/环境/投影检查。
- `ui-check.json`：两配装界面确认、刷新保留、真实模拟器启动通过，无页面错误或失败请求。
- `presentation-check.json` 与四张状态截图：正式 WebGL 舰体、牵引 + F、右键扩张波、G 远端释放通过；无 WebGL 错误。
- 45 秒自然 AI 功能场景出现牵引、F、G 和实际标定炮射击，位置有效；造成少量装甲损伤，不能据此宣布强度已平衡。

仍待人工长局手感与同级阵容调平衡、真人联机端到端验证，以及许可后的原版实机对照。当前交付是可玩工程版，不是最终平衡发布版。

## 单舰开发包

`artifacts/gravity/gravity-ship-dev-pack-v6.zip` 包含单舰/四武器 JSON、两套配装、五张原创运行资产、标定、独立引力扩展源码、接入说明与验证记录，不含未完成生涯代码或整宿主发布包。

本工程已内置这艘舰，不要重复导入相同 ID。其它宿主必须先接入本包列出的引力控制器、系统注册、物理帧序、动态残骸、显示协议与 UI 注册要求，再加载数据；仅导入 JSON 不会使旧宿主自动拥有新玩法。本包也不是 Java 原版 Starsector 的 mods 安装包。
