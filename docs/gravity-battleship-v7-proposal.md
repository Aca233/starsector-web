# 万有引力号 · 实验引力战列舰 v7 方案

2026-09-30。状态：新设计方案，未改写当前运行中的 v6 巡洋舰；不是已完成实装或平衡验证。用户试玩后要求重新设计为实验引力战列舰。

## 定位与现版问题

现版是 25 DP 的辅助巡洋舰，四门标定炮合计理论 480 DPS，核心牵引不造成伤害、持有仅 2.8 秒。有限 AI 场景只证明能运行，不证明玩家感觉有用。新定位为 60 DP 的实验引力战列：轴向重炮兑现控场收益，同时保留抓弹、救友舰、移动掩体和全向排斥的实验玩法。用户最新明确“不要搞宽体重装”，外观与生存路线改为修长实验舰，取消宽装甲核心及厚重堡垒轮廓。

核心循环：F 将目标聚向一条交战线 → 左键重炮压盾拆甲；G 精调一个实体或抓住危险弹体 → 右键近身排斥、反投或救援。普通瞄准开炮即可作战，组合操作提高命中、站位和生存收益。

## 四键与规则卡

| 输入 | 能力 | 玩家收益 |
| --- | --- | --- |
| 左键 | 双联潮汐质量炮，按住连续发射 | 主攻击输入；每轮先发一枚动能弹，再发一枚高爆弹，实际压盾/拆甲 |
| F | 固定重力井，在鼠标位置布置，再按收回 | 将敌人聚到火力线；井侧有限弯曲本舰质量弹，改变接近角度 |
| G 按住 | 重型牵引锁，抓取鼠标选中的一个真实实体并移动拖锚；松开释放 | 把目标带出掩体、抓弹反投、救友舰、移动掩体；真正固定物体反牵本舰 |
| 右键 | 全向强排斥波，成功时释放 G 抓取 | 近身解围和物体投送；与 F 独立，不要求预先布井 |

G 使用独立系统输入，不再占用左键，也不需要切换武器组。G 抓取时主炮仍朝鼠标正常瞄准；拖动敌舰时准星既是拖锚也是炮火指向，可以边牵引边射击，但舰体不是鼠标坐标的复制，目标推进/转向/反击继续有效。

左键不能因为没有可抓目标而变成无用操作。F/G/右键各有固定语义，不根据敌友或点击长短偷偷变招，也不增加第五个资源条。

### 左键：双联潮汐质量炮

- 1 个内置 XL 轴向双联加速器；XL 是 Web 扩展档位，不是 Java 原版槽位。两条长加速通道与主轴一体化，舰首有限射界；两枚弹体分别出膛、飞行、碰撞，不能把两次命中合成一笔绕盾伤害。视觉采用实验场发射结构，避免两个巨大传统炮筒。
- 初始候选：每轮动能弹 1800 + 高爆弹 2400，前后间隔 0.18 秒，轮间隔 3.2 秒，整轮理论 1312.5 DPS；射程 1600、弹速 1100、整轮 2200 软幅能。数字是待试玩基线。
- 即使不使用系统，主炮也有战列舰输出。动能弹实际增加盾幅能；高爆弹只有在盾已过载、转开或没覆盖命中侧时才能有效拆甲。没有默认穿盾、自动瞄弱点或隔掩体命中。
- F 对这两种自家质量弹实施有限弯曲：最多约 30°，不增加原伤害，不取得自动索敌。射偏仍会射偏，贴近井的路线和入射方向由玩家选择。
- 主炮受舰首转向、炮口遮挡及武器损坏限制；中小目标可以侧移规避。正在 G 控制的障碍也可能挡住自己的炮火。

### F：战列级固定重力井

- 候选放置距离 1700、半径 650、建立 0.25 秒、持续 7 秒；启动 900、维持 250/秒、冷却 8 秒。再次按下安静收回，保留已经产生的真实运动。
- 使用连续质量响应；轻舰明显横移，巡洋舰能被改变火力线，战列舰受到较缓慢的侧向牵引。不能直接定身、抹掉推进或强制将所有对象放到井心。
- 不做额外伤害技能。真正收益是创造主炮命中角度、集中交战线、延迟撤退，以及有限修正自己发射的质量弹。
- 普通友舰/友弹豁免；被主动 G 控制的对象按其明确关系受力。光束、已结算爆炸和无实体特效不受力。

### G：重型牵引锁

- 按住 G 对准目标建立连接；候选射程 1300、捕获船/环境 0.25 秒、弹体 0.08 秒、拖锚速度 650、最长保持 5 秒、释放恢复 1 秒；捕获 150、维持 400/秒。
- 优先真实准星覆盖的船/障碍，高速弹使用有上限的捕获辅助；不穿盾改变伤害，也不隔障碍抓后排。持续检查目标有效性、射界、距离与遮挡。
- 敌舰按整舰根质量与其实际推进抵抗；允许压迫射线或带出掩体，不允许瞬间甩飞战列舰或拆走附着模块。
- 友舰保留操纵、火控与推进。普通小行星/残骸能变成移动掩体；物理遮挡、舰船碰撞及导航必须随动。真正固定结构只反牵本舰。
- 只有成功手动捕获弹体才接管阵营并停止原制导；寿命、耐久、飞行预算、引信与发射时伤害继续消耗。松开 G 保留真实动量，不自动返航。
- 右键成功释放后必须松开 G 才能重新抓，避免按住键连续重复弹射。启动失败保持抓取关系。

### 右键：战列级全向排斥

- 候选 0.10 秒建立、0.40 秒扩张、半径 1050、启动 2800 软幅能、冷却 8 秒；单按触发，不要求 F 存在，不增加蓄力分支。
- 实际波前接触时给一次质量相关径向冲量：清开逼近的实体弹和小物体，推离轻舰，对重舰造成可察觉但有限的距离改变。不是几乎看不见的速度扰动，也不是瞬间传送。
- 成功释放 G 操纵对象并登记豁免例外；主动抓住的友舰/弹体可被推送，其他友舰与普通友弹不受影响。F 保留，因此可以把敌人推回已有井或推离危险位置。
- 抓弹反投按物体真实所在侧投出；想向敌人投送，先将它带到敌人方向的一侧。不会一按右键就让身后所有导弹自动命中敌舰。
- 推偏未经捕获的敌弹不变更所有权。波不删除弹体、不给无敌帧、也不抵消光束。碰撞伤害按真实相对速度与明确上限计算，禁止无限质量石头一击秒舰。

## 性能与安装草案

候选基础：CAPITAL / 60 DP / 280 OP；船体 28000、装甲 1400、基础幅能 24000、耗散 1400、速度 70。继续无护盾/无相位路线，以机动、引力干预和主动排斥承担更多生存职责，敌方光束与高爆持续火力能形成压力。无舰载机、无独立模块；保持四键操作集中。数值尚未实测。

| 档位 | 草案数量 | 类型/固定性/职责 |
| --- | --- | --- |
| XL | 1 | 内置、固定舰首、实验双联质量炮，内置成本纳入舰体基础，装配 OP 计 0 |
| L | 2 | 可换、混合炮塔，压盾或持续拆甲 |
| M | 4 | 可换、混合炮塔，副炮或有限偏轨 |
| S | 6 | 可换、混合炮塔，常规近防 |

这是新战列舰母版的挂点草案，不把当前巡洋舰图放大后强行宣称槽位可用。用户不要宽体重装，也已否定三根杆状分离场舱试稿；两张均弃用。用户随后选择流线高科技 + 简洁实验舰方向。最新候选 `output/imagegen/gravity-battleship-v7/gravity-battleship-sleek-v7.png` 采用完整流线主体、珍珠白大面板、深蓝内构、内嵌椭圆场核心、舰首轴向加速器与贴合舰尾的场翼；减少随机细节和支架。闭合场推进，无化学尾焰。该图尚未获用户认可或换入游戏，重新标定后才冻结尺寸、挂点、炮口、射界与碰撞。

## 两套配装草案

同一主炮与四键基础，不依赖另装一艘原创舰。以下 OP 是自研武器的候选成本；尚未由生产配装编译器确认。

- **攻坚型**：2L 压盾炮（各 24）+ 4M 拆甲副炮（各 16）+ 6S 常规近防（各 5）+ 45 排散器/45 电容器 = 232/280 OP，余 48 可供合法插件或换装。主炮破口后副炮持续兑现伤害，缺少偏轨保护。
- **控场型**：2L 持续主战副炮（各 32）+ 4M 重型偏轨器（各 14）+ 6S 常规近防（各 5）+ 45 排散器/45 电容器 = 240/280 OP，余 40。持续炮火较少，面对实体弹压力能为前进和主炮瞄准争取时间。

基础耗散 1400；45 排散器按宿主普通每个 +10 的草案口径到 1850。主炮平均约 688/秒，加维持中的 F/G 为约 1338/秒；开火、偏轨、副炮和频繁右键会压缩剩余预算，不能同时永久拉满。装配实际幅能、插件影响及 OP 需在实现后重新核算。

## 高水平收益与反制

1. 正面攻坚：F 放在敌舰侧后 → 双联质量炮先压盾后拆甲 → G 微调敌舰横向运动，让其难以简单侧移避开后弹。
2. 反投：G 抓住危险导弹 → 调到敌人一侧 → 右键推出。晚抓会引爆，拖太久会耗尽寿命，忙于反投会错过主炮瞄准。
3. 敌舰离井撤退：保留 F，右键把近身敌舰推向井边；或主动收井保留敌人横向动量，以主炮预判追击。
4. 救援：G 抓友舰，移到安全侧后右键推送；放弃自己的压迫角度与射击窗口，换队友生存。

核心选择是炮线、井的位置、当前抓取对象和排斥时机。主要弱点为缓慢转向、两发间隙、无盾时对光束/高爆的压力，以及高幅能时无法开波。敌方持续推进与质量抵抗、掩体遮挡及不同入射方向都保留。

## 实现差异与验收目标

可复用 v6 的对象解析、归属/制导接管、质量/限幅、环境碰撞、波前与显示基础，但要重新定义 G 输入、主炮攻击契约和战列级场预算，不能只改舰级与数值。新增 XL 母版/双炮管、L/M 资产及独立射线标定。旧 v6 147 项通过不证明新方案可用。

首轮试玩重点：没有系统时主炮足以威胁同级；小目标受力可见；同级战列不会被瞬移或定身；单 G 抓取不剥夺目标行动；动能/高爆两弹分别命中；右键能救急但不能连续抵消所有火力；两套配装都有使用场景。实际伤害、幅能曲线、反投命中、同级自然 AI 交战与人类手感分别记录后再调参。
