# UI 动效与过渡

## 实现

保留原版字体、材质、配色和布局，没有引入动画库。

- `src/ui/core/motion.css`：主菜单、改装、舰长技能与目录页面淡入；标题与主菜单按钮错峰出现；按钮悬停高亮、按下 1 px 反馈；筛选、列表、技能图标的颜色与边框过渡；新成员/AI 行、提示和装备浮窗淡入；换船淡入及改装预览缩放过渡。加载时有短线往复指示。
- `MotionPresence` 在 33 个条件弹窗入口中保留最后一份 React 内容，完成 140 ms 退出后再卸载，而不是复制 DOM。范围包括改装选择器、确认框、联机帮助/房间工具/AI 编成和暂停菜单入口。重新打开会取消旧的移除计时器。
- `Modal` 使用同一退出时长，并在退出期间使面板 inert、截断键盘向底层传递。关闭后恢复原控件焦点；快速重新打开重新取得焦点；旧弹窗在新弹窗下面退场时不抢走新输入框的焦点。
- 弹窗及浮窗祖先只做透明度动画，不加 transform，保留原有像素对齐及 fixed 武器说明卡的视口定位。
- 新动效仅在 `prefers-reduced-motion: no-preference` 下启用。减少动态效果时没有入场动画或关闭等待；关闭过程中更改系统偏好也会清除等待。

## 边界

不对战斗 canvas、物理、AI、网络同步或整个游戏循环做动画处理；没有全局 `*` 动画规则、常驻 will-change、逐帧 React 更新或装饰性无限循环（加载指示除外）。按钮命令仍立即执行，不等待动画才保存、安装或开始操作。完整页面/父树卸载不会为了退出动画保留旧模拟或旧连接。大型目录不逐行错峰展示。

## 验证

- TypeScript 与独立生产构建通过。全项目 oxlint 无错误，但最新工作区有 3 处联机代码警告（LanTeamControls / LanAiFleet 的同步 effect 更新、LanRefit 渲染阶段读 ref），未改动这些非动效逻辑；动效核心文件定向检查无警告。构建仍有项目原有的大分包体积提示。
- 浏览器逐帧观察设置弹窗：退出透明度从 1 经多个中间值降到 0，然后卸载；背景 inert 与原按钮焦点恢复。
- 关闭 40 ms 后重新打开：旧计时器不会移除新弹窗，且焦点回到当前弹窗。
- 退出时向 body 发送按键：事件被阻止，不漏到下层窗口监听器。
- 模拟减少动态效果：动画为 none、无关闭等待、背景恢复可操作。
- 改装武器组开合；武器选择浮窗与参数卡保持视口内定位；F2 嵌套数据百科逐层 Escape 返回，原选择器未被一并关闭。
- 连续切换两个独立弹窗：旧窗退场后新窗输入框继续持有焦点；全部关闭后不残留 inert。
- 独立联机房间：联机说明、AI 编成、分队规则、离开确认开合正常；测试房间已主动退出。未宣称完成 Steam 跨网或完整战斗性能压测。
