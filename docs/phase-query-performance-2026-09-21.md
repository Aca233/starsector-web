# 相位查询热路径：来源与性能边界（2026-09-21）

## 编码前对照

- 本机原版：`../decompiled/starfarer_obf/com/fs/starfarer/combat/entities/Ship.java:5006` 的 `isPhased()`，以及 API 源码 `../decompiled/starfarer_api_source/com/fs/starfarer/api/impl/combat/PhaseCloakStats.java:407-415`。相位状态是当前可碰撞/可瞄准状态，IN/ACTIVE 及 OUT 退相阶段需实时反映；不允许为性能跨步缓存其真假值。本机版本由 `../starsector-core/starsector.log:1` 核实为 **0.98a-RC8**。
- Web 当前 `Ship.isPhased` 先检查母舰、收纳、撤退、相位盾，再检查主系统、附加系统、防御系统，最后依序执行外部相位回调。每次通过 `allSystems` 创建 slice 和展开数组；这是本轮优化的分配热点，不改任何状态定义。
- 预期：常见 0/1 战术槽无需构建数组即可检查主系统与防御系统，但必须在首个 `isPhased` 回调前捕获两者，保留原数组的快照语义、短路和顺序；多系统保持原路径。公开 `allSystems` 仍返回可独立修改的新数组。
- 验证：冻结本轮全部源文件，逐查询及完整战斗状态对照；回调替换系统、数组长度变更、主系统独立替换、多槽、父舰、外部效果与异常传播的定向测试；前后交替生产浏览器测量。
- 原版 UI/实机：本次不改布局、素材、绘制或操作；没有占用桌面，也没有新的原版实机截图。只验证 Web 画面和状态不回归，不声称本轮完成原版等价验收。

## 初始定位（仅用于定位，不能作前后收益）

冻结当前 772 个源码文件；无头 Chromium/ANGLE D3D11，2560×1440，100 艘密集 Onslaught，360 步、60 步预热。CPU profile 含约 65.8 秒运行，`isPhased` 是多个火控/威胁栈的热点；护盾扇区 O(n²) 并非仅凭复杂度就认定需要重写。profile 保存于忽略目录 `artifacts/perf-20260921-shield/`。


## 第二候选：静态相位能力证明

第一候选虽减少了 30 步百舰约 365 万次数组构建，但生产复测无稳定整轮收益，已撤回它的生产代码，数据保留为失败实验。

第二候选不缓存 `isPhased` 的活动状态，而是对原生不可变系统定义证明“此系统永远不提供相位能力”：依据 `ShipSystem.isPhased` 在 `definition.phase` 不存在时恒为 false，以及 `Registry.ts` 对原生 `isExecuting` 等读者的纯函数认证。缓存只记主/防御系统对象及定义身份，槽数、对象或定义改变重新判定；多槽、未知注册系统、覆写读者保留原逻辑。母舰、相位盾、收纳/撤退、外部相位效果仍每次实时执行。

这不是对任意 JavaScript 原型篡改的通用纯函数认证。正常定义注册/更换及原生生命周期属于验证范围，热插入 getter/修改类原型的 monkey patch 不能自动当作静态原生能力。

## 最终决定：两个候选均撤回，不宣称新的生产提速

第一候选：单槽相位查询绕过临时数组。第二候选：原生不可变非相位系统的能力证明缓存。均没有降低画质、舰船数、AI/物理频率；最终生产 `Ship.ts` 恢复为本轮冻结前内容，新增 `PhaseCapabilities.ts` 已在核对内容仍等于本轮候选后删除。未重置工作区、未撤销原有优化、未暂存/提交/发布。

### 验证与限制

- 第一候选 9,984 组冻结 getter 对照：主/防御/多槽、外部效果、母舰、收纳/撤退、回调内替换/截短系统列表、短路顺序、异常与公开数组隔离。
- 两候选分别完成 Doom/Harbinger、Odyssey/Paragon、Onslaught 三组十舰、各 180 步；每 30 步完整模拟/AI 可枚举状态对照，各 18 个检查点一致。每轮观察到 1,668 个相位中的舰-步样本。仅排除 kernelMs 墙钟计时，不声称覆盖隐藏 WeakMap/闭包字节。
- 独立百舰 30 步计数：3,647,833 次 Ship.isPhased 查询保持一致；allSystems 构建 3,766,103 → 118,270。状态哈希相同。计数降低不等于整帧性能提高。
- 第二候选另做 13 项实际对象变更回退检查，包含系统/定义替换、追加相位槽、外部效果、相位盾/父舰等；通过。不把未验证的原型热篡改列为支持。
- 八组生产浏览器对照最终引擎 + 玩家 AI 状态摘要一致，页面和 GL 错误为零。
- 两个被冻结候选及基线的 Vite 生产构建通过，保留原有大 chunk 提示；构建仅在忽略目录，没有替换当前 dist 或发布未完成生涯内容。
- 同场景截图目视结构一致，但**不逐像素相同**：差异像素约 0.0012%–0.0171%，单通道最大差异 31/255。未修改渲染源码；原因没有进一步证明，不将其武断归为已验证的 MSAA 噪声。详见 pixel-comparison.json。
