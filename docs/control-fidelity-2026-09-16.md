# 操纵与鼠标瞄准修正 · 2026-09-16

## 已修正

- 默认 A/D 转向、Q/E 横移，鼠标单独控制武器；按住左右 Shift 中任一个，启用船头跟随鼠标且 A/D 改为横移。H 面板提供真正生效的默认鼠标转向设置，反转 Shift 行为并保存为独立操纵偏好，不修改舰队存档。
- 鼠标转向改用原版的停止角预测：角速度² / (2 × 转向减速度)，其中被动转向减速度 = 转向加速度 × 0.5。预期停止朝向误差在 1 度内时松开转向，不再人为强加 15% 最低转向输入或 25 单位鼠标死区。
- Space 暂停/继续，V 排幅。弹窗关闭保留玩家的暂停意图；暂停帧固定使用当前物理姿态，避免插值在前后两帧之间抖动。
- 鼠标屏幕坐标按 canvas 的 CSS 矩形和实际像素转换；不假设画布永远位于窗口原点或 CSS 像素等于渲染像素。点击画布恢复焦点；失焦清除操纵与开火输入；战术地图不把指挥鼠标位置当作手动驾驶目标。
- 炮塔携带舰体旋转，再用自身转速修正瞄准，损坏炮塔也保持舰体相对角。有限射界不能从禁止的一侧绕捷径，360 度炮塔才使用完整圆的最短转向。
- 手动开火不再受 AI 式瞄准误差门槛控制。固定挂点、窄弧和原版 DO_NOT_AIM / GUIDED_POOR 标记接受扳机；齐射组选取射界内武器、没有合适射界时选择最近的一门，交替组只触发活动挂点。弹丸仍沿真实炮口方向飞行，不会被偷偷拉向鼠标。
- 非选中手动炮塔只在鼠标接近自身射界时追踪；无目标时保留相对朝向 15 秒再回中。

## 验证与边界

使用内存脚本验证输入映射、反转 Shift、相反按键抵消、坐标变换、停止角预测、跨 ±180 度、有限射界绕行、实际固定炮开火和损坏炮塔旋转。三艘现有主力舰在独立转向场景中最终角速度为 0，目标误差约 0.88 度（在原版 1 度门槛内），不把转速加快来伪装成更灵敏。

隔离浏览器用真实键鼠验证 A/D、Q/E、Shift、默认鼠标转向反转、Space 暂停/恢复、弹窗关闭仍保持暂停、固定炮在鼠标位于船后时仍向炮口方向发射，以及失焦清除开火。未写入测试文件、未运行资源导入器、未修改原游戏或用户现有存档。

此修正不是完整原版输入系统复刻：自定义键位、Shift 切换锁定模式、原版镜头平移/缩放曲线、全部自动火控 AI 仍未声称一致。本轮没有通过修改舰船基础机动数值来“调手感”。
