原定早期门槛：**所有窗口**编码P50≤0.90、合计P50≤0.95/P95≤1.10。两版均未通过。改善只是局部且不足以覆盖所有实际负载；5席位晚期没有稳定节约，不能把较快窗口冒充全局加速。

这不是远程 Steam/n2n 或实际编译5浏览器的 Hz/延迟测试。没有因此跑更多昂贵联机场景，也没有下调门槛。候选未通过早期性能筛选，**尚未完成**源注释列出的所有合成 map 头部边界/通用兼容性验收；不能把真实帧字节相同写成完整正确性证明。
