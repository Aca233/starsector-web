- 普通首页和改装页不再显示「全量原版内容」目录按钮；保留开发地址 `?view=catalog`。
- 舰船列表：名称 / ID 搜索、舰级按钮、势力下拉框、结果数量、重置和定位当前舰船。

- 势力索引来自原版 known/priority 装备池、标签与显式势力装配；共享装备允许多势力归属。不是当前库存、独占来源或战役生成概率。

原有冲刺推进、堡垒护盾、空雷突袭保持原实现；新增如下：

| 原版 ID | 战斗效果 |
|---|---|
| maneuveringjets | 机动推进器：航速、加减速及转向能力随系统阶段变化 |
| plasmajets | 等离子推进器：航速及机动能力强化 |

**未实现的系统不能激活，也不会显示成「就绪」。** 仍保留原版数据与未接入状态，不用空计时冒充有效技能。

## 本次补接的插件

- 第十四军团舰型（fourteenth）：装甲、幅能及机动性调整。
- 分布式火控（distributed_fire_control）：武器承伤及 EMP 承伤调整。
- 零武器幅能（no_weapon_flux）：弹丸和连续光束均不产生武器幅能；不影响护盾与系统费用。
- 幅能分流（fluxshunt）：开盾时剩余软幅能耗散预算用于硬幅能耗散。
- 加固子系统（hardened_subsystems）：峰值表现时间与后续 CR 衰减调整。
- 安全协议超驰（safetyoverrides）：航速、机动、幅散、峰值表现、主动排幅及远程武器限制；保留装配限制与 OP 费用。

改装航速、幅散、武器射程和武器幅能统计从实际效果计算，不仅替换说明文字。未完整接入的原作内置插件单独列出，不能视作有效战斗加成。

- 不稳定的注射器（unstable_injector）：航速加成、非导弹射程惩罚与舰载机补充时间惩罚。
- 弹道测距仪（ballistic_rangefinder）：按舰体实弹挂点等级和武器原生安装类别计算基础射程加成，保留上限及点防御排除。
