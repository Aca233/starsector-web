# Starsector Web v0.2.5

本版提交全部已审查的非生涯改动，不包含未完成的生涯模式源码、入口、测试或构建配置。已有游戏素材库中的 campaign 命名图标/音效不等于启用生涯模式，维持原有素材库。

## 联机与桌面日志
- LAN可靠有序增量复用最近成功发送基线，改进字节匹配密度；Steam与LAN对可接收玩家轮转分发，减少固定席位偏向。
- Steam小ACK快速副本保留可靠兜底；协商累计输入ACK，保持动作即时；增加ACK路径与SDK轮询诊断。
- 默认Steam客机复用已校验的状态JSON，去除重复full校验与序列化；保留完整状态和数值精度，不放宽8秒保护。
- 解码任务调度与host消费回执发布改进；实验Sockets避免压缩被替换的未发送状态。
- 桌面启动至退出持续写同一会话日志，模式切换/重连/刷新和Steam受控重启保留历史；导出按钮导出整个会话前缀。新增长任务、输入待确认、CPU/内存、队列、编码及ACK诊断。

## 房间、配装与UI
- 联机入口记住玩家昵称。
- 房间改装准备/开始流程、本地舰长草稿预览与个人配装准备状态修正。
- 更换舰体或应用配装时保留当前舰长技能与档案；包含相关UI、测试与通用字体声明整理。

## 已知限制与发布渠道
- 真实跨账号/双机低Hz、Steam ACK停滞仍需新构建复测，不能保证任何带宽下60Hz。
- 当前完整Steam测试仍有三项未通过：legacy9客机8Mbps骤降256Kbps；实验Sockets长时停顿恢复吞吐；实验Sockets健康9客机每端40Hz。
- 按既有CI门禁发布为预览版（Prerelease），不替代稳定版自动更新。所有附件完成后才公开；不降低门槛或隐藏失败。
- 普通浏览器日志仍为最近约10分钟；整次启动持久日志针对桌面端。
