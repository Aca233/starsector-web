# 避障远距排除（2026-09-18）

在用户要求优先解决联机同步问题之前完成的小优化，已合入 TacticalNavigation.ts；不再继续扩展这条性能实验。

原生距离/速度函数且没有自定义导航记录回调时，用速度 L1 上界和坐标差下界排除明显过远的对象。边界附近仍执行原始精确距离表达式。负 horizon、自定义运动/距离/长度函数走旧路径；NaN/Infinity 上界失败开放，加入 1e-12 余量。没有缓存跨步状态，不缩小避障范围。

12,723 项原生百舰、公开导航结果、随机阈值、非有限坐标/速度/时域、自定义函数和回调顺序对照通过。原生 Vector2 数据字段是优化前提；没有声称穷举任意属性 getter monkey patch。

两轮同页双世界交替运行各 1200 步，以相同种子 2232494901、两真人守护者和 98 锤头为输入；全部 100 舰初始部署。剔除前 60 步，平均物理耗时分别 29.718→29.134 ms、23.385→22.952 ms，合并下降 1.92%。每轮 tick 60/300/600/900/1200 的完整投影字符串相同。计时带有对两版共同的内存选择包装，并非生产 FPS 对照。

初始场景扫描微基准约下降 19%；不能与之前轮次的百分比相加，也不能证明百舰实时达标。先前较弱的仅距离排除候选做过四轮独立世界对照，计时存在明显顺序漂移，未据其平均数作提速结论，正式版本采用上面的配对验证版本。

证据：artifacts/lan-navigation-bounds-fast-source.json、-fast-validation.json、-fast-paired.json；冻结依赖：lan-navigation-bounds-frozen-sources.json。隔离生产构建已通过，当前源码 typecheck/lint 通过。其后的真实联机验证随网络同步修复一并记录于 lan-snapshot-starvation-2026-09-18.md。
