# 休伯利安：舰船插件接入

## 本轮范围与证据

用户批准内置旗舰反应堆、可选大和聚能回路、可选战地抢修系统。保留舰体、武器、已有存档与跃迁选点交互，不生图、不复制女王虚空盾，不发布独立包。

- 原版本机0.98a-RC8：`data/hullmods/hull_mods.csv` 的 autorepair 只加速武器/引擎修复，不回复船体；本轮船体抢修是明确的 Web 改编。
- `decompiled/starfarer.api/com/fs/starfarer/api/combat/HullModEffect.java` 的适用性、创建后效果、advanceInCombat接口：对应宿主注册、装配校验、apply与advanceCombat，不新增另一套插件安装UI。
- `data/shipsystems/phaseteleporter.system` 定义预热脆弱与跃迁残影；本轮延长实际预热而不是只修改文案。没有复制其相位免疫。
- 已看当前既有Web改装截图 `artifacts/hyperion/refit.png`，插件栏空白。原版实机插件窗口本轮未验证；复用当前原版风格插件列表、内置标记、图标与OP机制，不新建布局。
- 当前差异：舰体builtInHullMods为空，共享反应堆初始化、消费与提示都在双系统实现中。移入独立舰体规则，继续使用ShipSystem的权威charges与恢复计时，不增第二个储备池。

## 规则（首版待验证数值，非SC2原值）

- 旗舰反应堆：内置0OP，100储备、3/秒；大和60、跃迁75。现有宿主系统次数/恢复/冷却舰装继续生效。创建时由插件配置已有系统储备，技能调用同一消费/互斥检查。
- 大和聚能回路：25OP；大和消耗45、基础冷却14秒（原18）；跃迁预热2.4秒（原1.2），无额外伤害/无敌。与抢修互斥。
- 战地抢修系统：25OP；所有炮与技能停火、连续6秒无盾/甲/结构受击，且非过载/排散/撤退时自动工作。每秒消耗6储备，以最大结构0.5%/秒修复，最多修至80%；本场累计最多修复20%最大结构，不修装甲、不复活。重新开火或受击立即停止并重新等待。技能优先，储备不足停止，不预扣整轮能量。
- 抢修状态属于本舰战斗生命周期，系统重置不能补回材料；新开战才刷新。显示客户端只读取权威状态文字，不执行维修。宿主网络快照是显示投影，不声称支持权威断点恢复。
- 两套新可选方案由玩家明确选择；保留原“跃迁突破”和旧存档。OP不足明确报错，不自动删玩家武器。
- 使用已有正式原版舰装图标，不用临时占位或虚构维修光圈。战斗通过原有被动插件状态区显示等待/修复/缺能/材料耗尽。

## 实施与实际验收

- `HyperionHullMods.ts` 注册三项插件，内置反应堆的apply配置已有系统储备/恢复/冷却，技能共同调用该模块的供能检查与消费。使用原有charges及计时，保留100初始储备和宿主次数/恢复修正，未建立第二个池。可选聚能只改大和消耗/冷却和跃迁实际预热。
- 抢修监听真实结构/装甲受击并使用现有护盾受击时钟；在武器/系统本帧更新之后核对发射周期、持续束和触发状态，消耗实际储备。材料以本舰实例为生命周期，不随战术系统reset刷新。权威状态经现有被动状态文本投影到HUD/Worker/LAN显示协议；不宣称显示快照可恢复权威战斗。
- 正式图标声明进资源闭包；复用原版插件列表/费用/安装限制/内置标记。提供两套显式新方案，均320/320 OP，不改原方案或用户保存内容。
- 真实页面曾出现 `Cannot access AutofireController before initialization`。定位为ShipWeaponControlSystem模块顶层从循环依赖中读取AutofireController.prototype。将原方法身份基线移到类定义所在模块末尾并冻结，调用方仅在运行时读取；没有关闭原生火控安全判断。定向测试确认替换preAim仍会退出原生快路径，恢复原方法后重新通过。
- 最终类型检查、限定改动文件oxlint通过。既有 `scripts/check-hyperion.mjs` 共24项通过，包含17项已有技能/军械/几何回归、6项插件组合场景和1项火控身份回归。此前测试夹具中的不支持零charges、错误舰型费用断言及诊断快照/生产显示快照混用已纠正，未修改全局规则迁就测试。
- 实际隔离无头页面 `scripts/check-hyperion-browser.mjs --hullmods` 通过：两种方案的内置显示、25OP费用、互斥、卸下/重装、图标加载、真实Worker和暂停。聚能大和发射后56/100（45消耗后已有1点恢复），进入14秒冷却；抢修方案在Worker显示真实安装项和材料/结构上限状态。页面错误与资源失败为空。
