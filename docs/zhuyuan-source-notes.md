# 烛渊原创装备组 — 接入与验证记录（2026-09-25）

## 使用

打开 Web 版 **舰船设计**，在舰船列表搜索 **烛渊**。默认配装为三门 **缝星针**、五门小型点防御武器和 **日蚀协议**。点击「舰船技能」可查看技能图标、效果和按键；默认第一技能槽使用 F，若用户改过快捷键，以界面显示为准。点击「模拟战斗」使用当前配装。

这是用户授权的 Web 原创扩展，不替换原版舰船、不修改存档，也未发布、提交或打包生涯内容。

## 原版证据 → 扩展边界

- 本机 `../starsector-core/starsector.log:1`：Starsector 0.98a-RC8。
- 前期查阅 `../starsector-core/data/hulls/aurora.ship` 对照精灵中心、挂点、引擎和碰撞数据结构；临时版本借用了极光。**现已完全替换舰体美术及几何，不再使用极光碰撞/挂点/喷口。**
- `../starsector-core/data/shipsystems/scripts/HighEnergyFocusStats.java` 的 `apply/unapply` 和 `ship_systems.csv` 的 `highenergyfocus`：能量伤害按系统阶段强度改变、结束恢复。日蚀协议复用 Web 生命周期，但数值和代价是原创，不修改原版高能聚焦。
- `WeaponSpec.refireDelay` 与 `ShipWeaponControlSystem`：完整周期为蓄力 + (连发数-1)×连发间隔 + 冷却；缝星针是 0.25 + 2×0.09 + 1.8 = 2.23 秒。三根炮管按发射序号轮换枪口。
- 保留现有改装、武器选择、技能槽、模拟战斗操作。新增可选技能图标字段；无此字段的原版技能保持原布局。图标是静态本地定义元数据，不新增网络快照字段。
- 原版实机/原版截图状态本次未验证；不操作用户桌面。此包是原创而非声称原版等价的移植。

## 原创玩法

| 项目 | 规格 |
| --- | --- |
| 烛渊 | 棱镜巡洋舰，35 DP，160 OP，11000 结构、850 装甲、15000 幅能、850 耗散、85 航速 |
| 挂点 | 3 中型能量 + 5 小型能量；默认武器均消耗 OP 且可卸下 |
| 缝星针 | 中型能量，18 OP，900 射程，三连发；每发 220 能量伤害、120 EMP、240 幅能，弹速 1450 |
| 日蚀协议 | 专属主动技能；0.4 秒启动 / 5 秒持续 / 0.6 秒退出 / 16 秒冷却；启动产生容量 6% 的硬幅能 |
| 增益 | 能量伤害 +25%～100%，随当前总幅能在 0%～75% 间线性提升；满强度能量弹速 +60%、射程 +20% |
| 代价 | 满强度航速 -35%、耗散 -50%、护盾承伤 +30%；所有加减益随阶段淡入淡出 |

EMP 不穿盾且不随技能增幅；实弹/导弹不享受增伤。允许主动排散，不清除硬幅能、不解除过载、不提供无敌。技能 AI 在有射击窗口、总幅能为 20%～65% 时考虑启用；撤退/航点与过高幅能不主动冒险。技能不可装备到其它舰体，改装后的烛渊通过稳定 `sourceHullId` 保留资格。

## Worker 接入审查

首次浏览器运行暴露了纯原创技能未获准进行显示投影的问题（并非战斗数值测试失败）。注册表现在仅将已审查的日蚀协议**确切定义对象**加入 stat-only 纯读取集合：其 modifiers 仅读取阶段、强度和 owner 当前幅能，返回新的数值对象，没有副作用或隐藏状态。外部扩展不会自动获准；原版 AI 预阶段集合不变。依赖实时幅能的日蚀协议明确不进入 OwnedNativeSystemModifiers 的仅生命周期缓存。回归验证包含投影许可、禁止错误缓存和同一技能强度下不同幅能导致不同增伤。

原创中文文本独立注册，避免已有原版注册流程的英文 fallback 让中文条目被跳过。HUD 对尚未解析的方案名称键使用定义内显示字符串，但保留玩家已命名舰船的名称。
