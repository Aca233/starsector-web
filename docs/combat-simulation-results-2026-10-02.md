# 战斗模拟底层改造结果（2026-10-02）

已落地共享观察阶段、每炮位批量瞄准、预瞄准范围索引和避碰扫描内运动属性复用。重型联机仍未通过，不能将此报告当成 60Hz 或完整战斗交付。

## 根因和实际改动

瓶颈是大量 AI/炮位各自遍历世界，再重复调用组合技能、运动属性、射程和炮口读取；旧优化通过全对象身份/纯度资格来准入，多技能和模块舰经常落回昂贵路径。避碰扫描甚至对每个障碍物重新计算观察者自己的运动属性。它们形成大串行工作量，单独增加线程只能转移其中很小一部分。当前证据不支持用数据库解决这个计算瓶颈。

- 可见性和电子战更新后，权威端捕获一次武器数字数据；所有根舰/模块预测读取同一阶段。
- 每舰发射前批次复用目标资格与友舰列表；每炮位寻敌扫描复用射程、弹速和炮口。
- 预瞄准使用保守范围索引和提前范围剔除；避碰扫描只读取一次自己的运动属性。实际射界、接触、友军阻挡、弹药和载荷检查仍实时执行。
- 纯武器预测能分给 4 个常驻 Worker；模块和组合技能无需旧 AI owners 资格。完整分区成功后才安装结果，故障在同一观察阶段串行回退。取消的半步引擎不能复用。

默认启用共享阶段和批量瞄准。`VITE_COMBAT_THREAT_PHASE=false` 回退旧查询；`VITE_COMBAT_BATCHED_AIM=false` 单独回退批量瞄准。预测 Worker 以 `VITE_COMBAT_THREAT_WORKERS=true` 开启，默认关闭：预测内核占比小，早期测量未证明稳定额外收益。单人入口使用共享同步阶段，单人 Worker 尚未接入新的预测池。

本阶段允许 AI 武器预测最多晚一个物理步观察其他 AI 的技能/排散变化；实际弹丸、光束保持实时，开始排散前通过源码中的实时完整威胁复查。没有降低物理频率、放宽过载/网络门禁或修改 UI。

## 整步测量

复用现有 LAN 三舰场景：2 人类 + 20 AI、seed917、3200DP，真实预设装配。初始 176 实体/734 炮位，结束 168 实体/92 弹丸。每臂预热 150 步、测量 120 步，合计仅 4.5 秒模拟时间；Node 数值运行不含渲染、墙钟调度和网络。

最终冻结 bundle 的六臂对照为：

| 顺序 | 路径 | 整步均值 ms |
| --- | --- | ---: |
| A0 | 旧 live 查询 | 141.45 |
| B1 | 新共享同步阶段 | 50.56 |
| C2 | 新阶段 + 4 Worker | 46.82 |
| C3 | 新阶段 + 4 Worker | 47.46 |
| B4 | 新共享同步阶段 | 48.29 |
| A5 | 旧 live 查询 | 149.79 |

邻近 A/B 配对耗时减少 64.3% 和 67.8%，吞吐量约 2.8–3.1 倍。新同步路径仍高于 60Hz 的 16.67ms 预算。此前只有武器预测阶段的首轮没有稳定总收益，加入最初批量瞄准后的第二轮减少约 17–19%；全部原始结果保留。各轮绝对基线发生变化，不能拿跨轮绝对值当严格配对，也不能将总收益归给四线程。

最终六臂的短场景统计相同：双方伤害约 20236.73 / 18580.11、开火 239 / 244、命中均 175、各损失 4 架战机。这只证明此短场景效果一致，不证明长期战斗平衡或所有技能的原版等价。

## 验证与未完成

- 项目 `typecheck` 通过；17 个改动文件使用项目已有 oxlint 检查通过。误用 ESLint 时因项目没有该配置失败，随后改用已有 oxlint；没有增加项目依赖或配置。
- 同一静态场景的威胁数量、ETA、伤害、类型和方向与旧路径在数值容差内一致；观察阶段不受随后弹药写入影响，下阶段可见变化。
- 新同步与真实 4 Worker 路径在 standard / large-battle-v3、技能激活及高载荷场景下，完整战斗快照和随机流对照通过。两条测量臂均完成 269 个并行阶段、零回退。
- 实际弹丸/光束状态改变仍被实时读取；非法分区不能覆盖已有结果。实际终止一个 Worker 后，超时串行回退与同步完整状态相同，恰好提交一个 tick；取消/重建也通过检查。
- **最新真实双客户端 headless Edge 验收仍失败**：176 实体进入战场，诊断记录约 62–65ms 模拟步、27–29ms 快照捕获，客户端在 tick15 后未进入可操作测量窗口，主机持续过载中断。因此 20 秒稳定联机、输入延迟、ACK 暂停/恢复与重连验收均未完成。此项使用 Vite 开发入口，不是生产包性能结论。两个客户端的浏览器、辅助连接和临时 relay 已关闭，cleanupCompleted=true。另有一条未定位 URL 的资源 404，不能认定它造成过载。

剩余耗时：最终 Node 分段约 11ms 根舰 AI、24ms 舰船/武器阶段、6–7ms 战机/无人机，其余物理与特效等共同占用预算。需要继续拆分火控和导航的数值计算域；单纯打开已完成的武器预测并行不足以填补剩余预算。真实联机还要同时纳入快照捕获和冷启动成本，不能用 Node 整步数据替代。
