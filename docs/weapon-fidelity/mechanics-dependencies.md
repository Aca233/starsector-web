## Guardrail

`visualSpawnType` is not a second simulation spawn type. It only selects renderer treatment and visual-family defaults. Likewise, `beamVisualMode`, `hitGlowBrightenDuration`, deterministic Beam contact cadence, launcher smoke, missile engine/trail fields, `missileExplosionVisualSpec`, independent hit-glow state, and impact presentation profiles do not own simulation. The mechanics-fidelity pass is separately authorized to change actual gameplay fields when backed by the source CSV/config/Java data recorded above. Missile top-level visual explosion radius/color still must never overwrite gameplay explosion/core/fuse/collision radii. Reaper remains unguided; Heavy Blaster's real simulation spawn contract is now source RAY-style; Sabot's MIRV stage is simulation-owned rather than inferred from its visual profile.
