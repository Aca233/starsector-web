# 火控范围筛选与查询属性表结果（2026-10-02）

本轮已完成用户同意的火控空间筛选和查询阶段属性表。增量收益小，重型真实联机仍过载，不能宣称 60Hz 或整套游戏性能问题已解决。

## 实现

- 将上一轮 preAim 的保守范围索引提取为通用 AcquisitionRangeIndex，正式 aim 和近防导弹获取也能使用。保留原目标顺序，无候选数量截断，最终角色、截获、射界、接触和开火检查仍执行。密集窗口或不合法数值回退原列表。
- 一次运动查询只合并一次完整技能属性；每舰发射前瞄准批次复用同一射手的射程/弹速修饰；武器预测捕获和舰队 readiness 的单船扫描也复用一次修饰表。
- 表不跨 tick、AI 激活、舰船推进或发射阶段保存。实际逐炮位发射的载荷和伤害增益仍实时读取，日蚀等随当前载荷变化的增益没有被整帧冻结。
- 组合系统仍可使用表；相关单项 getter 被覆盖或系统类被替换时，回退扩展的原标量读取。没有增加技能 ID 白名单。

默认启用本轮两项。`VITE_COMBAT_STAT_TABLE=false` 回退属性表；`VITE_COMBAT_ACQUISITION_INDEX=false` 回退本轮正式 aim/导弹索引（保留上一轮 preAim 筛选）。没有新增玩家界面或改变模拟频率。

## 测量

基线是上一轮已经启用共享阶段、批量瞄准和 preAim 筛选的代码，**不是最初昂贵的 live 查询**。测试配置 `THREAT_QUERY_COMPARE=true`，原始 JSON 的 mode=live 在此次表示这个基线。

复用 2 人类 + 20 AI、三舰真实预设、seed917、3200DP 的现有场景。初始 176 实体/734 炮位；每臂预热 150 步、测量 120 步，合计 4.5 秒模拟时间。Node 测量不含渲染、网络和墙钟调度。

## 验证与限制

- 全项目 typecheck 和 12 个改动代码/脚本文件的项目 oxlint 通过。
- 标量与表读取的运动、武器射程/弹速一致；确认一次运动查询只执行一次组合读取。载荷变化、父舰失效后重新查询能看到新结果；相关标量方法被覆盖时回退 live getter。
- 以实际 solveWeaponAim 作为截获检查，验证导弹、光束与大护盾候选没有漏掉合法截获，选中结果保留原顺序；非有限输入回退全列表。
- 现有静态威胁、阶段后弹药变化、取消/新 epoch 检查通过。standard 与 large-battle-v3、技能激活/高载荷场景下，基线、本轮同步、本轮真实 4 Worker 的完整快照和随机流对照通过。预测池仍为原来的可选功能，本轮没有把整个火控并行化。
- 浏览器复查仍未进入 20 秒可操作测量窗口：176 实体、2 个真实 LAN 客户端进入战场后，诊断记录约 63–65ms 模拟步、28–32ms/次快照捕获、15ms/次编码，在 tick15 后中断为主机持续过载。因此稳定联机、输入延迟、ACK 暂停/恢复和重连验收仍未完成。Vite 开发入口不代表生产包性能。
- 浏览器仅复查一次；随后审阅补上标量覆盖回退，集中复查对应逻辑和整步，不重新跑未改变的重载联机。最终报告明确区分该浏览器测试修订与补丁后的最终 bundle。
- 原来的资源 404 此次定位为测试页面的 `/favicon.ico`；保留日志，没有隐藏错误或改过载门禁。所有临时浏览器、辅助连接、relay 均已关闭，cleanupCompleted=true。

剩余主要成本仍需通过火控/导航的数值计算阶段与快照数据布局处理，继续加小型缓存难以补齐 16.67ms/步预算。本輪不包含后续导航并行、战机批量决策或快照重构。
