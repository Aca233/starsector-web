# Starsector Web v0.2.10

本次正式发布汇总当前全部非生涯模式改动。生涯模式源码、入口、服务、专用工具及新资源继续排除；保留 v0.2.8 的发布范围门禁与 Windows 换行兼容修复。

## 模拟与 AI
- 默认启用分时 20Hz 战术决策：降低目标/站位规划开销，保留每个物理步的即时威胁、防御、碰撞规避和操控；物理仍为 60Hz。
- 默认启用自适应在途火力评分：健康且在途火力较少的目标跳过精确过量伤害预测，残血/大齐射/自定义规则保留完整路径。该策略可能在其他战况下多发射少量炮弹，不承诺所有转火行为完全等价。
- 复用武器静态射程项和战术站位的同段射线计算。
- 在已启用 20Hz 战术 AI 的 22 舰短场景中，自适应评分使整帧模拟 P50 从 7.67/8.17ms 降至 6.83/7.18ms（3/5 席，约 11%–12%）；这些是限定场景本地结果，不是公网延迟或通用帧率承诺。

## 联机
- 保留仅用于权威模拟的武器字段裁剪，减少客户端不需要的数据捕获与还原。
- 默认使用普通精确字节增量，避免运动参考压缩在两端重复扫描整份基准的 CPU 开销；仍可显式启用参考编码。
- 固定显示记录、记录增量、全组件复制等实验代码保留为可选项，正式版不默认启用未证明收益的实验路径。
- 更新还原布局、诊断/测试和主客机性能基准工具。

## 兼容与发行
- 联机协议为 **29**，主机、客机及中继须统一升级。
- Windows 浏览器便携版、Steam 便携版、桌面安装版由同一提交构建；GitHub Pages 同步更新无生涯模式的 Web 版。
- 发布仍须通过范围检查、lint、网络/native 和 Steam 门禁；未通过不得自动替换稳定版。

## 发布修复
- 更新客户端测试夹具，分别覆盖默认关闭与显式开启的运动参考压缩。v0.2.9 被旧测试预期阻止，未发布正式安装包；本版不覆盖旧标签、不跳过门禁。
