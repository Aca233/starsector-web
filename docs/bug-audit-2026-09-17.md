# 项目缺陷审查与修复（2026-09-17）

## 范围

检查单机操作与部署边界、共享玩家控制、联机输入传输/主机执行、Worker 实验入口、战斗状态展示，并执行代表性实战回归。保留工作区已有改动；不新增测试文件或测试运行器，不做资源哈希/大小审计。

## 已复现并修复

### 1. 预设鼠标坐标和失焦后的旧瞄点继续转向

- 默认鼠标转向开启后，输入层仅清空按键和射击标记，不撤销旧鼠标瞄点。下一逻辑帧又执行鼠标转向；开局尚未发生真实鼠标输入也会朝预设坐标转向。
- 修复前，直接运行实际 useCombatInput/useCombatLoop 的内存复现中：首次进入、窗口失焦、UI 阻挡三种情况的 turnInput 都是 -1；修复后都是 0，真实鼠标移动仍产生正常转向。
- 新增独立的指针有效标记，贯穿单机、共享控制器和 Worker 实验入口；菜单、部署、地图、输入框、失焦/隐藏和鼠标离开战斗区域撤销相应输入。模拟继续运行时，手动控制的逻辑步也校验输入所有权。
- 指针失效不改变键位设置：默认 A/D 仍横移，Shift 临时键盘转向，Q/E 始终横移；Space 暂停不因清空按键而丢弃仍有效的瞄点。自动驾驶不被手动输入门禁代替。

### 2. 联机中立输入无法表达“不再跟随鼠标”

- 客户端打开菜单/失焦会发送零按键、不开火的数据，但主机看到新的序号便继续执行默认鼠标转向，且客户端持续发送旧瞄点。
- 协议 v9 增加必需布尔字段 pointerActive，服务端校验并转发。客户端阻挡操作时发送中立数据并丢弃未发送的旧动作；主机同时检查输入时效和指针有效性。不把失效指针误当作切换键盘转向模式。
- 旧协议客户端明确拒绝，避免新旧输入语义混用。旧联机后台需要重启，所有页面需要刷新；本次没有重启此前被执行环境阻止清理的用户服务。

### 3. 联机结算的结构上限忽略实际舰体加成

- 结算读取 spec.hitpoints，而实际最大结构来自 maxHullHp。加固舰体攻势可显示 28000 / 20000。
- 改为双方均读取实际 maxHullHp，显示与战斗逻辑一致。
