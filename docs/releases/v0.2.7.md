# Starsector Web v0.2.7

本次正式发布仅包含战斗、舰船配置、局域网和 Steam 联机；生涯模式源码、页面入口、服务和测试不纳入此次提交或发行包。

## 主要内容
- 合入本次发布快照内全部非生涯模式改动：战斗模拟、AI、渲染/HUD、本地战斗 Worker、保存点及联机诊断。
- 保留已采用的数值块编码、装甲缓存、快照处理和可靠传输改进；保持 60Hz、ACK/流控及完整恢复规则。
- 全组件增量复制原型及写入插桩仅保留为可选实验，**正式发布默认关闭**。该原型的离线性能出现回退，不将它描述为已实现的加速。
- Worker 产物使用 ES modules，支持当前本地战斗 Worker 的分块依赖。

## 联机兼容
- 本版协议版本为 27；联机各端和中继须统一版本。
- 离线处理性能不等于网络 RTT，本次不承诺降低公网 ping。

## 发行范围
- Windows 浏览器便携版、Steam 便携版、桌面安装版由同一提交构建。
- GitHub Pages 构建同样不含生涯入口。
- 发布流程保留范围检查、lint、网络/native 和 Steam 门禁；失败不得自动替换稳定版。
