# 星舰工坊 / Starship Foundry v0.2.12

版本准备日期：2026-09-30。Windows x64。正式发布以全部发布检查通过为准。

## 本次更新

- 产品正式更名为「星舰工坊 / Starship Foundry」。应用标题、安装器、桌面快捷方式及发布文件启用新名称，旧用户数据与更新地址继续兼容。更名不构成任何第三方授权声明。

- 更新原创舰船、模块、四档军械及配装内容；旧版亚顿之矛和旧军械退出运行目录，保留现有方案库的迁移与备份处理。
- 更新共享 UI、战斗 HUD 和原创美术资源，移除已淘汰或不再引用的旧资源，并阻止旧导入器重新混入资源。仍有明确保留的原版素材，不宣称整体版权/EULA 合规完成。
- 改进战斗模拟、AI 热路径和联机快照的捕获、编码、传输与显示流水线。性能测量的具体边界见仓库对应 source-notes/performance 文档，不承诺任意设备或公网环境的统一收益。
- 增加桌面内容级增量更新：复用未变化文件，校验下载内容，提供明确的重启激活及启动失败回退。

## 下载与兼容性

- 桌面安装版：`Starship-Foundry-Desktop-Setup-0.2.12-x64.exe`。
- 桌面便携版：`Starship-Foundry-Desktop-0.2.12-x64.zip`。
- 同时提供 Multiplayer 与 Steam 的 Windows x64 免安装包，以及对应更新清单。Steam 包需要正常的 Steam 环境。
- 已安装的 v0.2.11 或更早桌面客户端需要先完成一次完整安装版升级，才具备新的内容级增量更新通道；ZIP/开发运行不自动更新。
- 本发行目录明确排除未完成的生涯模式源码、入口、专用脚本及专用资源。生涯仍为开发内容，不包含在本次发行包中。
- 保留现有原版游戏安装和玩家存档，不执行存档清理。

## 发布检查

正式发布由 Windows release 工作流完成：发行范围、类型/构建、lint、网络诊断、共享捕获、Steam 传输和桌面增量更新检查；Steam 检查失败时保留草稿，不覆盖最新稳定更新。
