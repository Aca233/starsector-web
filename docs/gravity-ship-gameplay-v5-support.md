# 万有引力号 · 引力辅助实验舰方案 v5

> 用户最新要求允许抓友舰、弹体和静态障碍，并将右键改为本舰中心全向排斥。当前方案见 `gravity-ship-gameplay-v6.md`；本页不再作为最新操作规格。

日期：2026-09-30。用户确定定位：本舰主打引力，偏向辅助，是一艘实验舰。保留原B主体、场驱动尾段与无盾边界。下述为修订推荐设计，尚未实装或通过试玩；不能把既有v3规则检查当成本稿验收。

## 定位与核心收益

舰队中的引力场实验平台。玩家用引力创造己方射击窗口、干扰敌方掠袭路线、推开追兵并改变实体弹幕的路线。衡量价值的是队友获得的射线与撤退空间、敌人被迫改变的路线、实际避免的命中及幅能代价，不以本舰伤害排名为中心。

v4把左键交给质量主炮，与辅助实验舰的定位有偏差。本稿左键使用引力操纵专武，副炮只负责自卫和验证场耦合，不靠一组强力自动炮偷偷把船做成输出舰。

## 四键与武器联动

| 操作 | 推荐能力 | 玩家职责 |
| --- | --- | --- |
| 左键按住 | 矢量牵引器：持续对准敌舰后建立单目标连接，移动有限速锚点 | 精确改变一艘敌舰的路线或保护位置；松开保留实际动量 |
| F按一下 | 在按键时准星位置部署固定区域引力锚；再按安静收回 | 改变一片区域的运动趋势，预先选择进攻或救援位置 |
| G按一下 | 从既有F锚向外传播一次排斥波，随后锚消失 | 将持续吸引转换为一次释放；根据目标在锚的哪一侧决定推送方向 |
| 右键按一下 | 定向弹幕分流：向准星方向投射短时引力分流带 | 将来袭实体弹向两侧拨开，为本舰或队友争取开火/撤退窗口 |

左键仍是宿主武器组的普通开火输入，默认第1组装牵引器；切换到自卫武器组可以正常射击，不劫持其他武器。F/G复用可重绑系统槽，WASD、转向、V及自动开火沿用宿主。

### 左键：精调一艘

- 捕获要求短暂持续对准、真实炮口距离与射界成立，前方舰体/障碍会阻断。建立后锁定目标，不因鼠标划过其他船自动换抓。
- 捕获锚点从目标当前位置起步，按有限速度向准星移动；实际力按偏离量、相对运动与整舰质量计算并封顶。鼠标操作锚点，不能直接写目标位置。
- 敌人仍可推进、转向、开盾；牵引无直接HP伤害，不附带缴械、强制关盾或碰撞爆炸。重舰反应较小，模块不被扯散。
- 持有时间、恢复时间与持续幅能约束占空比。超距、出射界、遮挡、目标相位、过载/排散或失效立即释放；中断后先松键再捕获，避免按住自动反复抓取。
- 不抓友舰、弹体或静态障碍。救援通过移开威胁实现，不未经队友操作把其拖离原位。

### F：粗调一片

- 固定锚持续吸引多艘敌舰与支持的实体敌弹，中心柔化，按质量与总预算限制；不强制聚成一点，不归零速度。
- 拉偏掠袭路线、让护卫离开保护位置、把追兵留在侧面，是主要辅助用途。正放可能把危险敌舰拉近队友，侧放与及时收回更有价值。
- 源维持距离、持续时间和幅能有边界。收场后保留已产生的惯性，不能免费拖动整个区域。
- 与左键共用一个准星。需要在另一处部署F时先松开左键；目标保留动量，再用同一准星布场。没有隐藏第二指针或自动冻结拖锚功能。

### G：从布场位置释放

- 必须有可用的F锚；没有锚时明确显示不可用。G从远处锚点产生有传播时间的径向排斥波，不是本舰中心爆发或远程伤害炸弹。
- 目标位于锚哪一侧，决定被推向哪里。左键先把一艘敌舰引导到合适一侧，松手，再G，可以拆开阵型或把追兵推离队友。
- 成功G停止本舰当前牵引，要求松左键后才能重抓，避免牵引与释放机械对抗；失败G保留锚与连接，不消费。
- 每对象每波至多一次冲量，敌舰、敌弹及明确兼容的试验质量弹都有预算。源失效停止尚未传播的波前，已获动量不回滚。
- G结束持续控场，因此继续牵引/F维持与立即释放各有收益；不能不停吸推形成无限控制。

### 右键：定向弹幕分流

用户指出仅用右键换支援位置缺少价值；右键改为直接干预攻击路线的实验装置，取消主动滑移及其储备。普通移动继续沿用宿主。

- 按下时采样舰心至准星方向和投射点，在有效距离内形成一道短时引力分流带。带的长轴垂直投射方向；不是全舰常驻圆罩。投射有真实建立时间、距离及遮挡限制，不隔墙保护。
- 分流带对进入其中的支持实体敌弹施加沿带长轴、远离中点的有限侧向力，将弹幕向两侧分开。中线对象使用稳定规则选择侧向，不依靠每帧随机方向。
- 它改变实际速度和后续弹道，不吸收伤害、不删除炮弹、不改阵营、不保证反射回敌人。友舰和友弹豁免，队友可以继续向外射击。
- 可以布在本舰前方自卫，也可以布在队友受攻击的方向，争取短暂排散或撤离窗口。弹体只是被拨开，两侧仍可能危险，不自动保证场边其他友舰安全。
- 每弹每次分流有累计侧向冲量上限，同时限制处理数量与总动量预算。高动量弹、密集齐射可以突破，制导弹可重新追踪；光束不受影响。
- 接受后位置/朝向固定，短时自动执行，不需要持续按右键，也不随准星免费扫动。玩家可以再操作左键或F；布到另一方向要等下一次可用。
- 试验起点：约900投射距离、约400带长、约100带宽、约0.1–0.2s建立、约1s有效、约6–8s恢复、约500–650启动软幅能；都是待标定初值，不是已验证防护强度。
- 不取消F或牵引，失败不扣费；死亡、撤退、过载/排散、系统离线或脱离维持距离中断。F/G/分流的受力共用对象级上限，不能通过叠场形成无限拦截。

## 实验装备分工

挂点数量仍暂沿用1L、4M、6S、0XL草案；安装位置、OP、射界与预算尚未冻结。不能据此宣称合法配装已经完成。

- **1L内置矢量牵引器**：主实验装置，绑定且可转动，承担左键操作。它的价值是控制能力而非伤害；部署成本需要计入控制收益。
- **4M可换标定质量炮**：低频、适度自卫输出，发射可测量的实体质量弹。弹体可通过自己的F有限借场、通过G按真实接触获得推送；不追求主炮爆发，不因“实验”无限增伤。自动火控瞄准敌人的真实状态，不瞄准空锚心；基础直射应可靠。
- **6S偏轨/常规近防**：分工处理支持的实体炮弹、可拦截导弹与战机。偏轨有射界、处理次数与总动量预算，光束不受影响，导弹可能重新追踪，密集齐射可穿透处理能力。

推荐两种支援取向：拆阵配置保留更多常规PD，便于进入较近牵引距离；护航配置增加偏轨阵列，较侧重实体炮雨，但对跟踪导弹/战机的击毁能力下降。OP与实际配装编译待验。不额外堆必装插件、伤害标记或新能量条。

普通友舰与友弹豁免。首版仅自己的明确兼容标定弹借场；队友炮弹没有真实兼容协议前，不宣称可以自动校准或加速全部友军炮火，避免把队友的正常命中拉偏。辅助收益首先来自敌人的位置、敌弹的路线和队友得到的空间。

## 实际支援路线

1. **拆开护卫**：左键将护卫拉向队形侧面 → 松手 → F布在它另一侧 → G沿合适方向释放，给队友打开射线。也可以不G，让侧置F继续牵制。
2. **掩护撤退**：右键先在队友受攻击方向分开一轮实体弹幕 → F预放在追兵侧面 → 左键阻滞最危险的一艘 → 松手后G推离追兵，争取撤离时间。右键和G都有建立/传播时间，不保证临时施放来得及挡贴脸重弹。
3. **切断掠袭**：F偏置干扰高速目标 → 左键顺其原运动趋势加横向偏移 → 在合适位置释放，保留侧向动量，让它错过攻击路线；不必先刹停再硬拽回来。
4. **争取开火窗口**：右键对准正在承受实体弹齐射的友军方向分流 → 左键/F干扰对面护卫站位 → 队友继续向外射击。收益是短时减少迎面压力，不直接给友军伤害倍率或保证免伤。
5. **验证弹弓**：标定弹经过自己的锚 → 选择G释放时机，改变弹体到达角度/时间。属于可选实验技巧；队友仍是主要火力来源，支援不依赖每次曲射。

## 实验舰的性格与代价

实验性体现在设备需要布置、校准、持续维持与有限释放，而非随机炸机或无提示失灵。主动装置强，舰体直接作战能力克制；支援范围、牵引射界、持续占空比与幅能决定操作风险。

首轮试验可沿用左键约0.2–0.3s捕获、约2–3s持有与恢复限制；F/G从v4试验区间重新标定，右键采用本页分流带初值。牵引的持续费用加入后必须重新核算并行消耗，不能直接把所有旧数值相加就算平衡。

弱点明确：高质量/强推进目标、远程光束、绕后与分散进攻、舰体遮挡、幅能饱和、分流方向错误或预算耗尽。自然AI可使用有限计划牵引与布场，不能逐弹完美躲避。所有引力来源统一限幅，模块按根舰受力，无无限控制或叠加顺序收益。

界面显示目标连接、实际可到达的拖锚点、F边界与时限、G释放方向趋势、右键分流方向/时限/恢复和预算压力。轨迹/趋势预览来自真实规则，不画“必中”线。场驱动与连接效果服从正式硬件/炮口和真实状态，不用常亮大光圈制造实验感。

## 实施与验收边界

当前只是设计稿。已有v3固定井、传播波、G保速折转与右键入口可部分复用；本稿的远程G原子释放、牵引器、右键定向分流、标定炮耦合、正式素材与完整玩家路径仍待开发。

验收以真实生产引擎/Worker中的牵引、失败保持、松键互锁、共享限幅和清理为基础，再记录自然战斗中的友舰结构损失、撤离时间、火线暴露与本舰消耗。单次伤害榜或规则探针不能证明辅助价值；未经过试玩不声称操作性、平衡与上限已经达成。
