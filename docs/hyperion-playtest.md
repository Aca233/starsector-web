# 休伯利安原型 · 试玩说明

## 打开与换装

1. 打开本地改装页 http://127.0.0.1:5173/?view=design，搜索“休伯利安”。不是原版“海波龙”。
2. 点“装配方案”，选“雷诺旗舰 · 跃迁突破”，确认。**旧存档不会被强制替换**，旧方案仍可能是之前的原版武器。
3. 预设包含4大、8中、12小槽的主题武器，以及50耗散/20电容，310/320 OP。每一门都可拆换；大和炮独立于普通挂点。
4. 点“模拟战斗”，在部署界面选择敌舰并开始；Tab切换战术地图/驾驶视图。F/G在驾驶视图使用，战术地图里的G另有部署功能。

## 专属舰船插件（2026-09-28）

保存当前配装后刷新页面，重新进入模拟战斗以重建Worker。内置旗舰反应堆自动来自舰体定义；旧存档不强装可选插件。

- **旗舰反应堆**：内置0OP，100点共享储备、3点/秒恢复。大和基础60点、跃迁75点，不额外叠一份储备/恢复。
- **大和聚能回路**：25OP，大和消耗45点、基础冷却14秒，代价是跃迁预热延长到2.4秒；不增加单发伤害。
- **战地抢修系统**：25OP。全部武器与技能停火且连续6秒无盾/甲/结构受击后自动抢修，每秒花6储备修0.5%最大结构，最多修至80%；整场材料累计只可修20%最大结构。开火或受击中断，缺能暂停；不修甲、不复活。
- 两种可选插件互斥。安装入口为“安装舰船插件”→搜索“休伯利安”。有OP成本，手动装入旧方案时若预算不足需自行调整；不会擅自删武器。
- 快速试玩：在“装配方案”明确选择 **雷诺旗舰 · 大和压制** 或 **雷诺旗舰 · 战地续航**。两套均24门炮、50耗散/5电容，320/320 OP；原“跃迁突破”的50耗散/20电容保持不变。
- 抢修不另占主动技能键。想修船时先关闭各组自动开火（包括近防），不按主火力/技能，撤出交火但不要下达离场撤退；左下插件状态显示等待、维修、缺能、80%上限或材料耗尽。AI舰同样遵守这些触发条件，不因装配而获得无条件回血。

以下打法的60点/1.2秒是未装聚能回路的基础值。具体插件规则、验证和边界见[插件接入记录](hyperion-hullmods-source-notes-2026-09-28.md)。

## 两种打法，不是把所有按钮一起按

- **中距离重击**：AL连射激光持续制造硬幅能，ATA六发齐射打穿装甲薄弱处；舰艏对准后按F蓄能大和炮。大和成功发射消耗60/100储备，之后不能立即跃迁撤走。
- **跃迁切入**：按G进入选点，左键锁位置，再移动鼠标定朝向、左键确认；预热1.2秒后抵达，消耗75储备。收束后六秒“跃迁突击”强化能量火力；激光弹伤害×1.2、射速×1.5，但每发幅能×1.5，峰值幅能速率约×2.25。持续光束不提速，只改变伤害和成本。别在高幅能时盲目切入。
- 两者共享每秒恢复3点的反应堆，技能不能同时激活。预热中仍会受击；过载/排散会中止，失败不扣储备但技能照常冷却。没有相位无敌。
- ATA有24发可恢复电容储备（每秒1.5），别把齐射峰值当永久DPS；前后两组错峰开火可缓解电容耗尽。AL专攻盾，对装甲弱。小型守望者负责导弹/战机。
- 右键为普通240°前盾，Space暂停，W推进。技能也可以点HUD按钮；自定义快捷键以HUD实际标注为准。
