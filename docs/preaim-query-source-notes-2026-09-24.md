## 前置资格检查（独立实验）

整合测试发现内置 ArmorGrid.cells 为带私有身份的访问器，旧审计无条件拒绝，正常舰船从未进入 >=100 舰 batch。2026-09-22 的否决记录也存在此问题。本轮仅以私有 getter/setter 的精确身份识别原生 cells，不执行 getter、不接受包装器或任意自定义访问器；对公开 cells 的引用逃逸仍保持 cellMutationRevision=null，不把“只读查询安全”误当“护甲内容可以缓存”。资格修正会重新启用既有 batch，因此必须分开测量原实现 / 仅修正资格 / 资格+树，绝不把未启用候选的噪声当收益。
