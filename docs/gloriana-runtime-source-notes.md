## 扩展边界

这是战锤主题 Web 自定义舰，不是原版数据或原著数值还原。沿用获认可素材的九部分（核心含舰艏 + 六炮廊 + 两动力段），不退回早期十段纸面拓扑。将既有层按所有者合成为九张运行时贴图；保留透明 alpha，不按黑色抠图，不绘制新纹理。碰撞取每部分 alpha>32 最大实体轮廓并简化，忽略装饰性透明晕光。

补漏对照：保留旧28个样例ID和已纠正的实际归属；增加中轴(512,618)、左右(369,1001)/(655,1001)、后肩(300,1070)/(726,1070)、外缘(299,1117)/(726,1117)、内缘(410,1170)/(615,1170)，共9个，合计37。尺寸/类型/射界是可调整的 Web 首版配装，不把门、鹰徽、散热片或尖塔都当武器座。

首版使用原有武器独立安装、标准全舰核心护盾和机动喷口系统。未声称旧稿的自定义战列敕令、供弹网络、动力模块损失联动、统一手动齐射已实现。模块独立 AI 火控；不新增专属技能以掩盖未实现逻辑。
