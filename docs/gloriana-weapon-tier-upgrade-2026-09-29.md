# 女王号舰载军械升档 · 2026-09-29

## 范围

用户要求按武器实物尺度，把女王号全部舰载武器统一升一个安装档位。
这是 Web 自定义内容调整；XL 是 Web 扩展，不是原版第四档。
不改变舰载机自身武器，不改变其它舰船的挂点，不重新生成或缩放图片。

| 裁决重型光矛 | L | XL |

九段舰体的48个挂点同步升档：14 XL、14 L、20 M；核心12槽为2 XL、4 L、6 M。
槽ID与武器ID不变，历史L/M/S前缀仅为存档键，不再代表当前档位。
M12/M13仍为通用类型，当前尺寸是L。继续严格执行同档换装。

## 保持的内容

- 贴图、安装位置、炮口、转动方式、射界不变。
- 六件武器的伤害、射程、幅能、射速、弹药、OP及其它规格不变，仅档位和相关说明变化。
- 军械统合主炮判定随升档变为XL实弹/能量；宏炮与光矛仍受益，攻城炮不会因升到L而意外获得主炮加成。
- 两套现行完整预设核心OP均为260/260；通过本轮修改前备份的真实代码与当前代码分别编译计算，确认预算一致。历史测试中256的断言并非本轮修改前实际值。
- 罗西南特保留6个S近防、1个M轴炮、2个M鱼雷口；两种自有M鱼雷正常换装，不能再安装女王号L鱼雷。
