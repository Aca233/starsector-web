# 武器尺寸严格对应（2026-09-27）

## 来源 → 当前差异 → 最新决定

- 本机 0.98a-RC8：decompiled/starfarer_api_source/com/fs/starfarer/api/combat/WeaponAPI.java:65–68 只有 SMALL / MEDIUM / LARGE；starsector-core/data/weapons/hellbore.wpn:5 声明 LARGE。EXTRA_LARGE 为 Web 扩展。
- 修改前 Web 的 WeaponSizes.weaponFitsSlotSize 使用尺寸排名 <=，允许大槽装小炮。本次用户明确选择取消此行为，不宣称这是原版规则。
- 用户澄清“大槽装大槽武器那种”：S→S、M→M、L→L、XL→XL。保留同尺寸武器之间的换装、实弹/能量/导弹等类型约束、OP与内置限制；不绑定单个武器 ID、不改为免费内置炮。
- 原版当前实机界面未核实，不操作用户桌面。保留既有选炮面板结构，在已有尺寸筛选中禁用其他档并明确提示只接受同尺寸。
