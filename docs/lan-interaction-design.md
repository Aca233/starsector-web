# 联机操作与界面规范

状态（2026-09-17）：主要操作链路已落地，当前协议 v11。已实现左侧真人 / 缩略图 + 中央自己的原生改装台、选船弹窗、固定底栏、显式应用与服务器回执门禁、失败 / 房间关闭保留草稿。他人配装只读，AI 独立手动管理。入口现已简化为统一玩家名称和创建 / 加入表单；移除大船预览、参数与重复改装入口。阻塞提示和键盘规则仍持续完善；本文不是全部功能完成清单。
适用范围：联机入口、房间、选船改装、AI 编成、战斗与战后返回。沿用当前原生画风和共用组件，不新增“对战 / 合作”模式。

## 一、整体结构

主菜单 → 联机入口 → 房间 → 战斗 → 结算 → 原房间。
房间即改装工作台：左侧显示真人及已应用舰船缩略图，中间编辑自己的舰船，原生右侧配置区保留。选船弹窗、AI 编成、邀请、设置都是房间内的操作，不是必须逐页通过的向导。

基本原则：先进入房间，再安排舰船；同一状态只有一个主要提交动作；后台连接、启动与加载由系统处理，不要求玩家理解服务器步骤。

## 二、联机入口：只解决“和谁玩”

- 玩家名称只填写一次，创建和加入共用。
- 两种入口为“创建房间”和“加入朋友”，选中后只显示对应表单。
- 创建：确认名称后创建；此时才启动或复用本机后台，成功后进入房间。
- 加入：优先粘贴邀请链接；次级方式填写房主地址、房间码，必要时填写密码。
- 点击加入后自动连接并尝试入房，不要求再手动点一次“连接服务器”。邀请中带有房间码时不重复填写。
- 进入本页、切换入口和加入朋友均不得启动自己的后台。
- 不在入口常驻巨大舰船预览、舰船参数、AI 配置和房间分队说明。上次选用的配装可保留，入房后再确认。
- 创建 / 加入请求处理中禁用重复提交，显示具体阶段；失败保留名称、地址与房间码，并提供重试。
- 直达服务器或打开邀请链接也走同一套操作语义，不因为网址不同露出额外技术步骤。

## 三、房间：所有战前操作的唯一中心

| 区域 | 内容 | 操作 |
| --- | --- | --- |
| 顶部 | 房间名 / 房间码、在线人数、邀请 | 复制邀请；连接详情折叠，不常驻原始服务器状态 |
| 左侧：真人玩家 | A / B / C 等队伍、玩家名、房主标识、在线和准备状态 | 自己选择队伍；房主可调整所有人；点击其他成员只读查看配装 |
| 中间：我的旗舰 | 舰船预览、方案名、简要参数 | 点击舰船或唯一的“选船与改装”按钮，进入同页改装 |
| 右侧：战斗编成 | 各队真人旗舰数、AI 数、AI 配置入口 | 房主手动管理 AI；普通玩家只读查看 |
| 底部固定操作区 | 当前缺少的条件、准备 / 开始 | 操作位置不随内容长度变化；手机同样保持可达 |
| 次级工具 | 聊天、房间设置、帮助、离开 | 次级工具不与准备 / 开始争夺视觉重点 |

真人列表只列人，不将 AI 包装成玩家席位。房间人数上限只计算真人，包括断线保留席位。
选船、设置和聊天无需按步骤条强制依次完成；顶部展示当前位置 / 状态，而不是无法点击的假向导。

## 四、选船与改装：本地编辑，明确应用

1. 入房即编辑自己的船；左侧成员与房间连接常驻。点击他人缩略图只读查看，关闭后草稿不变。
2. “更换舰船”打开原生舰体目录，搜索 / 按舰级或势力筛选。选中只改本地草稿，带入建议配装；装备和技能沿用原生编辑器。
3. 有未应用修改时底部唯一主动作是“应用修改”；正在同步时禁用重复提交和改装；收到关联确认后主动作变为准备 / 开始。
4. 未应用、正在同步、已同步、同步失败明确区分。房间广播不代替请求回执；过期 / 无关回执不解锁主动作。默认配装若没有已提交设计，也必须先应用。
5. 修改取消自己的准备，应用重置全员准备；其他真人仍在编辑时房主不能开始。只读查看、聊天、邀请不影响准备。
6. “放弃修改”经确认恢复本页最近确认的基线；不能自动恢复准备。失败后即使恢复草稿，尚未确认同步仍须重试应用。
7. “另存方案”只追加本机副本，不覆盖单机草稿 / 基线或既有方案；保存不等于应用。已存方案 / 导入 / 导出沿用原生方案管理。
8. 拒绝 / 超时保留草稿，不自动提交。失去连接或房间关闭保留工作台，禁止应用但允许另存 / 导出；离开时对未应用草稿给出确认。

## 多队编成（v10 已实现）

房间码、编队规则与 AI 入口常驻左侧，只有真人列表内部滚动。“编队规则”内增加 C 队及更多队伍；“每人独立一队”会给真人和每艘 AI 独立阵营，并保持后续加入者独立。切回自由分队即可手动合队，不跳转新大厅。编队变动清除准备、不动配装草稿。只有末尾空队能直接移除；空队不影响开局，最后存活阵营获胜。

## 五、AI 编成：手动添加参战舰船

- 初始没有 AI，不自动填满空队或空房间。
- 房主打开“管理 AI 舰船”，先选 A / B 队，再选舰体，最后明确添加。
- 添加后显示舰名、队伍和数量，可换船 / 移除。普通成员只读查看。
- AI 不占真人席位、不需要准备，也不会替换房主旗舰。
- 当前能力边界（v11）：AI 不设固定数量上限，171 个已适配舰体的建议配装；选择队伍 → 点左侧缩略图直接加入 → 右侧直接改数量，个人战逐舰独立成队。列表滚动，不限制出战数。通信仍有 1 MiB 编成 / 16 MiB 快照字节安全预算；不等于百舰持续流畅或 AI 自定义改装已验收。
- 点击“添加”才提交；取消选船不修改编成。已提交的编成变更会取消真人准备状态。

## 六、准备和开局：让玩家知道下一步

| 当前身份 / 条件 | 主按钮或状态 |
| --- | --- |
| 客机未准备 | 准备 |
| 客机已准备 | 取消准备，并显示“等待房主开始” |
| 房主且所有条件满足 | 开始战斗；点击即确认自己的配装，不再先准备或重复确认 |
| 对面没有舰船 | 开始不可用；提示缺少哪一队，并提供“添加该队 AI”或分队入口 |
| 有其他真人未准备 | 显示未准备者姓名 |
| 有真人断线 | 显示等待谁重连；房主可在成员管理中移除，不自动剔除 |
| 正在载入 | 只显示加载阶段 / 尚未就绪的玩家，不允许重复开始或修改编成 |

开局条件保持前后端一致：至少两个敌对阵营有舰船（空队不参战），所有真人在线、没有未应用的编辑状态，非房主真人均已准备。客户端还必须收到自己的配装确认。
只有房主时，可以为对面添加 AI 后直接开局；不要求坐满房间。
改变配装、分队、AI 或容量后需要重新准备；聊天、邀请和只读查看不影响准备。

## 七、战斗、返回与键盘规则

- 战斗只保留 HUD 和菜单入口，不显示大厅的选船、准备、AI 编辑按钮。
- Esc 优先关闭最上层弹窗；在改装中处理未应用草稿；在战斗中打开菜单。不得直接离房或结束全场。
- 菜单不暂停联机。房主“结束本局”影响所有人，必须确认；客机“离开对局”只退出自己，同样确认。
- Enter 只提交当前表单 / 当前聚焦按钮，不能因为在聊天中按 Enter 而触发开战。
- 不增加一套与原有改装 / 战斗冲突的全局快捷键。按钮可键盘聚焦，并提供明显焦点状态。
- 结算主动作是“返回房间”。保留房间码、分队、旗舰配装和 AI 编成，清除准备状态。
- 下一局回到同一个房间确认，不绕回主菜单，也不让房主绕过其他人的准备直接再战。
- 离开房间与退出某个编辑页始终使用不同文案。

## 八、后续实施与验收（非全部已完成）

1. 先拆开联机入口与房间主体，统一创建 / 加入表单、名称与错误处理。
2. 再统一房间区域，合并重复选船入口，固定准备 / 开始按钮，加入可操作的阻塞提示。
3. 最后调整方案管理位置、AI 编成返回、结算和键盘 / 焦点规则。复用现有业务权限与验证，避免为界面重排重写协议。

验收至少覆盖：房主单人对 AI、两真人分队无 AI、两真人同队对 AI、粘贴邀请入房、密码错误重试、客机未准备、掉线、取消改装、载入失败、正常结束再开一局。
大屏标题不得被边框压住；窄屏主操作不在横向滚动区域之外；弹窗必须阻挡背景点击和快捷键。

### AI 编组卡（v11）

- 列表与选择预览使用本地原生舰船缩略图；加载失败显示占位文字，不显示破图。
- 自由分队以「队伍 + 舰体」归组，卡片显示缩略图、舰名和 × 数量；不同队同舰型不混在一起。
- 个人战以舰体合并显示，明确标记「独立阵营 × 数量」；服务器仍给每艘 AI 独立的 teamId，不改变敌我关系。
- 一个窗口完成操作：顶部选队和每次添加数量，左侧搜索 / 点舰船图直接加入，右侧按同舰体归组显示。数量可直接输入（Enter 或失焦提交，Esc 取消），＋/− 增减一艘。修改即时同步，不再进入编辑编组 / 选船 / 应用 / 返回等层层页面。
- 换船、删除使用次级文字入口。换船后直接点左侧新舰体替换整组；换到同队已有舰体会合并数量。删除在原卡片内确认，不打开另一个窗口；最后一艘不能用减号误删。
- 点击发送服务端原子增量消息，快速连点不会覆盖旧编成而丢失添加数量。服务端继续验证房主权限、编队规则、舰体、字节预算和开局冻结。
- 其他真人只能查看。每次成功修改仍取消准备；编队在编辑期间变化时拒绝使用旧编组草稿。

### 入房前入口收敛

- 只负责填写玩家名称、创建或加入；舰船缩略图、选船、方案导入和改装仅在房间中显示。
- 开发 / 预览页面点击创建才启动后台；加入者填写邀请链接或房主地址，只连接朋友。
- 已在服务器页面时，直接点击创建或输入房间码 / 密码加入，内部自动建立连接，不再多一次「连接服务器」。
- 已携带的方案仍随浏览器片段传递并带入房间；本地方案库不被覆盖。错误反馈留在原表单，房间关闭后仍保留改装草稿的原行为。
