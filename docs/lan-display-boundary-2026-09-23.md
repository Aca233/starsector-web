# 联机显示 / 模拟边界收尾 — 2026-09-23

## 范围和证据

本轮是架构迁移，不新增原版玩法、布局或交互。行为依据是本项目既有快照、插值、预测、HUD/地图/部署和本地显示投影的实现；护盾显示及运动方程沿用现有算法并共享纯计算函数。未进行原版实机或双客户端画面对照，不声称原版视觉等价。

此前的第一阶段仅移除了长寿命 `CombatEngine`，仍临时调用 `createLanWorld()` 并接管 `Ship` 图；**本轮已替换这一过渡方案**。

## 已完成的边界

### 1. 权威数据 → 纯联机显示世界

- `LanBattle` 的显示状态为 `LanDisplayWorld`，冷启动从首个权威帧建立；不构造 `CombatEngine`、`Ship`、`Shield`、`FluxTracker`、`ArmorGrid` 或 `ShipSystem`。
- 首帧可以处于任意 tick。舰船 ID、控制席位、舰队、预备队、模块、舰载机、静态定义、翼队和战术读数据均由权威端提供，不重放种子或依赖双方构造顺序。
- 资源清单就绪后先发送 loaded；显示资源准备与首次快照接收分开，避免客户端等待首帧、服务器等待 loaded 的死锁。控制仍须经过已有同步/ACK 流程。
- `LanShipProjection` 在权威侧列举显示/HUD/预测字段。模拟对象新增字段不会自动进入客户端船体状态。
- `LanDisplayShip` 及其组件只提供数据、缓存查询和显示数学；不具备 AI、伤害、武器发射、舰载机调度、模拟计时或权威随机源。
- 解码保留存续实体身份，先分配完整引用表再解码载机/模块/残骸引用；逐端点同步执行回调，保留增援首帧、传送、断线重置和弹体 ID 插值语义。
- 独立关键状态通道仍可更新 HP/幅能/护盾/武器标量；护盾和幅能显示读取这些最新值，而非过期的派生数值。独立弹体通道不会被无弹体的整体快照覆盖。
- 权威提供的舰名/译名仅注册显示字符串，不在客户端安装模拟设计。

### 2. 协议与旧诊断恢复分离

- `CombatSnapshot.ts` 现在只包含传输类型。
- 生产接收路径：`LanDisplayBootstrap` → `LanDisplaySnapshot` → `DisplaySnapshotCodec`。没有模拟类恢复或执行定义注册表。
- 旧模拟图捕获/恢复、组件胶囊及编码实验移到 `AuthorityCombatSnapshot.ts`，仅供权威捕获和显式诊断工具使用；其恢复 API 不在生产显示链路中。
- 新 LAN 帧使用 `displayVersion: 1`；`craftSpecs` 复用为所有舰船的去重定义表，每个主力舰/舰载机记录显式引用定义。
- 保留二进制数值块、字段字典、弹体列、粒子/爆炸配方、枪口/音频事件与既有传输信封。模拟组件胶囊、旧 fixed-display 和 record-delta 模式不用于新版生产显示帧；没有假称这些实验开关仍生效。
- 接收端检查版本、席位/房间队伍和舰队规模、身份唯一性、必要字段、定义与资源、引用、模块父链、部署名单及属性遮蔽。旧/未知显示协议明确失败，不回退到模拟对象。
- 真实传输基准使用的 `headless-battle-replica.mts` 同步改为纯显示冷启动；其它旧编码诊断显式导入旧模块。

### 3. 本地 Worker 显示编解码器

- 拆分共享 wire 类型、权威 encoder 和纯 decoder；`LocalWorkerHost` 直接导入 decoder。
- `render` 和 `render-strict` 均为纯显示协议，不再有 compatibility 模式；废弃模拟类 ID 1–9 及可执行系统定义标记均拒绝。
- 移除本地编码器针对模拟图的字段跳过名单和静默方法丢弃路径。
- `ProjectedRenderShip/System/Weapon` 位于纯渲染模块；渲染查询不再导入模拟类。权威内联路径通过窄读接口提供必要的射程读取。
- 未审计的自定义读取钩子会明确要求权威侧投影适配器；不再悄悄恢复完整模拟原型。这是明确的兼容性约束。

### 4. 预测和音频

- HUD、地图、部署、关键状态复制和预测消费者改用显式嵌套读契约，而非要求完整 Ship/CombatEngine 能力。
- 运动回放使用共享纯运动积分器和权威投影的运动参数；射程、弹速及系统武器倍率由权威计算。客户端不为预测重新求解模拟系统。
- 模拟/扩展代码改发 `CombatAudioEvents`。主线程 mixer 注册播放适配器，Worker 注册有界事件收集器；不再覆写 `SoundManager.play/playAtPos`。
- 事件复制位置数据，支持嵌套及乱序释放；AI 提案静音仅安装在对应 Worker 入口，导入 Owner 本身不会全局吞掉音频。既有回放音频抑制及队列预算保留。

## 版本要求

- LAN 协议：**29 → 30**。客户端、房主及专用服务器需使用一致版本。
- 本地 Worker 协议：**13 → 14**。不接受旧模拟原型显示包。
- 显示记录是显示拥有的可变接收缓冲，不是可恢复模拟检查点，也不是不可变历史快照。
- 权威实现和诊断工具仍合理依赖模拟类型；若干纯读接口使用 type-only Pick 保持类型一致。这不赋予显示对象模拟能力，也不代表仓库中删除了所有 CombatEngine 名称。
