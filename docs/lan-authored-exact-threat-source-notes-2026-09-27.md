# 自定义舰精确威胁复用候选（实现前，2026-09-27）

## 证据与范围

上轮176实体开场失败已保留。CPU采样显示fixedUpdate约71.9%、assessThreats约17.7%（包含关系不相加）。四种自定义技能都未进入旧nativeThreatPhaseAI集合。该门槛同时控制远期预测刷新，因此禁止直接扩大旧白名单。

本候选先接通**纯AI同步段**中的精确武器威胁统计复用，不改完整预测的刷新频率；不把缓存带过任何ship.update、状态效果/舰装advance、碰撞、武器发射或await。模块AI与ship.update交错，暂不能复用此段的缓存，必须保持原路径。这是总优化的一个已界定实现步骤，不是把总体目标缩小成只优化根舰。

当前源码审计：Eclipse.advanceAI只调用原有武器增益AI；GlorianaEdict.advanceAI只读本舰、模块和目标后激活本舰技能；Hyperion两技能advanceAI临时修改本舰准星并激活对应技能后还原准星。ShipSystem.activate只排队activation/active事件；真正跃迁、弹体、onAdvance由dispatchEvents在ship.update阶段执行。原生AI防御/排散/激活可能改变父舰统计及子模块组合属性，因此失效域必须覆盖整个父子模块/舰载机依赖组，不能只delete当前根舰。

## 不变量与资格

- 旧native门槛和compactForecast原封不动。使用独立exactWeaponThreatEnvelope字段；评估次数、horizon、时序、输入和实体集合不变。
- 只在现有私有Worker所有权、原生Engine/AI入口、已审计定义身份和已知只读伤害/射程钩子满足时启用。任意外部技能/回调仍回退；资格不是用户可声明的字符串标志。
- 同步AI段内保留敌人顺序、每武器精确ETA/浮点公式，复用的只是同一状态的range/DPS/motion/muzzle。父舰、任意模块、载机关系连通分量一起失效。段末finally关闭，异步/物理更新之后不得继续取缓存。
- 先以显式实验开关关闭默认行为；通过证据后才考虑启用。

## 预注册验证与淘汰门槛

实现完整后一次typecheck、改动lint、真实三舰/模块/载机差分合同（普通/激活/排散/模块状态/武器可变字段/外部钩子回退/段关闭/预测频率），以及同源单机受控AI段的A-B-B-A对照。逐项差分须完全一致，不以容差掩盖状态差异；四臂同一舰队、种子、调用数，不取最好一次。

AI段两对均至少降低10%墙钟时间且无任何合同失败才保留候选进入整局测试；否则记录并回退候选接线。离线段收益不是完整模拟Hz或联机延迟收益。后续必须用同176实体真实浏览器跑完整输入/停顿/重连场景才能称联机性能已改善；不能减实体/降频/延长超时取得通过。
