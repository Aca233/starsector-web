> 历史方案：2026-09-30 的无盾、右键排斥、G独立功能及全套联动重设计见 `gravity-ship-gameplay-v3.md`。本页原文保留追溯，不再作为当前操作定案。

日期：2026-09-29。状态：用户已认可核心玩法方案；截至2026-09-30，F/G与集中外力正在工程接入；完整武器联动和交互/平衡验收未完成。实际实现与证据见 gravity-ship-production.md。舰体三案选型见 gravity-ship-art-options-v1.md，候选生图不等于运行资产完成。
本稿修订v1以及后续口头的“惯性钳＋独立透镜＋质量炮”提案；保留v1作历史，不自动覆盖现有舰船或运行代码。用户已澄清“万有引力号”不必属于《三体》；舰名与本方案保留，当前按原创舰设计，不绑定任何IP。双臂造型未获确认，不列为既定结构。

## 1. 这轮必须解决什么

上一轮的缺点不是伤害武器还不够少，而是：
- 惯性钳、引力井都在压制运动，容易退化为叠减速。
- 透镜、偏转阵列和副炮都默认自动，玩家仍只是放一个圈然后等。
- 武器功能多，但缺少“我亲手改变了局势”的连续操作和有代价的释放时机。

新版核心：F改变多个对象的运动趋势，手动牵引器精修一个对象的路线，G从本舰位置解开近身局面。真正输出由质量炮承担。
设计深度来自位置、运动方向、释放时机、射界与幅能，而不是额外技能键、标记叠层、模式菜单或新资源条。

## 2. 核心规则：施加力，不写死结果

- 引力累积改变速度，不瞬移、不把位置直接写到鼠标、不取消转向或推进输入。
- 移除外力不强制清零速度；之后按宿主正常推进、阻尼、碰撞继续运动。不是永远无阻力滑行。
- 原本很快的目标可以通过少量侧向外力改变路线；掉头拽回则要先抵消已有动量，未必划算。
- 位置改变不等于舰首或护盾朝向自动改变。敌人仍可转向开盾，不能把绕侧描述成必定命中无盾部位。
- F/G作用多目标，不以“只能选一艘”限制场强；手动牵引器只精确操作一艘，是不同工具的职责。
- 质量、作用时间、距离、射界与目标推进抵抗共同决定结果；模块归并整舰质量和运动，不逐段复制控制力。
- 所有来源通过同一权威外力汇总阶段，设对象级和发射源级上限；无叠加无限加速或更新顺序依赖。
- 友舰及普通友弹不被强行移动。敌我场形补偿是明确游戏化规则，不包装成严格物理模拟。

## 3. 操作卡

| 输入 | 固定语义 |
| --- | --- |
| F（默认系统槽1） | 鼠标位置部署固定区域引力井；井维持时再按F收回 |
| G（默认系统槽2） | 以本舰为中心释放全向排斥，成功启动后终止自己的井和牵引连接 |
| 第1武器组，按住普通开火 | 牵引器先捕获实际瞄中的敌舰，维持输入时把鼠标用作有限速度移动的牵引锚点 |
| 松开普通开火 | 释放连接，不追加免费冲量，不把目标速度归零 |
| 其余武器组 | 质量炮和近防默认自动；仍可按宿主原有操作接管 |
| 右键及移动/排散 | 维持宿主原义 |

F/G遵循已有重绑。持射牵引是本专武的新交互，不冒充宿主已实现或原版既有行为。没有额外单击/双击/长按技能分支。
同一鼠标没有两套独立指针：拖动目标时按F，井也部署在当前指针位置。需要在远处另布井时，先松手；不会暗中冻结锚点并让另一个准星移动。

G先判断成功条件，再原子结束F/牵引、扣消耗和发布波前。失败保留原场与连接。G成功后仍按着开火不能立即重新抓回，须松开再开火；HUD提示“已释放”。

## 4. 手动专武：矢量牵引器

### 基础交互

1. 瞄住敌舰并按住开火，短暂持续对准后建立连接。正式捕获不能越过中途实体遮挡；不会隔船锁后排。
2. 捕获时锁定对象，不因指针经过另一个目标自动换抓。锚点从捕获位置起步，不在建立连接时突然大幅跳转。
3. 移动鼠标改变期望锚点。锚点有最大移动速率、牵引距离及发射器跟踪射界，实际力随偏离量增加并封顶，配以有限阻尼。
4. 松手、持续时间到、连接出射界/超距/被阻断、敌方相位或失去有效状态、过载/排散/死亡/撤退时释放；需正常恢复后再次捕获。

捕获时间暂以0.2—0.3秒、最长牵引约2—3秒作为交互实验区间，不是平衡定案。它不强制眩晕，持续消耗幅能，并有真实占空比；不能用松手重按规避恢复。

### 有用但不全能

- 锚点留在目标附近：阻滞其离开，但敌方推进始终抵抗。
- 锚点横移：拉偏它的掠袭路线、撤退路线或保护位置，而非仅减速。
- 顺着原运动方向引导，提早松手：目标带着实际积累的侧向速度离开，比先刹停再反向更有效率。
- 对小舰位移显著；对重舰改变速度较小，但不能完全免疫到不可测量。
- 首版只捕获敌舰整船，不抓导弹、碎片或友舰；弹体交给F/G/偏轨近防。避免瞄准时因前方一粒弹丸变成错误工具。
- 不加入舰体自动转向、护盾关闭、强制武器停机或撞击附加伤害。
- 护盾可作为连接的接触表面，力作用于整舰；不因此穿盾造成HP伤害。武器零直接伤害的控制预算仍要计入部署成本。

### 代价与可操作性

牵引距离短于质量炮的主要交战距离，选择直接抓人就要进入更危险的位置。不是离屏拖动敌舰。
牵引器应有足够的转动能力支撑侧向操作，但不是无射界限制的360度抓取；本舰走位和姿态会影响连接。
场上只显示实际可到达的锚点、当前连接与短程速度趋势。超界鼠标显示钳位后的锚点，不许准星指哪里就暗示目标必到哪里。

## 5. F：偏置引力井——群体控场，不是聚怪吸尘器

井固定在部署位置，作用区内敌舰获得趋向中心的有限外力，保留已有惯性、推进和碰撞分离。
- 放在敌群中间：压缩分散阵型。
- 放在掠袭路线侧面：让高速舰群偏航，或使它们经过己方交叉火线。
- 放在敌人撤退方向前侧：干扰退路；并非点敌舰就自动吸向本舰。
- 放在来袭弹幕侧面：偏折实体弹体，为防守服务。

中心软化，无奇点加速度；不强制绕圈，也不持续归零速度。恰当放井与提前收井才可能留下有用的切向运动，结果取决于实际进入速度和驻留时间。
一次仅维持一个自己的井；再按收回，重新部署走正常恢复，不可用鼠标拖着整个井走。
初始持续约4秒的v1探针可作参照，但费用和CD须随新版牵引器重新测，不照抄旧平衡。

## 6. G：全向排斥——方向由站位决定

G永远从本舰释放有传播时间的径向波前，一次命中多艘敌舰、战机和敌方实体弹丸。每个对象每次波前只结算一次冲量，按距离/质量变化。

高手的“定向”不靠第二模式，而靠站位：
- 正对敌舰，把它推离自己；
- 移到它侧面，把它推离队友或推向预先选择的交战区；
- 等弹幕真正接近再推偏，避免太早触发后被后续攻击填满空窗。

在波前范围外的敌舰不会因为已被牵引器连接就额外获得远程抛射。成功G结束F及牵引连接，解除制动后保留真实惯性；没有额外“连招爆炸”或重置所有技能。
G可推送本舰兼容质量弹，但不改阵营、不补射程、不直接增加伤害。光束不受影响，已造成的伤害不撤回。

## 7. 另外两种武器：少而不同

### 质量投射炮（输出）

正常是可靠的实体重弹武器，可自动也可手动。命中正常结算伤害及有上限的冲量，不赋予武器之外的任意船碰伤害。
- F提供可选曲射路径；本武器的火控负责求解，不再单独占一个“引力透镜武器”。
- 只在有可行、有效的拦截路径时借自己的井，默认优先可靠命中而不是每发炫技绕圈。
- 只能有限偏转，一发至多一次借井；累计真实行程，正常碰撞、射程与寿命。
- 主动接管可以选择不同发射时机/入射方向，提前收井可能令在途弹失去后续修正；没有隐藏兜底必中。
- 击退方向可能帮敌人脱离己方火线，不能宣称控制永远正收益。

### 偏轨阵列（自动防守）

短程侧向脉冲令将命中的敌弹偏离；按威胁和处理预算排序，不删除、不转阵营、不无损全屏反射。重型高速弹可能偏折不足，导弹可能再次捕获，光束无效。
首版只默认保护本舰，保留常规近防用于真正击毁导弹；不偷偷自动选队友或靠一个含糊锁定改变操作。团队保护首先由玩家放F/靠近队友使用G实现。指定护航目标可作为后续有明确界面的扩展，不列入首版完成项。

取消v1的潮汐炮打井自动范围伤害，以及后续提案中的独立透镜武器。不是零伤害武器越多越好，而是每件装备都有不重复的决定。

## 8. 入门、熟练、高手之间应该差什么

| 层级 | 行为 | 真实收益 | 失误后果 |
| --- | --- | --- | --- |
| 入门 | F拉群，质量炮自动，贴脸时G | 容易看懂的控场与解围 | G结束进攻场，不能持续兼得 |
| 熟练 | 放偏置井，牵引一艘侧移，及时松手 | 拆开保护阵型，让队友获得射线 | 把敌人拉到自己脸上或拖进队友炮线 |
| 熟练 | 挡在队友一侧再G | 给友舰留出空间，而非把追兵推到队友面前 | 站错边反而助攻敌人 |
| 高手 | 观察运动方向，侧向引导后释放 | 用更少的牵引时间达到更有效的位移 | 反着拽耗尽窗口而没改变局面 |
| 高手 | 控制敌位置并选择曲射/直射、收井时机 | 在正常护盾/碰撞规则下争取交叉火力 | 错误收井让自己的炮弹打偏 |
| 高手 | 根据对手剩余机动/幅能保留G | 诱出突进后再解围，保持下一步选择 | 贪控制导致高幅能时无力释放G |

没有固定F→牵引→G毕业连招。若自动使用所有能力总是最优，本方案失败；若不用全部机制就完全没有输出，本方案也失败。

## 9. 三个典型决策局面

### 拆掉护卫队形

敌方重舰身边有快速护卫。F部署在一侧，只需牵动位置；牵引器把其中一艘顺势带开，使质量炮或队友得到更好射线。可以继续输出，也可以松手切换武器组；不要求马上G把好不容易带来的目标推走。

### 救人不是抢人头

F改变追兵的运动趋势；本舰绕到不会把追兵推向队友的位置。如果牵引能打断追击路线，就不花G；对方继续压近才交G。输出量可以很低，队友获得的脱离时间仍是有效贡献。

### 和重型舰对决

不能把对方当轻船抛飞。用有限侧移和偏置场改善入射方向，重炮维持输出；对方可以转盾、推进抵抗或用远程光束压制。单挑需要质量炮的基本输出，但同DP纯火力舰不应同时在输出与持续防御上被本舰全面压倒。

## 10. 平衡与反馈的硬门槛

- 第一目标是“动作有效且可读”，不是先把所有控制削到看不见。以同级可见位移/射线变化验收，不只看速度变量动过。
- 优先靠距离、占空比、幅能、射界与失误风险限制控制。连续抓取应有释放窗口；若能无限留住同DP目标，调整占空比/总外力，不先加隐藏绝对免控。
- 对手保留移动、转向、护盾、射击与相位等正常应对；远程光束、超出射界、绕侧、饱和攻击、抓恢复期均应有效。
- 捕获多源叠加、F与牵引叠加不能突破整体控制上限；多引力舰不能把模块或单舰重复分配无限力。
- 高幅能时有明确失败预告，不能先删F/断索再告诉玩家G没成功。
- 特效表达真实连接点、波前、当前受力和实际弹道；不靠震屏、黑洞大光圈或静态贴图伪装物理变化。
- 预告是短期受力趋势而非必达轨迹；所有画面取权威模拟状态，客户端不另算一套伤害/运动。

## 11. 首版范围与待验项

首版：两系统＋牵引器/质量炮/偏轨阵列三族武器＋常规护盾/近防。暂不加模块、舰载机、独立资源、残骸投掷、抓友舰、接弹储弹反射或直接扭转敌舰朝向。
残骸搬运要有真实可动对象及其碰撞契约；v1所读环境接口只读，不能把静态障碍换成可抓物就声称已支持。

旧v1的固定主炮11槽账本不自动继承。待控制器的射界/尺度可用后重排安装账本；SMALL/MEDIUM/LARGE/EXTRA_LARGE仍同档换装，固定/转动、内置/可换分别说明。先比较“更多质量炮的独立作战装”与“更多偏轨阵列的护航装”，OP/槽数/DP/HP均未冻结。

进入代码前先做使用真实生产规则、无占位美术的机制验证：
1. 同样输入预算下，顺势侧拉与反向硬拽确有可测差异；鼠标瞬甩不能瞬移或免费加速。
2. 松手后的运动连续、正常阻尼仍生效，单次连接不会锁住错误目标或重按绕过恢复。
3. F多目标/整舰质量/弹体预算正确；大舰有有限效果而非完全无感。
4. G站位改变推离方向，波前去重；失败不破坏原场，成功不被同一持射立刻重抓。
5. 直射/曲射/中途撤场/碰撞/射程相符；相同方向的“视觉弯曲”不算通过。
6. 玩家专注牵引时质量炮自动目标稳定，不把锚点误当射击目标；已有目标选择与鼠标控制必须实际核对。
7. 牵引自动模式/AI不得获得比手动更多的力或转弯能力。无指针的AI用有限锚点计划，不做帧级完美预知。
8. 混编、重舰、光束、饱和导弹及双引力舰场景测输出、友舰脱离时间、控制占空比、实际位移、操作负担。
9. 主线程/Worker、暂停、快照恢复、死亡/撤退/排散/过载清理均需新增状态证据；接口存在不等于实现。

本轮仅完成规则取舍与交互提案。不能将“预计好玩”写成已通过试玩；需要用户审议后进入真实机制与操作验证。
