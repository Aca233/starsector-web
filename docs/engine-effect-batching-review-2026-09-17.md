# 引擎特效合批实验复盘（2026-09-17）

## 决策：撤回，不报告新的整体提速

本轮尝试减少 WebGL 程序、VAO、纹理切换，而非继续压缩顶点数据。候选的渲染提交耗时在测量中有改善，但 **百舰完整工作负载收益没有复现**：首轮降低约 8.1%，第二轮反而增加约 1.0%，第二轮完整 P95 也变差。因此未保留生产改动，不把 draw call 的大幅下降等同于用户体验改善。

已只对本轮两个源文件执行受保护的回退，验证当前冻结的 288 个源文件与本轮基线一致。此前武器威胁裁剪、几何计算、尾迹等优化均保留；未重置工作区。

## 实验边界

候选只修改：

- `src/engine/render/webgl/ShipEngineRenderer.ts`：先计算同一艘舰的引擎样本，将其喷焰、轮廓、光晕分别提交。不跨船体或其他绘制通道重排。
- `src/engine/render/webgl/MissileEngineRenderer.ts`：在已有加法混合块内，将交替的轮廓/光晕精灵按纹理分组，喷焰块保持原样。

所有效果、形状、颜色、透明度、时间和随机采样公式保留；不减粒子、分辨率、AI/模拟频率或预测窗口。非标准颜色、透明度等不满足安全条件时保留原顺序。候选引入了临时样本与闭包，不能在未测量 GC 的情况下声称它们无代价，也不能把模拟波动归因于 GC。

## 完整工作负载

Chromium / ANGLE D3D11 / RTX 5060，2560×1440、DPR 1，固定种子 `0x51180`。两个隔离页面交替推进；每场 360 个 1/60 秒模拟步，前 60 步预热，后 300 步计时。每轮包含模拟、视觉更新、一次渲染和 `gl.finish()`；第二轮反转每步的先后执行顺序。基准不与构建、采样或重型验证并行。

| 百舰指标 | 首轮基线 → 候选 | 第二轮基线 → 候选 |
| --- | --- | --- |
| 模拟均值 | 139.991 → 129.168 ms | 122.571 → 125.517 ms |
| 渲染提交均值 | 32.149 → 29.101 ms | 30.531 → 29.101 ms |
| 完整工作均值 | 172.202 → 158.330 ms | 153.151 → 154.676 ms |
| 完整工作 P95 | 219.2 → 203.8 ms | 196.9 → 200.4 ms |

渲染提交分别减少约 9.5% 和 4.7%，但首轮完整耗时的大部分差值来自未修改的模拟代码计时。第二轮渲染节省约 1.43 ms，整轮却增加约 1.53 ms。不能选择首轮作为稳定整体收益，也不能将不同轮次的基线差异算作优化成果。

首轮其他规模：10 舰完整均值 10.532 → 10.016 ms；50 舰 60.801 → 58.745 ms。两个百舰对照及首轮其他规模的最终引擎状态哈希均一致，页面与 WebGL 无错误。

**这些是脚本工作耗时，不是实际 rAF 或显示器 FPS。** 不取倒数宣称游戏帧率；未达到百舰 180 FPS。

## 固定状态渲染验证

模拟 180 步后固定状态渲染 180 次，前 30 次预热，交替页面次序。CPU 提交计时不包含紧随其后的 `gl.finish()`。

| 场景 | 渲染均值 | P95 | 总绘制次数 |
| --- | --- | --- | --- |
| 10 舰 | 3.741 → 3.619 ms | 4.5 → 4.5 ms | 983 → 589 |
| 100 舰 | 30.833 → 27.451 ms | 37.0 → 32.4 ms | 9786 → 5644 |

百舰绘制次数减少约 **42.3%**，固定状态渲染均值减少约 **11.0%**。这证明了局部收益，不证明完整战斗负载稳定提速。记录中的 GPU timer 单次样本不作为平均 GPU 性能证据。

## 几何与像素验证

仅使用忽略目录内的运行时诊断脚本，未恢复测试套件/运行器，也未做素材哈希或大小审计。

- 950 组舰船/导弹参数场景，61,079 个绘制图元参数保持一致；比较允许候选在加法块内改变图元顺序，不宣称全局绘制顺序相同。
- 包括战机、相位、系统专用引擎、推进插值、缺失状态、关闭引擎、自定义颜色和异常数值。80 组有输出的保守回退场景保持原图元顺序。
- 实际战斗推进 180 步，100 艘舰、1322 枚导弹；使用同一浏览器、同一 GPU 上下文、同一批处理器/纹理，切换旧/新渲染函数比较。
- 4 类像素场景：百舰特效、单舰近景、导弹特效，以及单舰 320 个引擎与 2200 枚导弹的容量溢出压力场景。包含跨舰普通透明绘制边界。
- 4 个非 MSAA 场景全部零像素差异。
- 4 个 MSAA 场景中，舰队与导弹场景零差异；近景有 151 个通道差异，压力场景有 1912 个通道差异，最大均为 **1/255**。旧对旧压力控制组也有 172 个通道的 1/255 差异。不能宣称所有 MSAA 像素或所有显卡完全一致。
- 页面错误和 WebGL 错误均为零，近景截图经查看确认包含有效喷焰/光晕，并非空白比较。

## 对下一步的影响

仅减少引擎特效提交，无法解决占完整耗时绝大部分的模拟开销。下一轮优先针对 `ThreatAssessment.ts` 的跨目标重复查询与原生 AI 阶段数据复用，而不是再以 draw call 数量为成功指标。

当前 `TacticalWorld` 只有实时数组引用，没有阶段版本号；AI 更新还可能激活系统、改变排散/护盾状态。任何共享查询或整舰粗筛都必须定义生命周期和失效边界，保留挂载可变数据、自定义回调与完整预测窗口的语义。这个方向尚未实现，不将方案当成果，也不重复此前已撤回的简单动态射程缓存实验。
