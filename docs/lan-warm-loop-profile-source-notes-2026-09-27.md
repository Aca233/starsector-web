# 热身后完整模拟循环CPU采样方案（2026-09-27）

相位依赖组缓存与既有包络命中资格复用均未通过整步门槛，生产已恢复726模块基底。此前主要CPU来源为浏览器短冷启动，不继续据此盲试getter微优化。
复用最近验收的A0冻结bundle（四既有实验开），同一176初始实体734挂点/seed917/3200DP。用Node内置inspector Session，不开启网络调试端口、不启动可见应用。150完整步热身后，仅对120个完整fixedUpdate做一次500us采样。不是新的ABBA，也不是性能收益检验，不拿采样运行耗时与旧A/B比较。
完整270步权威+隐藏tracker/RNG终态必须与已知A0相等。保存原始cpuprofile、bundle/基底SHA、起始/热身/终点实体弹体计数、函数self/inclusive和模块self汇总。递归栈同一函数的inclusive每个样本只计一次，self不重叠；不能把inclusive桶相加。源模块由esbuild的模块注释定位，保留bundle行号，不冒充原TS精确行号。
结果只用于选择下一主热点。Node采样不能代表浏览器稳态Hz、输入P95、CPU占用或原版实机等价。
