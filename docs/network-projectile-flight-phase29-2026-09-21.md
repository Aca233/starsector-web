# Phase29：已确认普通弹丸的本地飞行显示

## 已落地范围

`ProjectileFlightPrediction` 接在 LAN/Steam 共用 `LanBattle` 的完整状态还原回调及绘制入口，无环境变量开关。它接管的只是**已收到房主确认的普通弹丸显示坐标/尾端**，不是发射许可或战斗判定。已有本机移动、炮塔、开火预测保留；handoff offset 与新 flight pose 合成，不重复绘制。

- 固定 1/60 内部步长，RAF 余量使用 scratch，不把余量反复积分入固定步状态。
- BALLISTIC、PLASMA、BALLISTIC_AS_BEAM 复用原生 source lifecycle 的运动和 tail 规则。
- 最多向前100ms，250ms无新完整端点即让回原快照；射程耗尽前停止预测，不推断新的命中、fade、消失、音效或爆炸。确认删除/命中立即服从新完整状态。
- 导弹/制导、flare、水雷、mote、近炸、MIRV、旋转系统弹、既有命中/消退及未知种类不启用此预测，仍用原渲染路径。
- 权威对象、RNG、伤害/EMP、弹药/flux/冷却不变；完整世界协议、采样目标、精度、屏外战术信息不变。
- 不借用独立实验视觉流的替换层，因此不会触发 LocalFirePrediction 原有的“实验层活动时关闭”保护。实验流活动时新层主动让路。
- 日志新增 `hud.input.projectileFlight`：active/tick/entities/renderedFrames/extrapolationMs。这些明确是显示工作，不是网络/完整状态Hz。

## 量测与否定实现

第一版每弹丸 `Object.create(nativeRecord)` 建立独立原型。逻辑正确但V8热路径多态开销过大：合成1500弹丸/60Hz接收的新增处理P50约11.3–11.5ms、P95约13.5–16.5ms。**已移除这种实现，保留负结果/对应bundle**于 `benchmark-prototype-negative.json/.mjs`，不能拿它上线。

最终改为普通记录：快照时更新外观、复用私有Vector存储，显示帧只推进小块运动状态。首轮三组A/B→B/A→A/B结果（单位ms，每60Hz显示帧，含该帧如有的flight receive，以及geometry属性读取）：

| 场景 | 新增路径总P50 | P95 |
| --- | --- | --- |
| 100弹丸/20Hz接收/1显示端 | 0.016–0.018 | 0.033–0.067 |
| 500弹丸/20Hz接收/1显示端 | 0.052–0.071 | 0.141–0.169 |
| 1500弹丸/10Hz接收/1显示端 | 0.159–0.172 | 0.441–0.666 |
| 1500弹丸/60Hz接收/1显示端 | 0.297–0.336 | 0.565–0.605 |
| 500弹丸/20Hz接收/5顺序显示副本之和 | 0.336–0.368 | 0.782–0.881 |

这是合成但使用原生生命周期的展示成本测试，不含完整捕获/解压/恢复、AI/碰撞或GPU绘制；3/5副本不是实际多人。baseline本身没有这段推进，不能把“比本轮失败实现快”宣传成对旧游戏CPU/RTT的改进。脚本保存所有每帧时间、warmup180/测量720帧及运行顺序。

确定性10/20Hz完整端点、60Hz绘制的无碰撞匀速例子中，每个显示帧均前进，最大位置误差<1e-7。它证明已知轨迹能填补端点间停顿，**不是低配机器真实能渲染60FPS，也不是房主模拟/网络60Hz**。

## 实际绘制与验收

- 32项针对性检查已通过：三种native运动/tail、源舰速度、不同RAF分割、range/horizon/stale、unsupported fallback、fractional ID/复用对象/删除/旧端点、实验层让路、开火handoff、capture/RNG不变等。
- 无头Chromium+原生资源+真实WebGL：重迫击炮/TPC分别改变720/3362像素；已确认弹丸头部50ms前进50单位，TPC尾端在成长阶段保持原位；GL错误0，权威删除后恢复空弹丸像素（差0）。不是原版实机逐像素对照。

**渲染后端是重要测试条件差异。** 不把默认软件后端的失败与D3D11的通过比较成“本轮代码提升了网络Hz”；这不是严格性能A/B。三个客户端在同一台电脑上；D3D11仅一轮通过，也不是三台机器/Steam/n2n或者五人长期稳定性证明。早先22舰失败没有保存viewer GPU信息；较轻默认后端轮的SwiftShader信息有直接记录，不能冒充早先每轮都单独读到了GPU。
