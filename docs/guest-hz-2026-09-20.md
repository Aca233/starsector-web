# Browser-host guest Hz — 2026-09-20

## Scope and pre-edit audit

User priority: actual client state-update Hz first, input latency second. Keep browser-host authority and relay; no lockstep, no full client simulation, no production/cloud restart, no campaign publishing.

This change concerns snapshot projection only, not native game rules or UI. Existing local evidence for motion remains `docs/control-fidelity-2026-09-16.md`; no movement/AI/damage equations are changed and no new native visual-equivalence claim is made.

Evidence → expected behavior → current difference → verification:

- `host.worker.ts` constructs the simulation locally via `createLanWorld`; browser/Node messages contain validated data, not executable getters or Proxies. `CombatSnapshot.pack` currently walks simulation-only health/decal subtrees, adds layouts, and only then discards their packed fields. A native-only capture path can omit exactly these ALREADY omitted fields before traversal; generic capture must keep its current two-pass getter/reference-discovery semantics. No additional visible state is removed. Test expanded projection equality, real restore equality, wire validation, and generic accessor behavior.
- 32-ship baseline, two actual headless Edge browsers, one browser host Worker and a local relay, deterministic test seed 1511506142: physics ~60.05 steps/s; guest accepted ~43.53 snapshots/s over 20 seconds with CPU profiling enabled. Host profile: capture `pack` ~3.38 CPU-s self; doEncode ~0.86 CPU-s self, plus array/map encoding. This is NOT a WAN or separate-PC benchmark, and profiled results are not compared against unprofiled results for a speedup claim.
- Retain the 60 Hz target, input validation, bounded snapshot credits, event ordering, and receiver counters. No duplicated packets, increased queues, lower simulation frequency or lower AI fidelity.

The optimized path is opt-in only at the internally constructed authority Worker. It reads retained data fields once instead of twice, and omits only the already-excluded damage/health/projectile fields before recursive packing. Generic capture remains the default for diagnostic/custom callers. Native-only means the caller guarantees the normal engine graph (no accessor/Proxy instrumentation); prototypes alone cannot establish this guarantee. Existing generic omission and layout semantics remain available for compatibility tests.

## Validation/results

Implementation and projection/restore tests complete; paired unprofiled browser measurements completed. 64-ship capacity gate FAILED on both versions (details below).

The unfinished page-WebSocket latency harness was removed: it could not observe worker-owned sockets, and its timeout is not game latency evidence. The Hz harness reads the actual local server's room fixture and test-build accept/RAF probes instead. Hooks exist only in the isolated Vite test plugin, never production modules.

Regression coverage: expanded frame-local layout/projectile-column equivalence and actual receiver restore equality over 1,200 steps of 32-ship combat (21 checkpoints); damaged decals, projectiles, muzzle event windows, RNG/non-mutation checks; carrier craft; generic getter exceptions/two-read behavior; unrelated same-named fields; reserve deployment/destruction. The native contract intentionally does NOT support arbitrary getter/Proxy instrumentation: those callers must leave the flag off.

Both packets in this fixture are 272,651 bytes. This does not prove a corresponding Hz increase or bandwidth reduction.

47 network/codec/publication/credit regressions passed, including Steam transport compatibility tests. This is not a live Steam session or a WAN test. No physics, AI, numerical encoding, authority security validation, damage, input handling, playback policy or queue limit changed.

## Follow-up: Steam / LAN / web relay together

## Follow-up: shared snapshot codec, retaining host authority

Scope: user confirmed keeping host-authoritative combat and prioritizing **unique accepted authoritative states/second** over latency. This is transport/serialization work, not a native gameplay or UI change: no AI/physics/damage rules, snapshot credits, catch-up guards, Hz targets or interpolation policy are changed. The shared binary path covers browser-host LAN, web relay, negotiated Steam binary and the Node authority adapter. Legacy JSON stays compatible but is not expected to gain from a binary-writer optimization.

- Promote the existing exact numeric writer (previously Node-summary-only) to the shared host Worker binary path.
- Add an opt-in numeric/null array writer without changing iterator, getter, sparse-array, live-length or depth-check ordering. Preserve the conservative encoder as an independent byte oracle.
- Decode common numeric array tags directly, retaining full preflight, Unicode fallback, key validation, all other tags and allocation/depth/byte limits.
- Add `check-shared-snapshot-codec.mjs` to the shared regression command. Cover conservative byte equality, pinned-library decoding, seeded mixed trees, numeric tag/IEEE edge cases, custom iterators and depth, getter reads, fallback/ownership, truncation and hostile containers/keys.

Validation plan: fixed-frame Node/headless Edge microbenchmarks; real two-headless-browser host + local relay runs using matched fixture and ABBA order; shared Worker capability modes; full Steam regressions without relaxed assertions.
