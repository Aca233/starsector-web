# 可装配舰船技能（2026-09-19）

## 使用

- 造船/改装右侧 **舰船技能**：左侧管理当前装配，中间搜索和筛选技能，右侧查看详情后装配。添加、卸下、排序、恢复默认均为临时修改，点击 **应用更改** 才写入当前自定义方案；取消或关闭不保存，不写回原版船体。
- 装配窗口的 **快捷键** 独立成页，改键同样随“应用更改”一起保存；主菜单和暂停菜单的独立按键设置仍即时保存。界面复用现有改装器的 NativeButton、NativeBitmapText 和 NativeChrome，不另设一套皮肤。
- 技能库复用原版效果定义，不复制数值。当前不收取技能 OP，不引入等级或解锁体系；同一技能不能重复装配。键盘槽与右键槽之间可直接移动技能，不会复制一份。
- 默认 F / G / H 对应槽 1 / 2 / 3。更多槽可点击战斗 HUD，或在装配窗口/游戏设置中绑定未占用的字母键。
- 点击键位进入按键录入，再按字母改键，Delete/Backspace 清除；冲突会拒绝保存。数字键仍归武器组，移动、防御、浏览器组合键不会被覆盖。按住 Shift 操舰仍可直接使用技能。
- 可选启用 **Shift + 滚轮** 轮选，默认 **J** 释放选中技能。普通滚轮仍缩放；F/G/H 直接释放不受轮选影响。长按不重复触发。
- 联机帮助由 H 改为 F1；战术地图中的 G/H 指令保持原样。

## 配置与兼容

`ShipSpec.systemTypes?: string[]` / `Design.systemTypes?: string[]` 是有序装配列表。

- 未提供列表：读取已有 `systemType`，原版默认技能及旧方案保持不变。
- `[]`：明确不装战术技能，不能回退到原技能。
- 列表 ID 支持现有源别名解析；重复别名等同于重复技能。
- 最大 64 项只是文件/网络输入的安全边界，不是 OP/等级槽位机制。
- `ShipSpec.rightClickSystemType?: string` / `Design.rightClickSystemType?: string` 是右键装配覆盖：省略继承原生 `defenseSystemType`，`NONE` 卸下右键技能并使用舰体护盾/相位（没有防御硬件则为空），其他 ID 装配对应技能。原生字段和护盾/相位所有权不变。
- 右键槽在同一装配窗口内修改，统一暂存、应用或取消。技能详情提供「装配到技能槽」和「装配到右键」；已装配技能可直接换槽，已占用的右键槽会被新技能替换。
- 鼠标右键执行当前右键槽；Shift + 右键直接控制舰体护盾/相位，不消耗右键技能次数。卸下右键技能或恢复默认均不会给无盾船凭空增加护盾。

## 实现

- `ship.systems` 是独立 `ShipSystem` 实例列表：每项分别持有阶段、计时、次数、目标快照和待消费的使用成本。
- `ship.allSystems` 包含战术技能与防御，用于更新、事件派发、离场/战沉/过载处理。原生防御保留原 CR 防御规则；自定义右键技能遵循战术技能的 CR、排幅和过载规则。
- `ship.system` 保留为旧代码的第一槽/组合属性入口；现有 `auxiliary` 组合链扩展至其他战术技能，末尾是防御。不通过替换 `ship.system` 来执行技能回调。
- 属性遵守原有加算/乘算组合，武器/防御/运动限制取合并约束；没有暗中更改原技能数值。共享幅能时，激活校验计入所有技能同帧已预留成本。
- AI 显式传入 `context.system`，各行为只激活自己的实例。音效在整组层面协调循环声，资源闭包遍历所有技能。
- 装配约束由定义的 `installReason(spec)` 声明：常规护盾、舰载机、SYSTEM 发射器、微光挂点或镜像配对方案。缺少依赖不允许新增。没有凭空添加专用发射器，也没有把依赖不足伪装成可用技能。
- 草稿、导入/导出、LAN 方案保留列表；命令的 `value` 为零基槽位。省略 `value` 兼容第一槽。
- 联机快照保留各实例状态，`auxiliary` 是由本地配置重建的只读拓扑，不递归发送。现有仅支持单技能的 AI 多核标量协议对多技能船安全回退到主线程。

## 2026-09-19 技能实际效果与视觉反馈修补

### 根因与范围

- 原先多个数值技能已经生效，但 `ShipSystemDefinition.visuals` 只支持推进/堡垒布尔标志，原版 `.system` 的 weapon glow、jitter 与引擎倍率没有传入渲染器。
- 加速填弹器/高能聚焦/导弹重装等可在没有适用武器或没有可改变状态时走完计时；目标类技能未捕获到目标时，HUD 仍可能显示“就绪”。
- 本轮不改原版默认装配、技能数值、冷却、次数或控制规则；新增无效使用拦截与解释，不再为这些无效指令花费次数/幅能。未新增测试文件或测试运行器。

### 实现

- `NativeSystemVisuals.ts` + `native-system-visuals.json`：技能定义注册时按 source ID 挂接视觉数据，包含 RGBA、武器类型、舰体抖动层、引擎倍率与传送起点副本，并验证数据。25 条源 profile 中 24 条目前对应已注册系统；`phasecloak` 的专用盾/相位渲染仍沿用原路径，不以数据条目数冒充完成数。
- 20 条来自本机 `starsector-core/data/shipsystems/*.system`；5 条脚本型来自 `TemporalShellStats`、`DamperFieldOmegaStats`、`CryofluxTransducerStats`、`AcausalDisruptorStats`、`TargetingFeedStats`。
- `ShipSystemRenderer.ts`：读取全部键盘槽及右键槽；死亡/入坞/撤退和失效技能不绘制。抖动使用真实舰体 sprite 与独立视觉随机，不消耗战斗 RNG，不增加快照字段。瞄准指示系统的视觉只作用于该航母所属战机。
- 武器光独立于开火 `glowAlpha`：填弹器黄色、能量聚焦紫色；按武器类型过滤，优先原炮塔 glow mask，无 mask 时只对炮塔/炮管原图着色，不画额外大光圈。
- 推进系统使用各自原版参数，而非全套用冲刺推进倍率；多个系统取最强增强与最强抑制，保留传送的零尾焰及 infernium 的缩短/暗化参数。槽位顺序不改变尺寸叠加结果。
- 加速填弹器/高能聚焦检查当前实际武器（含失效、弹药）；导弹工厂只在有可补导弹时触发；快速重装只在能实质缩短导弹冷却时触发。
- 熵放大器/非因果干扰器/拦截场在无合法目标时提示目标要求和受插件修正后的射程；显式选错目标不偷偷换目标。
- 战斗 HUD 显示填弹器射速/耗幅、聚焦伤害、推进/机动和阻尼减伤状态；长失败理由省略显示，悬浮显示全文。
