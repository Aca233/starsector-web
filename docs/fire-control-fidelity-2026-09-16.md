# 自动火控完善 · 2026-09-16

## 本轮实际交付

自动火控不再是 `ShipWeaponControlSystem` 中“盯住一个敌舰然后看距离开火”的分支。

- `src/engine/ai/AutofireController.ts`：逐挂点目标保持/重新搜索、角色筛选、预测瞄准、射击安全和资源决策。
- `src/engine/ai/FireControlGeometry.ts`：稳定二次方程截击解、真实下一根炮管的炮口坐标、舰体多边形/当前护盾弧的射线交点。
- `CombatEngine` 每个物理步传入同一份舰船/导弹/小行星视图；不依赖 HUD、渲染器或固定的两个主角。
- `Ship.fireControlMode` 区分操作者，而非阵营。敌舰、增援与玩家自动驾驶的所有挂点使用同一控制器；玩家手动驾驶时，仅未选中的自动组使用它。不会改写玩家保存的武器编组设置。
- AI 不再通过 `isFiringMain` 冒充玩家按住鼠标。手动固定炮仍可朝真实炮口方向空射，自动固定炮必须满足预测命中条件。

## 行为

1. **逐武器选敌**：保留有效目标，主目标可打时优先；主目标超射界/射程、死亡、相位或被遮挡时，可以另选目标。目标身份不会覆盖舰船的指挥/HUD 主目标。
2. **点防**：真实枚举敌对导弹，按 PD/PD_ONLY/PD_ALSO/ANTI_FTR 角色选择导弹或战机；无拦截目标时普通 PD 可攻击舰船，PD_ONLY 不会乱打大舰。原版普通点防可能受诱饵影响，只有 IGNORES_FLARES 标记时明确忽略诱饵。
3. **截击**：使用发射方与目标的相对速度，求截击方程而非仅用距离/弹速；考虑剩余充能时间与当前炮管坐标。光束不套弹丸飞行提前量。解不存在时不浪费弹药。目标导弹将在预计接触前到期时不射击。
4. **命中判断**：实际炮口方向与平移预测后的目标外廓/当前护盾弧相交才开火，删除旧的固定角误差阈值。目标中心在射程外而外廓/已展开护盾在射程内时仍可开火。
5. **遮挡**：自动开火前检查友舰舰体/已展开盾与小行星，包括它们相对弹道的直线运动；前方被挡住时停火或选其他可打目标，不把后方友舰误判成挡炮。
6. **导弹锁定**：发射周期开始时记录挂点自己的舰船目标，后续发射沿用该目标；不再错误绑定整艘船的主目标。
7. **弹药**：实现原版充能弹药的低弹量/恢复阈值，以及 USE_LESS_VS_SHIELDS 的 80%/满弹滞回；PD、DO_NOT_CONSERVE 按角色豁免相应保留规则。受击一侧没有护盾覆盖时不假装目标仍被盾保护。
8. **幅能**：继续保留执行层实际成本校验；AI 普通进攻武器新增 95% 的可选射击预算上限，点防允许使用预留空间。已提交的不可中断连发不因预算检查被吞掉。玩家手动扳机不受 AI 预算接管。
9. **排查信息**：挂点 `fireControl` 暴露目标 ID、类型和 `NO_TARGET / ALIGNING / FIRE / FRIENDLY_BLOCKED / OBSTACLE_BLOCKED / CONSERVING_AMMO / FLUX_BUDGET / UNAVAILABLE` 原因。`FIRE` 是火控许可，实际发射仍受冷却/生命周期约束。没有增加玩家 UI。

## 数据与新增内容

`WeaponSpec.aiHints` 保存原版 CSV 的提示名称，加载器与内容验证器统一处理。当前 17 门武器只回填提示元数据，没有改其机动、弹速、射程、伤害或冷却数值。

本轮实际消费：PD、PD_ONLY、PD_ALSO、ANTI_FTR、STRIKE、USE_VS_FRIGATES、IGNORES_FLARES、DO_NOT_AIM、GUIDED_POOR、USE_LESS_VS_SHIELDS、DO_NOT_CONSERVE。其他提示保留为元数据，不声称已经实现它们的语义。

同类新增武器/舰船只需规格、挂点和上述角色标记；本轮没有武器 ID/舰船 ID 特判。ID 仅用于目标身份、稳定排序与选敌计时随机流的种子，不用于行为分支。不同机制仍需在扩展接口实现，不能把不存在的能力靠填标记伪装出来。例如现有导弹制导只支持舰船锁定，故不会让“制导导弹 + PD 标记”假装已经能锁定和拦截导弹。

## 原版依据与明确的近似

本地只读依据（相对于 `decompiled/starfarer_obf/com/fs/starfarer/`）：

- `combat/ai/private.java:58–119`：按武器尺寸/PD 调整的选敌间隔、失效目标重新捕获与保留。
- `combat/ai/private.java:124–164`：USE_LESS_VS_SHIELDS 与充能弹药保留/恢复规则。
- `combat/ai/private.java:202–287`：PD_ONLY/ANTI_FTR/STRIKE/USE_VS_FRIGATES、主目标优先、各挂点射界与目标选择。
- `combat/ai/private.java:314–419`：导弹/诱饵候选与射线/友军判定。
- `combat/systems/WeaponGroup.java:299–319`：自动组逐武器调用 AI，不把手动交替组的轮换强行套在独立自动炮上。
- `combat/ai/attack/AutofireManagerV2.java`：幅能管理、95% 条件与正在进行的发射周期保护。

没有将简化算法写成“原版完整复刻”：

- 原版导弹候选带随机选择；Web 使用目标保持、对本舰的直线预计碰撞时间、转炮距离与稳定 ID 排序，未实现舰队级拦截分工/过量火力分配。
- 截击是恒速平移预测，没有移植原版逐步提高精度、技能/性格误差、目标未来加速度和转动预测。导弹以额定速度用于候选解算，非完整加速/转向轨迹模拟。
- 遮挡为直线发射/光束通道，不保证散布、导弹后续拐弯和爆炸溅射的完全友军安全；残骸片尚未纳入火控预判，原有物理碰撞仍会结算。
- 95% 预算是明确的 Web 简化，不是原版完整的全舰幅能、护盾/装甲收益、鱼雷齐射时机或伤害饱和度管理。
- 未完成 CONSERVE_FOR_ANTI_ARMOR 等全部策略提示，未移植战机/轰炸机的完整进攻 AI。战机/轰炸机既有攻击状态机仍保留；它们可被新的大舰火控选为目标。
- 大舰机动 AI 仍是现有简化策略，没有在本轮伪装成“已评估最强火力弧”。

## 验证

未新增测试文件；使用 Node 内存编译运行断言：

- 37 项通过：截击数值与退化解、逐炮射界、点防与各角色、失效目标、友军/小行星遮挡、实际炮口命中、盾弧、弹药/幅能、手动与自动驾驶切换、逐炮导弹锁定等。
- 真实战斗引擎中，点防光束实际击伤/消灭来袭导弹，而非仅检查“选中了导弹”。
- 两次同种子 20 秒完整战斗产生相同状态，位置与炮塔角度均为有限值。
- 内存注册一艘新舰、一门新点防武器，未修改火控代码即可选弹并实际发射。
- 隔离浏览器通过正式构建入口测试：敌舰 AI 已接管所有挂点；开启/关闭玩家自动驾驶正确切换控制权；手动选中组不被 AI 抢占；持续战斗无页面脚本错误。

开销抽样（仅 Node 下的火控/武器执行，不是整场游戏帧率）：12 舰、156 挂点、240 导弹，180 步。采用原版区间内的独立确定性计时，避免所有挂点同步扫描；遮挡几何按候选优先级惰性计算。本机一次采样首次扫描约 28.1ms，后续平均约 4.28ms、P95 约 4.93ms、最大约 5.39ms。该数值不是跨机器性能承诺。

最终 `npm run typecheck`、`npm run lint`、`npm run build` 均通过；最新正式包的隔离浏览器复验也通过。


## 2026-09-17 火控植入与运行时射程更新
- 新增NativeAim自动瞄准点消费者：原版Ship.getAimAccuracy/OO0O半径扣除与闭合速度公式，持续射击15秒收敛；换目标或停火超过3秒重置。不用随机偏转或反应延迟冒充精度。
