# 现有多核模拟的标量协议优化（2026-09-17）

## 已合入内容

**正式 `src/` 已合入固定字段 codec；没有启用新的火控并行阶段。** 保留原来的 4 个 AI Worker 和适用性门槛，减少快照打包、输入校验和 Worker 读取中的动态字符串访问、槽位解构和循环开销。

正式运行时只改三个文件：

- `src/engine/ai/multicore/ScalarWire.ts`：12 类已验证的原生组件字段布局，用静态属性访问实现编码、校验、本地快照与读取。
- `src/engine/ai/multicore/Protocol.ts`：构造时分组，运行时按组调用 codec；原字段槽位、顺序、NumericStore 和私有原值快照保留。
- `src/engine/ai/multicore/Owner.ts`：Worker 初始化时建立读取分组，不再每步逐个解析字段名。

字段布局未知、字段增加或重排时仍走完整通用路径，不截断、不丢字段；没有运行时 eval/new Function。没有降低 AI/武器频率、跳模拟步、改变 dt、换 Float32 或减少画质。正式 `CombatSession`、引擎步顺序、线程数和暂停/重启调度没有改动。

## 本轮整步结果

i5-13490F，100 艘默认 Onslaught；双方均为 4 个 AI Worker。新鲜冻结同一份当前源码，先做 60+180 步筛选，再做两轮相反初始顺序、各 **60 步预热 + 600 步计时** 的对照。每一步轮换版本执行顺序，哈希在计时区间外。

| 配对轮次 | 基线 ms/步 | 候选 ms/步 | 整步吞吐变化 | P95 耗时变化 |
| --- | ---: | ---: | ---: | ---: |
| 延长轮 `scalar-extended.json` | 43.44712 | 42.15697 | +3.060% | −1.302% |
| 反向复测 `scalar-repeat.json` | 44.11798 | 41.06852 | +7.425% | −10.181% |
| **两轮同权合并，双方各 1200 个计时步** | **43.78255** | **41.61274** | **+5.214%** | 不对两个 P95 求平均 |

合并后的平均步耗时减少 **4.956%（2.16981 ms）**；吞吐从 **22.84015 → 24.03110 步/秒**。

首轮短筛选为 59.36681 → 55.76186 ms（约 +6.465%），但不把它与不同长度的延长轮混成最后结果。不同时间系统负载存在波动，因此保留每轮数据和范围，不只选最好的一轮。

这是**本轮新增净收益**，不是通宵累计总提升。步/秒不是屏幕 FPS，**100 艘战列舰 / 180 FPS 仍未实现**。

## 成本变化

两轮延长数据中，打包与校验均持续下降：

- 打包：4.07258 → 3.33267 ms；复测 4.49422 → 3.46612 ms。
- 输入校验：2.78333 → 1.97009 ms；复测 3.19571 → 2.10344 ms。
- 最慢 Worker 同步：1.46365 → 1.30504 ms；复测 1.62729 → 1.38874 ms。

Worker 同步已经包含在等待及总步耗时中，不重复相加；不把某个局部百分比冒充整步收益。AI 内核、主线程武器与弹体系统的主体算法仍然存在，因此这不是近线性的多核扩展。

## 正确性与回退

- 两轮都运行到 tick 660，各有 **50 条双方完整状态哈希记录**，全部相符。哈希包含私有 Autofire tracker。AI 提交/重算数量一致，无页面错误、无正常轨迹输入失效。
- 静态 codec 语义诊断：12 种原生形状、反向字段顺序以及未知字段形状；**400 次编码、400 次读取、9808 次逐字段变更拒绝、400 次私有快照防共享缓冲篡改检查**通过。

- 真实浏览器等待期注入 5 种变化：冷却、武器健康/受击时间、瞄准、未知 schema 字段和替换向量对象。每例两版均确认第 35 步发生一次注入、旧 AI 计划被拒绝；34/35/36 步及后续到 65 步的完整状态相同。
- 原型 TypeScript 检查通过；合入后 `npm run build`（包括 TypeScript 项目构建与 Vite）通过，保留常规大 chunk 提示；改动文件定向 lint 命令退出 0。

## 方法与范围

计时包括玩家 AI、原有多核打包/派发/等待/校验/提交/回退、完整引擎模拟步和视觉时钟更新。沿用两版相同的实验 awaited 调用驱动，不含完整渲染/浏览器显示；本轮没有把这种异步驱动合入正式调度。
