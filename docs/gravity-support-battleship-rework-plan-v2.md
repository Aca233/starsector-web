# 万有引力号方案 v2：保留抓取拖动，简化辅助操作

2026-09-30。状态：简化评审稿，未实施。

## 最新确认与边界

用户确认定位：**实验 / 引力 / 辅助 / 战列舰**。最新反馈：操作太麻烦，目前左键拖动感觉不错。

因此保留当前生产版的“按住左键捕获真实实体、鼠标移动拖锚、对象按有限力跟随”的核心，而不是把“当前拖动”误记成尚未实施的自由圆场。现有捕获/拖动手感和参数不在本轮改写。

v1中的多场形切换、F援护选择流程、G锁场绘轴均撤出主推荐。储弹、轨道装填、近战处刑连段也不恢复。本轮只写方案，没有修改生产文件、素材或配装。

## 一句话玩法

**抓住、拖动，就能改变局面；武器自动配合，技能只负责在恰当时机隔开威胁或送走对象。**

玩家的大部分注意力仍是看战况和移动鼠标，不是管理模式、场形或库存。日常战斗不要求先完成F/G。

## 操作：一个主动作，两个待评审的即时辅助动作

| 操作 | 推荐作用 | 不新增的操作 |
| --- | --- | --- |
| 左键按住 | 保留当前实体捕获和拖动；敌舰、友舰、实体弹及环境对象沿用真实质量/动量边界 | 不绘区域、不改成多目标区域场、不加释放蓄力流程 |
| 右键 | 推荐保留当前本舰周围排斥，作为本舰解围；成功释放当前抓取 | 不改成必须频繁管理的极性模式 |
| F：远端分流（候选） | 以当前抓住的对象为中心，发出一次短促的有限排斥；抓住的对象本身不受这次脉冲影响 | 不另选施放坐标，不锁场，不生成第二个常驻场 |
| G：定向送离（候选） | 沿当前拖动方向给被抓对象一次有限冲量，然后释放 | 不按住另行瞄准、不绘制方向、不自动追踪敌人 |

右键、F、G分工：右键保护本舰周围；F处理远端被操纵对象附近的威胁；G只决定当前这个对象怎么离场。F/G仍是候选，不把用户对左键的认可扩大为已经认可新技能。

### F的辅助价值

- 抓住受压友舰：F推偏它附近的敌方实体弹，给继续拖离争取时间。不是治疗或护盾，光束不受影响。
- 抓住敌舰：F把附近护卫向外推开，帮助将关键目标拉出保护圈，为本舰和友军打开射线。
- 抓住可移动残骸：可在合适位置用F偏转局部来袭弹幕，但不凭空提高残骸耐久。

普通友舰/友弹不因F被推出；被抓对象及其装配根成员明确豁免。没有合法抓取对象时F不可用，不静默改成另一种技能。脉冲不附赠范围伤害，不能同时复制本舰全向防御。

### G的辅助价值

- 抓住友舰并沿撤离方向拖动：G托送它一把，结束连接。本质是已有拖动的收尾，而不是夺取完整控制。
- 抓住敌舰并向阵型外拖动：G让它带着实际动量离开，打乱接近路线。重舰只能有限改变速度，不任意投掷。
- 抓住实体弹/环境物体：沿手动选出的方向释放，不自动返航或命中。

出射方向依据最近一小段有效拖锚运动，而不是增加第二个瞄准流程；静止时使用明确的目标到拖锚方向，若仍无方向则使用本舰到对象的向外方向。界面在按G前显示实际送离箭头，保证可预判，不用隐藏手势识别决定结果。

启动失败保留合法连接；只有成功接受才付费、施加一次冲量并释放。结束后需松左键再抓，不能按住重复刷冲量。

## 武器联动：把繁琐工作交给火控，不交给玩家

### M质量炮

保留可靠的正常射击。核心候选联动为：

1. 抓住敌舰时，本舰质量炮优先把它作为火控目标，并使用其真实运动计算提前量；射界、射程和遮挡仍有效。玩家不用另外选目标/切炮组来兑现抓取机会。
2. 专用质量弹击中当前合法牵引目标时，可触发一次有限的牵引耦合工作，帮助抵抗目标推进；不额外增加单发损伤，不挂爆炸印记。
3. 这份耦合消耗同一投射器工作预算与幅能，按装配根/时间限频；炮弹飞到时连接已断、已换目标或投射器失效，就不触发旧连接效果。
4. 抓住友舰时，质量炮继续攻击正常敌方威胁，不能自动向友舰开火；不强制抢占队友火控。

这样炮与引力是同一条工作链：**抓取提供稳定战术目标，正常炮火提供压力，实际命中协助牵引，拖动把目标带到更有利的射线中。**

是否调整现有M炮火力、是否加入破甲弹药版本，需要单独平衡；不在“保留操作手感”的前提下偷偷换武器或强制重写旧配装。

### S偏转/近防

继续自动保护本舰，分别提供有限改道和真实拦截。无需把每种装备都做成新的主动按钮；它们保证玩家能持续关注抓取目标。

### XL投射器

保留当前抓拖规则。现有潮汐伤害强度是独立的待平衡项，不因为本轮操作简化就擅自删掉或加强。角色仍以战线干预和援护为主，不能后续又变成单体处刑主炮。

## 三个简单的典型流程

- **拆阵**：左键抓住关键敌舰并往侧面拖 → 质量炮自动配合 → 必要时F隔开护卫。不是每次必须按完整组合。
- **救援**：左键抓住友舰沿退路拖 → F偏开附近实体弹 → 需要时G托送并释放。本舰承担持续操作和暴露的代价。
- **反投**：捕获合适的实体弹/物体 → 鼠标拖出所需方向 → G释放。方向选错就可能浪费机会，不保证命中。

新手只用当前抓拖和正常火力就能正常作战；熟练度来自选谁、往哪里拖、什么时候分流/送离，而不是多按几层模式键。

## 逻辑与表现

- 无瞬移、无无限质量收益、无角度/寿命/伤害重置；模块按装配根处理。
- 外力、冲量与超速统一限幅；多投射器/重复进入/多个炮命中不得绕过上限。
- 真人友舰受力需有接受/退出机制；救援不是允许强制拖走其他玩家。
- F反馈出现在被抓对象的真实位置；G箭头和实际出射方向共用同一几何。目标运动、弹道弯曲和接触点都用权威结果。
- 不用巨大场圈、额外UI模式面板或假弧线遮住战场。辅助价值通过敌阵被拆开、实体弹偏离、友舰获得撤离速度体现。

## 下一步与验收门槛

先确认两个候选即时技能是否值得保留，不因已有F/G键位就必须塞满。如果F远端分流仍与右键重复、实际价值不够，应删改它，而不是再增加一层操作。

后续实施第一步只做“质量炮与当前抓拖的火控联动”，比较是否增加可控收益且不破坏原手感。然后分别验证F远端分流、G方向预测与援护授权。每块完成后集中类型检查、改动lint与相关生产场景；实际Worker、自然实战、正式画面、真人试玩分别报告。
