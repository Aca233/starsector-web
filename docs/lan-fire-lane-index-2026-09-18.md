## 修改

新增 `FriendlyFireLaneIndex`，只在既有严格原生同步 AI 阶段创建，第一次真正查询时才建立：

1. 按原舰船和武器顺序保留 `FRIENDLY_BLOCKED + SHIP` 的候选武器。
2. 首次需要目标时建立按 ID 的候选名单；重复 ID 保留原顺序，不将最后一个同 ID 对象覆盖到前面。
3. 不缓存位置、朝向、护盾、相位、死亡、实际目标选择或几何结果。每次查询继续读取实时值，保持原比较、首个命中和矢量运算。
4. 每个 AI 阶段结束在 finally 中 close；异常也关闭，过期索引或不同 roster 身份退回原扫描路径。
5. 自定义 AI/引擎方法、未知系统、被替换的名单读取器、引擎子类及多核 owner batch 不使用该索引；不放宽原生阶段资格。

原生 AI 阶段不会创建/删除舰船、改舰船 ID 或写武器 fireControl 决策；这些在其他阶段处理。此不变量是索引适用条件，不是跨帧缓存假设。索引不进入快照或持久化状态。
