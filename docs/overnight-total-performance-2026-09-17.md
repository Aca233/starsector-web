# 整晚战斗性能：留存旧版到当前版直接对照（2026-09-17）

## 总结果

密集百舰完整周期均值 **864.64 → 161.74 ms**：总耗时减少 **81.29%**，按此指标计算的周期处理速度是旧版的 **5.35 倍**。这不是各轮百分比相加/相乘，也不是 FPS 提高该倍数。

| 指标 | 留存旧版，ms | 当前冻结版，ms | 耗时减少 |
| --- | ---: | ---: | ---: |
| 完整周期 | 864.64 | 161.74 | 81.29% |
| 模拟 | 789.44 | 116.06 | 85.30% |
| 绘制提交 | 75.15 | 45.62 | 39.29% |
| 完整周期P95 | 1347.00 | 231.10 | 82.84% |

## 口径与起点

旧版为 artifacts/catalog-performance-before/：最早找到的完整生产构建，index 修改时间为昨晚23:03，已含最初首页优化，早于后续核心战斗优化。不是第一条用户消息瞬间的完整存档。新版为 artifacts/fuse-center-index/build-after/，包含截至最新近炸导弹中心索引的全部保留改动。当前源码相对该候选图的漂移文件数：13。这些后续/并行功能修改未计入本次结果；本文“当前冻结版”是最近一次已验证的性能优化构建，不是测量期间持续变动的实时工作区。

Chromium / ANGLE D3D11 / RTX5060，2560×1440、DPR1；100艘Onslaught，双方各半，seed 0x51180。密集布局列间距1000、敌我偏移500、行间距650；相同相机和缩放。360个1/60固定步，60预热、300测量，两个页面逐步交替执行，无同时推进/构建/剖析。完整周期包含模拟、视觉更新、绘制和 gl.finish。一组直接配对，不代表重复实验的统计置信区间。

## 可比性与限制（不能省略）

最初试跑发现前两艘舰的默认炮塔朝向因版本初始化差异相差90°，该次中止并排除。有效试跑将两版所有舰体/炮塔起始姿态显式统一，初始关键游戏状态检查点一致。

后续60～360步的关键战斗状态并不完全一致，存在跨版本演化差异。因此上述结果是**相同起始场景的版本净变化**，不能作为完全隔离的“纯性能补丁总收益”，也不能借此证明所有优化合并后战斗结果逐位一致。

两版结束均存活100艘。峰值弹丸：1789 → 1774；其中峰值导弹：980 → 977。页面/GL错误为零。保留所有不匹配的关键状态快照，没有屏蔽差异后宣称校验通过。其他用户/开发服务没有为了压测被关闭。
