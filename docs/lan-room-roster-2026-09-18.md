# 联机房间左侧统一舰船列表（2026-09-18）

## 交互与空间
- 真人与 AI 放在同一个左侧滚动列表，按队显示。相同实际配装合并成一行，显示舰体缩略图、方案名和数量。
- 队名旁提供「＋AI」及入队按钮，不再各占一行。队名可折叠；真人卡片压缩为身份、参战舰船与队伍选择。
- AI 行内直接增减数量、查看配装、改装单舰或整组。移除最后一艘需二次确认。
- 保留底部「添加 / 批量管理 AI」，用于配装选择、批量数量、复制及移动到其他队伍。
- 开战准备明细默认收起，当前阻塞原因与下一步操作仍显示。左栏宽度 260–316px，窄屏 230px；短屏隐藏底部重复说明。
- 个人战只在「独立 AI」区域按配装合并显示；每艘 AI 仍是独立战斗队伍，不改变敌我关系。

## 状态与安全
- 行内修改复用 submitAiFleet 的修订号、请求 ID 与服务器确认，不做乐观数量更新或自动重试。
- 一次只允许一个行内编成事务；等待确认时禁用其他行内修改、批量入口及准备 / 开始。拒绝时保留真实数量并显示错误。
- 客机只提供查看入口，房主在可编辑状态下才可修改。
- 行内改装结束直接返回左栏，不弹出批量管理窗口；从管理窗口进入改装则保持原来的返回行为。
- 个人草稿持续保留；左栏折叠和滚动状态由房间工作台持有，返回后再等待底栏布局测量恢复滚动，避免临时高度夹住滚动位置。
