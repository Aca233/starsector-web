# 武器威胁可达范围裁剪（2026-09-17）

## 结论与范围

本轮不降低画质、粒子数量、模拟频率、AI 更新频率或威胁预警时长。为武器威胁预测加入保守的可达范围判定，在计算精确炮口、距离和径向接近速度之前，排除整个预测窗口内不可能形成威胁的挂载。

**这还不是整舰级空间索引。** 仍逐个读取挂载及实时射程，但多数远处挂载不再执行昂贵的精确几何计算。没有把“不在当前射程内”当作“不会构成威胁”，敌舰在排散窗口内接近的情况依然保留。

两轮百舰完整工作耗时分别降低 **11.3% 和 5.4%**，两轮 P95 均有改善，保留本轮改动；收益是有限的，不只报告较好的一轮。

第一轮生产浏览器对照，百舰模拟均值 **153.615 → 133.029 ms（降低 13.4%）**，完整轮次 **186.456 → 165.427 ms（降低 11.3%）**；完整轮次 P95 **235.3 → 206.5 ms**。

**尚未达到百舰 180 FPS，也未实现体验上的质变。** 180 Hz 展示预算只有 5.56 ms；当前百舰渲染提交仍约 32 ms，模拟也远超 60 Hz 的 16.67 ms 预算。下面的脚本耗时不是实际 requestAnimationFrame / 物理显示器 FPS，不应直接取倒数宣称游戏帧率。

## 为什么能够提前排除

用 `D` 表示目标护盾中心到敌舰原点的最大轴向距离（L∞）；用 `E` 表示当前挂载及当前枪管偏移的 L1 范围。旋转不会让任意一个轴上的炮口位移超过 `E`。

对当前实时射程 `R`、目标原有预测半径 `r`、完整窗口 `H`、原有运动统计 `U`，以及敌我相对速度 `V`，若

`D > E + R + r + H * max(1, U.maxSpeed + abs(V.x) + abs(V.y)) + 数值余量`

则原有 `approachTime` 必然超过预测窗口，不必继续计算该挂载。径向接近速度不会超过相对速度的 L1 范围，原 normalize 的近零分支也满足此约束。

- 余量按坐标、射程、偏移、接近距离的尺度扩展；模糊边界仍执行精确计算。
- 非有限预警窗口不启用裁剪；不可判定的范围保留原路径。
- 使用实时射程，覆盖 ECM 和舰船系统效果；不是裸武器标称射程。
- 炮口范围逐次读取可变挂载位置、偏移数组及当前 barrelIndex，支持炮塔 / 固定挂点的偏移回退、负数和非整数索引；不缓存可变几何。
- 所有保留候选继续使用原炮口、Math.hypot、转向、恢复、准备、接近、飞行和爆发伤害算法。

## 副作用与动态状态边界

只有审阅过的内置舰船系统统计回调及原生 hullmod 射程回调，才允许将射程读取提前到炮口读取之前。

- 注册表以私有 WeakSet 标识当前受信任的定义；第三方注册不会自动获得标识。
- `ShipSystem.hasNativeStats` 同时检查当前辅助系统，不缓存系统状态或效果值。
- 自定义系统 / 辅助系统 / hullmod 保留原回调调用次数、顺序及实时状态读取。
- 目标侧护盾承伤回调也可能修改其他舰船。到达一次 `add('WEAPON', ...)` 后，保守停用该敌舰剩余挂载的预计算范围，避免复用回调前的位置、速度或装配状态。
- 不引入跨舰、跨 AI 更新或跨帧的活动状态缓存。
