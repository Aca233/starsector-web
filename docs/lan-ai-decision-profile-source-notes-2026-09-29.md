# 大规模战斗规则 v1：AI 决策分频（2026-09-29）

## 授权与原版对照（编码前）
- 用户明确同意以自动单位决策细节换性能；独立规则，默认 standard，非原版等价优化。
- 本机 `starsector-core/localization_version.json` 声明游戏 0.98a-RC8。
- `decompiled/starfarer_api_source/com/fs/starfarer/api/combat/ShipAIPlugin.java:13-25`：AI 支持周期性环境评估，接管自动驾驶时须立即评估，advance(amount) 是决策入口。接口未指定 20Hz，不能据此宣称原版也是 20Hz。
- `ShipSystemAIScript.java:7-8`：技能 AI 收取危险方向和目标。与技能本身的物理/冷却推进分离。
- 原版实机/UI 对照：待核实。用户不允许桌面操作。本项是 Web 联机扩展，仅在既有房间设置加规则项，不改原版战斗 UI。

## 预期行为与明确代价
- standard 完全保留现有路径。现有部分战术/远期威胁已经 20Hz，不能把该工作重复算作新增优化。
- large-battle-v1：普通 AI 舰及其自动模块整套 CapitalShipAI 决策按模拟时间 20Hz 采样，错开相位；其间保持控制指令。运动、转向积分、武器发射/碰撞/伤害、护盾/技能/冷却状态仍每物理步推进。
- 真人控制舰（包括自动驾驶）及其模块完整频率，不用 isPlayer 判断，它在本项目还有队伍含义。
- 普通 AI 防御、避碰、技能选择响应可能延迟至 50ms；不是仅降低导航规划，也不保证与标准规则同样强。紧急失效、接管、战术指令编辑、目标失效、过载/排散状态切换立即评估。
- 不减少实体、炮位、粒子和画质；不改 ACK、校验、过载保护及物理频率。未实现副炮分组和舰载机编队。
- 房主在大厅/结束时选择，服务端只接受标准枚举并复制到 Match；开战锁定，客机不可自行更改。LAN/Steam 共用房间服务。
- 分频规则暂不兼容 AI owner 预计算，明确退回串行主机决策；不默默绕过分频。

## 验证计划
1. 完整实现后一次 tsc、改动 lint、针对性规则/时钟/引擎/服务端测试。
2. 冻结源图及资源：旧默认 vs 新默认逐步五段 wire/authority/hidden/receiver 一致；新规则独立重复确定性一致（不要求标准/简化结果一致）。
3. 独立 Node ABBA，仅一组：150冷+120热，2玩家20AI，seed917，3200DP。热 simulation 与完整五段每对均改善至少5%方可称该场景性能收益；冷完整链路回退不超过3%。改变AI会改变轨迹/伤害，不将差值冒充纯代码等价加速。
4. 离线不是实际联机输入延迟验收，记录开场/交火覆盖及未完成范围。默认关闭，未验收不发布。
