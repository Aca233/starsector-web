## 完整玩法

| 部件 | 战力 | 丢失后果 |
|---|---|---|
| CORE | 全向护盾、三技能、100太阳能 | 核心毁灭，整舰战斗结束 |
| FORE | 内置固定XL太阳长矛；2M离子、2S近防 | 失去主炮与前方压盾/近防；默认由玩家接管 |
| PORT / STARBOARD | 每翼1L裂解、1S近防、2航空甲板 | 该侧停炮、停补机；未毁侧仍可战斗 |
| AFT | 2M离子、2S近防、工程供能与主推进 | 航速-45%、转向-25%，太阳能恢复从2.5降到0.8/秒 |

- 12个可替换挂点：6S、4M、2L；另有1个内置XL。锁定身份与固定/转动是独立字段。普通二维武器仍可同档换装；内置XL利用原生舰体发射口，不叠加一个通用炮头。
- 主炮：2800射程、6800能量、6200幅能，1.5秒蓄能+5秒间隔；3发电容，每10秒补1发。8度前向火控，必须用舰身对准。
- 离子阵列压盾，双联裂解破甲；小型棱镜优先近防，不是用同一炮缩放冒充四档。
- 4联队共14机：每侧4架截击+3架突击。截击优先护航，显式攻击命令可对舰；突击机每架4发1400高爆电容，真实弹尽返航、停靠重装再出击。两种装备使用同型原创机体，不伪称两张独立美术。
- 飞机有自身小型护盾/幅能；高幅能降盾，低幅能恢复。引擎使用现有绘制序列，去掉这两种飞机的重复通用尾迹。

### 默认操作

- 左键：舰艏主炮。其余模块自动火控；HUD可接管其他模块，再返回本体。移动、舰盾与技能始终在CORE。
- 右键：正常全向星灵护盾。不是荣光女王的虚空盾，不免疫幅能。
- **F 太阳锻炉**：40太阳能，8秒舰体能量伤害+45%、射速+20%；幅能成本+35%、耗散-15%、航速-35%。
- **G 护盾超载**：先升盾，35太阳能，7秒护盾承伤-65%、维持耗能+50%；模块能量武器幅能+25%。不清硬幅能。
- **H 重构光束**：50太阳能，6秒，每秒修复存活模块1.5%最大结构与近旁己方舰载机12%结构；舰体能量伤害-60%，飞机可掩护。不修装甲、不复活已毁模块。
- 三能力互斥、工作时停止太阳能恢复；过载/排散中断，已消耗资源不退。
- 方舟不享受普通舰船的零幅能+50航速；太阳锻炉启动后仍保留工程段战损。两个航速百分比惩罚按宿主规则相加：工程段损毁且锻炉全功率时为基础航速的20%。
- **Z**：整舰存活甲板联队召回/出击，适合重构时收回受损飞机。**V**排幅，**1–4**切换当前接管模块的武器组。
- 在设计页选“亚顿之矛 · 方舟”，装配方案选“方舟 · 太阳战阵”，再进入模拟战斗。旧舰仍单独保留。
