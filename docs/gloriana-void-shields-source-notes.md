## 本轮规则
- 核心携带4层屏障，每层6000承载；独立于幅能。部署时满层且自动上线，360度覆盖整个固定模块编组。不同伤害类型按原始伤害等额消耗屏障，普通护盾效率不参与；总体承伤/CR仍有效。
- 从外层逐层击穿；同次伤害穿过全部剩余屏障后，残余沿原弹道/光束继续结算，不白吃余伤。外部范围伤害先作用共享屏障一次，再结算未阻挡的模块伤害，不按9个实体重复扣盾。
- 受击后5秒内不回复，包括核心/模块装甲或结构受击。屏障全灭后至少10秒锁定，之后按每秒1000重建；首层完整重建后才重新上线。其他层依次回复。
- 右键可关闭/开启屏障，开关不刷新承载或冷却；关闭期间允许安静重建。武器过载/主动排散临时暂停屏障与重建，结束后按原开关状态恢复。死亡/离场不重启。
- 普通舰体和现有原版护盾/相位规则保持不变。虚空盾不修复装甲、不复活模块；没有机库/光矛新资源。
