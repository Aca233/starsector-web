## 本轮仅补材质/光影与可编辑分层

1. 保持模型顶点、相机、取景、帧、分辨率不变。不得改变长宽、镂空、连接或添加槽位。
2. 在可编辑Blender材质中区分金色装甲与非金属区域，适当降低装甲饱和度，保留星灵的金/蓝身份；使用原贴图，不虚构新的表面机构。
3. 统一左上主光，减弱多方向填光，使凸起与凹部在游戏尺寸下可读。使用局部接触遮蔽辅助现有结构，不用黑描边改剪影。
4. 能量面减轻大面积均匀高亮，不烘焙外围光晕、光束或引擎火焰。
5. 导出同相机的合成图、漫反射色、发光、法线/深度等实际支持的渲染层，保留处理场景和参数。分层源文件仅供美术，不作为游戏依赖。
6. 在512×1024与常见缩放下并排检查；原型材料处理不自动视为最终手绘精修或用户批准。

## P6 本轮交付：同坐标状态图与可见区域分层

### 已做

- 从已认可的 v02 可编辑场景继续处理，不改顶点、UV、源贴图、相机和第 0 帧姿势。用 Blender Bevel normal shader 增强既有装甲边缘厚度（0.0045 源单位，约半像素）；这不是手绘精修，也不添加新面板或几何。
- 512×1024 正常自发光 / 关闭材质自发光两张透明图。后者由真实材质重渲染，不是全图压暗；蓝色基色保留，不称为完整“停机”“技能关闭”或“损毁”状态。
- 固定结构、核心机构、前部机构的三个 object-ID 可见区域蒙版；保留真实 Emit / DiffCol / Normal / Depth / AO / IndexOB 等 EXR 层与可编辑 Blender 母版。
- 输出状态对照、100%/65%/35% 像素尺寸检查和部件着色检查板。所有检查板均非游戏截图，彩色标注不是最终舰体涂装。
- PNG、无损 WebP 解码后逐像素 RGBA 一致；两份 WebP 合计 493,414 字节（约 482 KiB）。每张解码 RGBA8 为 2 MiB，两张 4 MiB，不含 mipmap。Blender / EXR / 蒙版 / 检查板仅用于离线制作，不计入运行资源。

### 集中验证结果

- 与认可稿的 alpha 轮廓 IoU 为 0.999890；两种状态之间为 0.999307（阈值 16）。边界均为 `[49,23,463,1001]`，未裁切。
- 两状态 alpha **并非逐像素相同**，差值最大 19/255，平均 0.03787/255；单独渲染存在采样边缘差异。将来若做过渡混合，仍需统一边界和验收闪边，不把该结果称作已经无缝可叠加。
- 三蒙版覆盖全部高 alpha 舰体像素（alpha≥250），但仅代表可见表面选择，未验证用它们拆图重组是否无缝，不能当作已完成的独立旋转资产。
- 已实际查看：正常态保留金/蓝身份；关闭自发光后可辨原装甲与暗机械。65% 下主要镂空和装甲区可辨；35% 下部分细暗肋和前部小机构开始合并，不能宣称小炮位仍清晰可操作。
- 本轮没有改变游戏逻辑或资源，未运行游戏类型检查；图像检查通过不是装舰验收通过。

### 骨架证据及后续边界
