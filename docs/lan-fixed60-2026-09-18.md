# 联机固定 60Hz 目标（2026-09-18）

按用户要求取消 2/5/10/20Hz 自动降频，协议 v25 统一快照目标 60Hz。房主对每轮完成的最新物理状态尝试发布，服务器对就绪且 socket 无积压的客机逐帧转发；不再按舰队规模/CPU 预算或拥塞反馈降低目标。物理仍为 1/60，不发重复快照凑频率。

保留单个在途主机快照、有界解码队列、socket 背压、消息大小/速率保护与原有物理过载保护。高负载仍可能达不到 60Hz，且更频繁的采集、编码、解码可能降低可承受舰队规模。AI 多 Worker 继续默认关闭，不自动试跑。

同时修正旧 HUD 接收间隔最低 50ms、显示最多 20Hz 的统计钳制，改为统计真实最近一秒收到的有效快照数。首秒/重连重新测量；断流自然降到 0，目标与实收分开展示。

## 验证

- 类型检查、全项目 lint、独立生产构建通过；已有大 chunk 构建警告保留。
- 34 项计数与过载预算诊断通过，覆盖 2/5/10/20/30/60/120Hz、断流、批量到达、重置。
- 最新主机 32 舰诊断：AI pool 构造/准备/预算试跑次数均为 0。
- 真实浏览器房主 + 协议客机，两个人控舰、无额外 AI、6.007 秒：收到 358 个不同 tick，客机平均 59.595Hz，物理约 59.928 步/秒；目标均为 60，零页面/协议错误。浏览器房主当时 HUD 显示 57Hz、战斗 1.00×。此为低负载验证，不是百舰承诺，也不是客机浏览器完整渲染性能。
- 临时诊断浏览器与服务器均已关闭。
