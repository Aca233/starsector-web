# 渲染热点实验复盘（2026-09-17）

## 结论

本轮两个候选实现均撤回，**没有保留新的生产性能改动**。此前的武器威胁可达范围裁剪、弹道几何与尾迹优化保留，不降低画质、模拟/AI 频率或预测窗口。不能把顶点数量、上传字节或 draw call 的下降直接当成用户可感知的提速。

`RibbonBatcher.ts` 已恢复到本轮冻结基线，回退时验证冻结的源文件集合无差异；没有重置工作区或撤销此前修改。

## 测量口径

- Chromium / ANGLE D3D11 / RTX 5060；2560×1440，DPR 1；固定种子 `0x51180`，100 艘 Onslaught 同屏战斗。
- 完整工作负载：两个隔离页面交替执行，共 360 个固定步长（1/60 秒）轮次，前 60 次预热，后 300 次统计；每次含模拟、视觉更新、一次渲染及 `gl.finish()`。不与构建或分析任务并行。
- 固定状态渲染：先模拟 180 步，再渲染 180 次，前 30 次预热；每次提交后执行 `gl.finish()`，但渲染提交计时不包含该等待。
- **这些是脚本工作耗时，不是实际 rAF / 显示器 FPS。** 不同轮次基线存在波动，不将跨轮次数字拼成累计收益。

## 候选 1：喷焰与脉冲扇形索引化（撤回）

保持原三角形序列，减少重复顶点；受影响网格的顶点加索引上传字节示例减少 43.75%。

| 百舰指标 | 基线 | 候选 |
| --- | ---: | ---: |
| 完整工作轮次均值 | 131.912 ms | 128.161 ms |
| 其中模拟均值 | 105.226 ms | 102.767 ms |
| 其中渲染提交均值 | 26.632 ms | 25.334 ms |
| 完整工作轮次 P95 | 162.8 ms | 154.2 ms |
| 独立固定状态渲染均值 | 26.117 ms | 29.205 ms |
| 独立固定状态渲染 P95 | 32.0 ms | 42.6 ms |

完整轮次仅减少约 2.8%，且大部分差值来自未修改的模拟代码计时波动；固定状态渲染反而慢约 11.8%。没有稳定证据支持保留。

验证：10/50/100 舰完整工作负载引擎状态哈希一致，页面和 WebGL 无错误。16 个几何/溢出/状态切换场景的展开三角形数值一致，非 MSAA 像素零差异。非有限输入的 NaN 位模式受 JIT 影响，数值比较只规范化 NaN，原始位哈希另存。

**不宣称 MSAA 像素相等。** 默认与受控 4×MSAA 密集叠加样例存在像素差异，旧实现对旧实现的控制组也有差异，因此该实验不足以归因视觉回归，也不能证明 MSAA 完全一致。

## 候选 2：CPU 打包顶点复用（撤回）

从基线单独实验，保持原 GPU 三角形数据流和刷新边界，通过 `Float32Array.copyWithin` 复用重复顶点。

百舰固定状态渲染均值 **27.511 → 27.876 ms**，没有改善；绘制次数相同（5672 次精灵 + 3814 次 ribbon）。引擎状态哈希一致，无页面或 WebGL 错误。因目标渲染负载已无收益，未继续完整动态负载或像素验证，也不将候选 1 的验证套用到此候选。

## 当前瓶颈与后续方向

当前基线的完整帧 CPU 采样中，威胁评估仍是突出的模拟热点（120 步样本中约 5528 ms self）；渲染内的喷焰、移动脉冲、缓冲上传和提交仍明显。采样用于定位，不能与无采样基准混算收益，父子调用的 inclusive 时间也不能相加。

180 Hz 的展示预算为 5.56 ms。这里百舰仅渲染提交就约 26–28 ms，完整轮次还包括约 105 ms 模拟；小幅优化不会使该压力场景产生体验质变。

下一步应优先评估：

1. 原生 AI 阶段共享重复威胁查询，严格处理可变状态、挂载及自定义回调的失效边界；尚未实现。
2. 只在现有连续加法混合特效块内部合并引擎尾焰/光晕提交，减少程序、VAO 和纹理切换；不能跨船体、普通透明混合或其他有序图层重排，需验证自定义颜色、混合舍入及 MSAA；尚未实现。
3. 继续要求同场景完整负载重复对照与尾部耗时改善，不以局部计数代替收益。
