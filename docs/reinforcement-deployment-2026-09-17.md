# 局内增援与后备舰队（2026-09-17）

## 操作

- 单机舰队：舰队 / 存档中选择旗舰，勾选其它首发舰，未勾选的可用舰船进入后备；部署点上限在战前确定。战斗中 Tab → G 打开增援。
- 联机：房间设置 → 高级部署：首发与后备。真人舰和各队旗舰首发，AI 按编成顺序填充首发目标，余舰待命。房间战斗规模换算出的每队额度在开战时锁定（整合并行的 battle-size 规则）。
- 选择和部署不请求暂停。取消只关闭增援面板；成功部署后关闭面板及地图。联机必须收到主机确认才显示成功；错误、超额、过期选择保留面板并显示原因。
- 地图可下达撤退；驶离本方边缘后才释放部署点。已撤离 / 已损失舰船不能在同一场战斗中作为新舰重新部署。联机不能替另一个真人玩家撤退；全面撤退只处理自己的真人舰及本队 AI，并撤回未出场后备。

## 统一实现

- CombatDeployment 是每场战斗的后备名册、额度和状态的唯一所有者。状态包括 reserve / deployed / retreating / retreated / destroyed。
- allCapitalShips 表示完整身份名册（含待命和已撤退）；capitalShips / ships 表示当前战场查询。后备舰不参与 AI、碰撞、伤害、PPT/CR推进、武器开火或航母补充，也不提前释放舰载机。
- 后备舰保留同一 Ship 实例和完整装配、结构、装甲、弹药、CR、组件状态。实际部署只更新入场位置、朝向及活动成员资格，不重建一艘满状态新舰。
- 部署整批先验证队伍、重复 ID、状态、费用和可用位置，再加入活动世界。编成以外、敌队、已出场、重复与超额请求均拒绝。
- 入场位置由本方固定战场边缘及碰撞半径计算，不追随玩家位置。当前 Web 使用半边长 6000 的逻辑边缘，多队按战前方位确定入口；不是声称所有原版战役地图尺寸已复刻。
- 模拟战仍允许从目录添加敌 / 友舰，但共享入场位置规则，费用由内容定义校验，不信任 UI 传入的小数值绕过额度。
- 新舰的 deploymentPoints 优先；原生导入从 ship_data.csv 的 supplies/rec 保留部署点。旧内置记录通过 sourceHullId 查询原生费用，不能拿 OP、舰队战力或舰级猜测；缺失费用明确拒绝。

## 胜负与结算

- 纯 AI 阵营每 5 秒按空余额补充后备；有真人的队伍由玩家呼叫。某队在场主舰全部损失时，自动呼叫可部署的下一波，然后再判定胜负，避免还有可用后备却提前结束或无限等待部署。
- 全面撤退会撤回未出场后备，不会在最后一舰离场后又自动叫回来。
- CombatRequest 增加可选 initialPlayerIds / initialEnemyIds / deploymentPointLimit；旧记录缺省各队旗舰首发。首发名单必须属于对应舰队、包含旗舰且费用有效。
- CombatHandoff 按完整身份名册结算；始终未出场的舰船原样回写，不扣除战备、不改变弹药 / 装甲。已出场舰按实际结束状态捕获；绕过名册加入的非临时主舰仍拒绝不完整结算。

## 联机权限与同步

- 客机只发送对局 ID、请求 ID、操作及舰船 ID，不能传船型或指定费用直接生成主舰。
- 服务端核验连接席位及其队伍，越权请求返回独立失败消息，不使整场战斗退出。主机 Worker 再校验活动状态、权限和实时额度。
- Worker 对请求 ID 缓存结果；同一请求重送不重复部署，换新请求 ID 再调用已出场舰仍拒绝。错误操作不会进入 Worker 的致命错误通道。
- 完整名册在双方初始化时就有稳定 ID，部署后的主舰不依赖未登记的临时 ID。待命舰仅同步轻量状态，激活后发送完整组件及新增舰载机快照。
- 首个激活快照将前一帧位置对齐到实际入場位置，避免插值把待命位置到战场边缘画成横扫 / 跳船。
- 联机地图的普通战术指令未接入主机，因此不允许它们修改客机世界；本次开放观察、增援和撤退，不把无同步的本地命令冒充联机命令。
- 协议已随本轮及并行战斗规模变更升级；旧服务需重启，所有客户端刷新并创建新房间，不支持混用旧协议或迁移正在进行的旧对局。

2. 敌队、重复ID、已部署ID、超額和模拟战费用伪造拒绝；新原生舰费用导入与自定义显式费用验证通过。
3. 边缘入场、边缘撤退、DP释放、撤退舰不可重刷、全灭后下一波与最终失败、全面撤退不自动增援通过。

5. 8艘 / 3队 / 2控制席位场景：首发3艘、客机视角、部署后主舰及舰载机快照、入场插值、纯AI增援和真人保留后备通过。

## 已知边界

- 浏览器验收的前两次长时间停留触发了既存“计算主机无法跟上”保护；重开后完整增援交互和确认通过。本轮没有通过放宽保护阈值掩盖它，也不宣称已通过长时间 / 大规模性能验收。
- 目前同场不允许撤退舰重新上场；没有补上原版所有战役非对称DP分配、转移旗舰控制或其余联机战术指令。
- 后备名册仍有内存、内容预载及通信安全预算；轻量快照不等于无限舰队容量。
