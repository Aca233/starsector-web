# 可装配舰船技能（2026-09-19）

## 使用

- 造船/改装右侧 **装配舰船技能**：添加、卸下、上下排序、恢复舰体默认技能。修改的是自定义方案，不写回原版船体。
- 技能库复用原版效果定义，不复制数值。当前不收取技能 OP，不引入等级或解锁体系；同一技能不能重复装配，也不能与独立防御槽重复。
- 默认 F / G / H 对应槽 1 / 2 / 3。更多槽可点击战斗 HUD，或在装配窗口/游戏设置中绑定未占用的字母键。
- 点击键位后按字母改键，Delete/Backspace 清除；冲突会拒绝保存。数字键仍归武器组，移动、防御、浏览器组合键不会被覆盖。按住 Shift 操舰仍可直接使用技能。
- 可选启用 **Shift + 滚轮** 轮选，默认 **J** 释放选中技能。普通滚轮仍缩放；F/G/H 直接释放不受轮选影响。长按不重复触发。
- 联机帮助由 H 改为 F1；战术地图中的 G/H 指令保持原样。

## 配置与兼容

`ShipSpec.systemTypes?: string[]` / `Design.systemTypes?: string[]` 是有序装配列表。

- 未提供列表：读取已有 `systemType`，原版默认技能及旧方案保持不变。
- `[]`：明确不装战术技能，不能回退到原技能。
- 列表 ID 支持现有源别名解析；重复别名等同于重复技能。
- 最大 64 项只是文件/网络输入的安全边界，不是 OP/等级槽位机制。
- 独立右键防御继续使用 `defenseSystemType`，不改变相位护盾的所有权。

## 实现

- `ship.systems` 是独立 `ShipSystem` 实例列表：每项分别持有阶段、计时、次数、目标快照和待消费的使用成本。
- `ship.allSystems` 包含战术技能与防御，用于更新、事件派发、离场/战沉/过载处理。CR 的系统与防御禁用规则仍分别执行。
- `ship.system` 保留为旧代码的第一槽/组合属性入口；现有 `auxiliary` 组合链扩展至其他战术技能，末尾是防御。不通过替换 `ship.system` 来执行技能回调。
- 属性遵守原有加算/乘算组合，武器/防御/运动限制取合并约束；没有暗中更改原技能数值。共享幅能时，激活校验计入所有技能同帧已预留成本。
- AI 显式传入 `context.system`，各行为只激活自己的实例。音效在整组层面协调循环声，资源闭包遍历所有技能。
- 装配约束由定义的 `installReason(spec)` 声明：常规护盾、舰载机、SYSTEM 发射器、微光挂点或镜像配对方案。缺少依赖不允许新增。没有凭空添加专用发射器，也没有把依赖不足伪装成可用技能。
- 草稿、导入/导出、LAN 方案保留列表；命令的 `value` 为零基槽位。省略 `value` 兼容第一槽。
- 联机快照保留各实例状态，`auxiliary` 是由本地配置重建的只读拓扑，不递归发送。现有仅支持单技能的 AI 多核标量协议对多技能船安全回退到主线程。
