# 万有引力号 · 引力弹弓方案 v4

> 已被用户最新定位修订：本舰主打引力、偏向辅助，是实验舰。当前推荐设计见 `gravity-ship-gameplay-v5-support.md`；本页保留上一稿，不再以手动质量主炮作为核心方向。

日期：2026-09-30。状态：本次重新设计的推荐方案，未实装、未完成平衡验证。保留用户选定的原B主体与等体量场驱动尾段。舰船继续无护盾，不增加相位、无敌或隐形防护层。

本稿回应“重新整一套技能和武器联动的方案，用上F、G、左键、右键，操作性好、可玩性高、上限高”。不自动把设计改成运行规则。当前工程仍是v3：F引力井、G惯性折转、右键本舰排斥；2026-09-30续接时既有规则场景主线程与真实Worker各86项通过，这不证明本稿已经实现。

## 核心选择

玩家直接操纵主炮输出，用一个固定引力锚改变战场几何，再决定何时把吸引变成向外传播的一次排斥。机动始终有独立入口。

四个操作围绕一个锚点与实际动量，不增加手动牵引器、叠层资源、第二准星或技能模式菜单。引力不制造额外爆炸伤害；收益来自入射角、到达时间、队形和射线的变化。

旧方案让左键用于零伤害牵引、主输出自动，精确拖动又与放井共用准星，容易分散玩家的注意力。本稿把左键恢复为可靠射击。F负责持续吸引，G负责远程释放，右键负责本舰机动，职责清楚。

## 四键固定语义

| 输入 | 固定作用 | 操作反馈 |
| --- | --- | --- |
| 左键按住 | 当前主武器组持续射击；默认是内置质量主炮 | 普通瞄准与炮塔转动，没有蓄力后松键才射或单击/长按分支 |
| F按一下 | 在按键时准星位置部署一个固定引力锚；存在锚时再按F安静收回 | 放置范围、作用边界、剩余维持时间清楚可见；失败不扣费 |
| G按一下 | 将当前锚转为一次向外传播的排斥波，波结束后锚消失 | 波从锚点产生，有实际传播时间；没有锚时明确显示不可用 |
| 右键按一下 | 沿当前移动指令做一次短促场驱动滑移 | 接受时方向锁定，移动准星不会继续改道；右键无护盾功能 |

WASD、舰首控制、武器组、自动开火和V排散沿用宿主。左键仍遵守武器组语义，不强行覆盖其他武器组。F/G沿用可重绑的系统槽。

### 右键方向的操作约定

右键采样当前WASD的世界移动方向，斜向输入归一化；因此玩家可以持续瞄准敌人，一边侧移一边右键加强这次侧移。它不按舰艏方向猜测，也不沿着当前惯性自动加速。

没有移动输入时，默认沿“准星→本舰”方向后撤；准星与舰心重合则沿舰尾方向后撤。方向成功接受时提交，之后不会追随鼠标或按键。

右键从静止也能启动，不要求先攒速度。它在短时间内真实施加有限推进，加速度与新增航速均有上限，不写位置、不穿碰撞。原有动量仍参与结果，高速反向输入先抵消动量，不保证立即掉头。

## F · 引力锚

F锚固定在世界坐标；它不是持续追踪敌人的锁定，也不会随鼠标免费移动。

- 范围内多个敌舰和支持的实体敌弹受到朝锚心的有限吸引。目标仍可推进、转向和开盾，中心柔化，不强制聚成一点。
- 本舰发出的兼容质量弹可以借自己的锚有限弯转；普通友弹、队友炮弹与友舰豁免。场形选择性属于Web玩法规则，不宣称严格物理模拟。
- 炮弹入场后才受力，不在场外隐形修正。每弹只绑定一个自己的锚，限制累计弯转与耦合时长，不能永久盘旋蓄弹。
- 收回F立即停止吸引，目标和炮弹保留当时速度。安静收回不生成排斥波；是节省幅能、避免错误弹道的主动选择。
- F维持、射击和机动共用幅能，满负荷并行会缩短持续作战窗口。

锚放在目标正中是易懂的控场；放在目标侧面或弹道侧面才可能获得较好的射击角度。放错位置可能把敌舰拉近自己，或使炮弹提前撞上障碍。

## G · 弹弓释放

G成功后结束该锚的持续吸引，从相同世界位置发出一次排斥波。G不是远程伤害爆炸，不自动瞄准目标。

- 敌舰按接触侧、距离与整舰质量获得有限径向冲量；重舰的运动变化较小，模块不能被单独扯散。
- 支持的实体敌弹与本舰兼容质量弹同样按真实波前接触受力，每对象每波至多一次；不改阵营、伤害、年龄、寿命或补射程。
- 炮弹处在“锚心→目标”一侧时，有机会被向目标推送；处在错误一侧时，也会被推离目标。不是按G后所有炮弹自动拐向准星。
- 空场可以用于推开敌舰、救队友或干扰弹幕，不必先射炮。但没有可用锚就不能凭空产生远程波。
- 失败的G不收锚、不消费，不打断正在射击或右键机动。成功后的锚进入释放状态，不能同帧收回/重放规避恢复。
- 结束时的冲量与多来源外力统一限幅。多舰、多弹有处理数量和总动量预算；饱和弹幕可以漏过。

G是“结束这次持续控场，换取一次瞬间改变局势”的取舍。早释放可能错过炮弹或提前救走敌人，晚释放可能让目标脱场或炮弹先撞上。继续吸引和立即释放都应有可行收益。

## 右键 · 矢量滑移

无盾舰的主动生存入口，与F/G的进攻周期独立。

- 短促、可读、有限距离的真实场推进；能用于侧闪、后撤或换射击角度，过程中仍会受伤。
- 保留两次储备，逐次恢复；每次另收软幅能，短锁定防止同一帧连续消耗。用尽后有明确的恢复空窗。
- 不清除来袭攻击，不返还已受伤害，不解除过载/排散；动力失效、死亡、撤退或系统离线不能启动。
- 不取消F，也不重置主炮、F或G冷却。离开锚的维持距离仍会断场。
- 滑移时继续按真实炮口与当前舰速发射，已经出膛的炮弹不会跟着舰体移动。

玩家通常可以保留一次滑移撤退，也可以连用两次抢侧面，但后者失去紧接着的逃生余量。光束不会被引力推开，躲避要靠真实离开照射线。

## 武器组成与联动

初始挂点账本沿用1L、4M、6S、0XL的数量草案；尚未标定正式安装位置、射界、OP或合法配装，不据此宣称已可安装。L由牵引器改为主炮，属于本次玩法推荐。

### 1L内置 · 惯性质量炮

默认第1组、手动瞄准，按住左键按固定节奏发射清楚可见的重质量弹。不蓄力、不要求先放锚，正常直射就能可靠压盾。

- 初版采用动能伤害，真实盾/装甲/遮挡与宿主正常结算一致；护盾仍能拦下，没有“技能连招必穿盾”。
- 发射速度适中，让炮弹有可观察的借锚与G推送窗口；不会为表现威力设成瞬间抵达。
- F改变实际行进方向，G改变入射方向和到达时间；不额外给连招伤害倍率。
- 正常直射应有竞争力。曲射目标是绕开特定射线阻挡或争取侧面入射机会，不能当作每发都必须完成的仪式。
- 弯转和推送后按实际路径消耗射程；空射正常耗散，击中实体正常终止，不重复引爆、不生成无限有效尾段。
- 命中可带小幅沿入射方向的有上限冲量，按质量响应；不新增撞船爆炸或叠加无限击退。

### 4M可换 · 潮汐破甲副炮

默认自动、低频高爆实体弹，负责把主炮压盾及控场创造的窗口转换为装甲伤害；仍可按宿主方式手动接管。

- 副炮的自动火控瞄准敌人真实位置和运动，不瞄准空锚心，不因“在井里”就视为必中。
- 兼容专武弹同样能借自己的锚和G，但不自动选择不存在的理想曲线。AI必须在可验证的拦截解成立时才用曲射，否则正常直射。
- 较慢射速与发射费用使G时机有取舍：等副炮抵达锚侧，还是先释放解围。
- 可替换其他同档合法武器；卸下兼容副炮后，F/G仍能控敌舰与敌弹，核心舰船不依赖强制装满专武。

### 6S可换 · 偏轨阵列与常规近防

默认2S偏轨＋4S常规PD；偏轨只处理预测将威胁本舰的支持实体弹，有射界、转速、次数和每秒动量预算。PD真正攻击可拦截导弹与战机。

偏轨不成为持续360°护盾；密集齐射和高动量弹可以突破，导弹被推偏后可能重新追踪，光束不受影响。F/G主动处理战场，日常防守仍会漏弹。

控线配装可采用4S偏轨＋2S常规PD，较侧重实体炮雨；代价是对跟踪导弹和战机的处理不足。该分支的OP及实战强度待编译/验证，不预填虚假预算。不再另外添加必装的专属插件来补齐基础能力。

## 四条可执行路线

### 基础压制

左键可靠直射 → F放在敌人路线侧面干扰走位 → 右键侧闪或后撤。G可暂不使用。基本输出和生存不依赖复杂连招。

### 弹弓射击

F放在目标与射线的一侧 → 左键沿锚的边缘发射 → 炮弹受有限吸引进入曲线 → 在炮弹处于朝向目标的释放侧时G。

收益是改变射线、入射角和到达时间，仍须瞄准；早按、晚按或放错锚都会降低命中。提示轨迹只呈现当前真实条件下的短程预测，不自动修正射击。

### 拆阵绕侧

F放在护卫队形侧面 → 右键侧滑，改变自己的射击位置 → 左键压迫暴露的护卫 → 看局势继续维持，或G从锚点把它推出原保护位置。

这条路线不要求炮弹曲射。G方向由锚与目标的几何关系决定；放在错误一边可能把敌人推回队友身后。

### 撤退与护航

F放在追兵路线或来袭弹幕侧面 → 本舰正常后撤/右键滑移 → 若目标进入合适位置，再G推离追兵或推偏敌弹。

不是瞬间罩住队友的无敌圈。G传播需要时间，临时F→G来不及处理贴脸高速攻击时，应依靠机动或已有PD；这保留了提前布场的价值。

## 深度与反制

| 技巧 | 可测量的收益 | 可能的失误 |
| --- | --- | --- |
| 预判F位置 | 迫使敌人修正路径、打开射线 | 把强敌拉近自己、引入危险弹道 |
| G释放时机 | 改变弹体到达时间与敌舰位置 | 炮弹被推离目标、帮敌人撤退 |
| 右键与射击并行 | 离开火线时保持压迫、获得侧角 | 冲进集火、耗空机动储备 |
| 留场或收场 | 持续控线或节省维持幅能 | 收早丢窗口、维持过久无力防守 |
| 同一G用于攻击或救援 | 选择当前最有价值的用途 | 不能同时覆盖不同位置的危险 |

上限来自几何、节奏与资源保留，不依靠多按键、隐藏增伤、叠层爆炸或自动绕盾。自然AI应能靠正常直射、有限布锚、必要时释放和保守滑移作战，不赋予AI逐弹完美预测。

明确弱点：重舰推进/质量抵抗、快速脱场、长程光束、从两侧同时压迫、实体障碍、幅能饱和和滑移储备耗尽。敌人应能从场边界、锚状态和机动残影判断接下来的危险。

## 状态、反馈与工程边界

- 锚：无锚 → 建立 → 吸引 → 安静收回或G释放 → 恢复。每舰只有一个锚；释放与收回互斥，未结束的波不能靠重部署重置命中名单。
- F/G以成功指令边缘捕获数据；释放需要权威确认，失败保留原状态。死亡、撤退、排散、过载、源离线或距离失效终止尚未执行的场力，已获得动量不回滚。
- 各船、弹体、锚的状态独立、可序列化；共享外力在一个权威阶段汇总，模块按根舰质量/运动处理。暂停不推进计时。
- 右键储备、方向、剩余推进时长及新增速度预算进入实例状态。失效中断剩余推进，不退还已消费费用或储备。
- 显示F位置/维持时间、G可用/恢复、右键剩余次数/恢复；G未就绪时有禁用原因，不能先清掉F再失败。
- 准星不因右键移动改变职责。F边缘按当前准星提交，G使用既有锚的位置，不另索要第二个目标。
- 轨迹预览必须与生产弹道/施力使用同一规则，并标出G将改变方向的区域；缩放后仍可读，避开满屏圈与永久辉光。
- 场驱动用真实推进状态显示硬件响应，不烘焙火焰、护盾或光束。主炮/副炮从实际炮口发射，场力效果与波前接触一致。

可复用的已实现能力：固定井、传播波、系统槽/右键入口、质量弹显式耦合、统一限幅与Worker规则入口。待开发能力：远程G从锚释放的原子状态转换、主炮/副炮与自己的井实际耦合及曲线火控、右键有限推进与两次储备、共享轨迹预览、完整武器与正式运行素材。现有G折转保速不能冒充本稿滑移推进。

本轮只交设计。后续实施先验证四键基础交互，再做武器联动、正式资产与自然实战；不能将86项v3检查写成v4已可玩。
