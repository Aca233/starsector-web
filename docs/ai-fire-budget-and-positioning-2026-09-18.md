# 规则 AI：在途火力预算与站位评分（2026-09-18）

## 本轮实现

### 在途火力预算

新增 `InFlightFireBudget.ts`，在权威 `CombatEngine` 的武器阶段创建每步索引，并在实际弹丸发射回调中增补。本帧稍后执行的武器/舰船能够看到已经发射的弹药，不把尚未发射的理论 DPS 当作确定伤害。

自主非 PD 武器获取目标时，对预计先于本次射击抵达、最多 3 秒内的友方在途火力估算船体损伤，降低明显被覆盖目标的评分。它不改变舰队主目标，不新增停火原因，不修改弹药或伤害，不抢玩家手动目标，也不改变 PD 拦截优先级。

保守边界：

- 按真实 teamId（或已知发射舰阵营）区分多阵营火力。
- 已命中、被摧毁、缴械、无碰撞、飞行寿命/射程不足、未及时引信解锁、追踪诱饵的弹药不计入。
- 只有当前相对运动确实与船体相交才计入；不假设还在转弯的导弹必定追上。导弹、可能重新开盾的目标分别折减可信度。
- 检查其他可见船体/小行星的先行拦截；计算装甲减伤，并对每发重新扣除预计命中区的整片 21 格装甲，不预支前序弹药的破甲收益。
- 护盾已开启、相位舰、未知伤害钩子保守不计入。持续光束的未来 DPS、未发射连射、MIRV 后续弹头、爆炸溅射、EMP 和 moving-ray 暂不预算。
- 仅调整目标排序，仍要经过原来的射界/命中/友伤/障碍物/幅能/弹药门禁。只有一个合法目标时不因预算停火；替代目标被挡住时仍回到原目标。
- 沿用原生获取目标周期，不增加每帧全武器强制重新扫描。预算是有意低估的建议，不是“必杀预言”。

### 接敌站位评分

新增 `TacticalPositioning.ts`，在无显式命令的正常接敌中，对原速度与最多 6 个候选速度评分。只在预测存在挡炮、遮挡友军火线、可见侧翼威胁或局部退路受阻时搜索；开阔单挑不凭空绕圈。

- 3 秒、6 步的有限加速度预测；不会把舰船瞬移到候选位置。
- 综合自身武器射程/炮口位置/射界/舰体转向与炮塔转速、可见船体及小行星遮挡、友方舰队分配的射线、侧翼敌方火力、局部向外退路和距离偏差。
- 最多 12 个邻舰、8 个小行星、4 个侧翼威胁，每舰最多采样 8 门输出武器，限制建议层的计算成本；最终碰撞控制与实际火控仍执行完整检查。
- 不改变主目标，不覆盖 ENGAGE / WAYPOINT / DEFEND / ESCORT / AVOID 等显式指令；不干预撤退、航母站位、排能、过载和系统战术模式。
- 选择结果仍通过原来的 `avoidCollisions`，不把位置评分当作碰撞安全证明。
- `tacticalAI` 增加 `positioning`、`positionScoreGain`、`clearFireFraction` 诊断字段；clearFire 是候选预测中的输出权重比例，不是实战命中率。

### Worker 一致性

火力预算只运行在权威武器阶段，不由多个 AI Worker 各自预约弹药。位置评分本身无 RNG、跨帧缓存或隐藏状态。

射界相关依赖可能比碰撞走廊更远，所以评分用到的对象会显式纳入 owner 的依赖记录。补全只读目标视图的船体、幅能及存活/碰撞状态标量，避免串行能够观察到的攻击窗口在 owner 中变成 undefined。

## 验证命令

```powershell
npm run ai:check
npm run ai:benchmark
npm run lint
npm run build
```

`ai:benchmark` 在 3 个固定种子、每场 6 艘舰船/30 秒的场景中逐场复跑并核对状态与行为指标；另有 24 舰/4 秒拥挤场景的计算耗时检查。可传入提前保存的模拟器打包文件进行 A/B：

```powershell
npm run ai:benchmark -- --baseline artifacts/ai/tactics-baseline.mjs
```

本轮 baseline 是修改前保存的本地 bundle，不是另写的近似公式；该本地产物不进入 Git。详细报告保存至 `artifacts/ai/tactics-benchmark.json`。

## 本轮结果与限制

- 24 项检查通过：原 14 项底座检查，加上在途火力有效性、同帧发射/失效、装甲与拦截、目标分流及安全回退、有限加速度与友舰绕行、可见性与命令/航母/排能优先、侧翼规避、正常/高幅能/残血目标的 owner 数据包与串行决策对照。
- 3 组 6 舰短场景的累计武器友舰遮挡量：115.18 → 88.60 武器·秒，下降约 23.1%。这是各武器被友军挡住的时间之和，不是战斗持续时间或命中率。
- 同批有限弹药消耗：180 → 200。打开火线可能增加开火机会；**不能把本轮结果描述为整体弹药节省**。预算分流由定向场景验证，整体弹药效率还需要更长对局评价。
- 这批场景 30 秒内没有舰船被击毁，不构成胜率或最终战损改善证据；双方均使用各自版本的同一种策略，也不是新旧 AI 直接对战。
- 24 舰检查未见数量级开销增加，但计时受 JIT/机器负载影响，不是百舰联机性能保证。owner 验证覆盖同步数据包与决策，不等同于完整浏览器多 Worker 压力测试。
- 位置评分仍是短视局部搜索，宽舰体阻塞、密集编队和长距离绕路可能需要更长时域规划。弹药预算也不会兑现未确认的击杀。

强化学习策略继续默认关闭。本轮增强的是可解释的规则基线。
