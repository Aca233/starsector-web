# 荣光女王级：视觉参考与方向重置

日期：2026-09-25。状态：参考研究，不是已批准设计；未修改运行时、生成新图或导入游戏。

## 结论

以《Battlefleet Gothic: Armada 2》中 Macragge’s Honour（马库拉格之耀）的具体形象为主参考，而不是把“荣光女王级”当成没有具体结构的金色哥特大船。荣光女王是舰级；选择这艘船作为本轮的视觉锚点，不表示所有同级舰完全同形。

优先级：整体轮廓与结构 → 正交俯视改编 → 安装真实武器精灵试配 → 模块切分 → 精修。前面提出的十模块、72槽方案只是未批准的游戏草案，没有原著依据，不应继续反过来规定舰体长相。

## 对上一张生成图的修正

上一张图：`C:/Users/Aca/Downloads/Screenshot_20260925_173404.jpg`，已看图。

1. **轮廓**：从六块宽平板围绕细长梁的组合，改为连续的纵长舰体。前部厚重、中央长炮廊、后部堡垒与动力段形成节奏，避免全长等宽或现代尖头驱逐舰轮廓。
2. **上层建筑**：恢复集中在后部的层叠城塞与沿脊线的次级构筑。转为严格俯视时用屋顶、扶壁基部、层叠遮挡与阴影表达，不能画成朝向镜头的教堂立面。
3. **侧舷**：连续炮廊与多层外缘平台，而非三对独立托盘。可采用局部退台，使部分武器与安装接口在俯视中可读；这是游戏适配，不应声称为原图已有俯视布局。
4. **安装接口**：小、中、大槽都保留；不要先给每个槽画一个巨大的圆圈。大槽嵌入厚结构，中槽沿功能带组织，小槽依附外围平台。具体像素大小先拿项目现有武器精灵试配，再确定；不要用生图模型数数代替槽位数据。
5. **模块**：模块是受损与装备单元，不等于把船画成悬空拼板。先保证总装连续，再沿装甲层叠、舷侧段落和动力舱接缝划分。
6. **引擎**：通过尾端喷口、护罩与阴影表达向后排气；不能是朝镜头的顶面大孔。喷焰另做，最终舰体图不烘焙喷流。
7. **武器分离**：不绘制可换装炮管/炮塔，但保留炮座基础、炮廊围护、装甲领圈与后坐空间；“无武器”不能被误解成删掉整片炮廊。
8. **细节密度**：小窗列、重复肋柱、局部密集工业层级体现巨舰尺度；不能全船均匀铺噪声，也不能只留几条缝线与大片空白。

## 限制与后续验收

- 未获得可靠的官方正交俯视图。依据斜视截图绘制俯视舰体属于视觉改编，不能宣称官设一比一复刻。
- 3D 中多层侧舷火力不能不加区分地平摊成顶面炮塔；挂载平台需要二维可读性改编。
