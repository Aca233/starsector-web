## 可用的 Web 功能

- 175 艘非战机舰船可改装，31 个原生战机舰体进入现有舰载机模拟；另有 3 个联队专用战机配置。
- 142 种武器进入运行时，其中 118 种可外装，其他为内置/载荷武器。
- 31 个联队可在有机库舰体上配置，计入 OP；旧方案未声明联队时保留其旧版机库行为。
- 原版 3 艘主展示舰、5 个原有运行时舰体、17 种原有武器及其策划配置保留。
- 舰船列表支持舰名/ID 搜索、级别筛选、分批加载；只为当前舰构建完整挂点预览。
- 武器列表支持名称/ID 搜索、类型/尺寸兼容检查、OP、内置锁定及特殊机制提示。
- 349 条关联可改装舰体的原版方案可以转换载入：武器组、幅能投资、已实现插件和已导入联队生效。缺失的配置与不支持的机制必须先确认，不宣称无损转换。
- 模拟战斗可以选择所有可改装舰体作对手。船体与武器的近似状态在目录、改装和战斗前可见。

## 不等于完整原版游戏

`runtime-import-report.json` 与 `refit-source.json` 是当前适配边界的机器可读记录。`supported` 也不代表已证明像素或机制逐项一致。

- 未适配舰船系统保留独立的 `UNADAPTED_SOURCE_*` 标识与「未适配」名称；没有伪装成已实现系统。
- 未实现的 Java 武器钩子、特殊命中/每帧特效、自定义导弹/MIRV、舰体插件、特殊战机行为与渲染均列入逐项说明。
- 62 个源舰体 ID（主要为空间站、模块、辅助对象等）和 21 个武器 ID 暂时仅保留数据，不能声称已经完整参战。
- 皮肤中的不支持插件效果不会伪造；S 插件、完整模块组装、原版战役/经济/技能、所有特殊 AI 仍需后续专项移植。
- 默认运行时装配保留基础幅能值。要载入原版的容存器/耗散投资，应在目录选择具体装配方案。
- 原安装缺少 5 张可选通讯频道图标，导入报告记录了它们；不是舰船/武器运行时资源缺失。原版 `music.bin` 未转成浏览器音乐。
- 仅打包合法本地安装中的相关资源。没有上传/公开发布，也不包含存档、登录信息、JAR 或整个安装目录。

## 再生成

在项目目录运行：

```powershell
npm run import:all
npm run typecheck
npm run build
npm run dev -- --host 127.0.0.1
```

`import:all` 先生成运行时配置，再导入原生目录及资源，最后生成轻量势力索引；单独更新索引可运行 `npm run import:refit-factions`。资源闭包同时扫描运行时生成的文件名（例如相位舰辉光后缀），避免源定义未直接写出的贴图漏进清单。

如需指定安装目录：

```powershell
npm run import:content -- 'C:\path\to\starsector-core'
npm run import:catalog -- 'C:\path\to\starsector-core'
```

资源导入是保留已有资源/字体/采样设置的增量操作，不删除旧项目内容。Vite 的离线内容导入使用独立缓存目录，避免和正在运行的开发预览争用预构建缓存。
