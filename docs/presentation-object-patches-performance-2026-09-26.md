# 无损Object行补丁：保留（2026-09-26）

## 实现与边界

此前计数发现稳定Object行仅7.31%字段变化。本候选已实际实现：本地render通道的旧身份/同布局行，只在3×变更字段数小于2×完整字段数时使用ObjectPatch；新建/重入/布局变化或稠密修改仍发完整行。UI/LAN通道仍用原字节格式，接收端拒绝UI补丁。LOCAL_COMBAT_PROTOCOL 14→15，使Host与Worker明确拒绝跨格式混用；这是临时本地恢复协议，不改存档格式。

Decoder保存独立的已接受标量历史（字符串为实际值，不是逐包索引），先重建/验证候选整行与完整可达图，再写入。行预算按完整展开长度而非补丁长度计数。变更Object仍整行写入，所以显示端篡改未变化字段、删除字段的覆盖语义不变；引用/别名/循环、typed-array替换重绑、NaN/-0与精度不变。错误包不提交历史/版本/对象图。
