# 私有Worker导航扫描运动复用：否决结果（2026-09-27）

## 结论与当前生产状态
候选行为正确，但没有证明稳定整步收益。两组都至少降低3%的预注册门槛未满足；已在核对两个文件候选hash均未被并行修改后，精确恢复TacticalNavigation.ts与host.worker.ts的本轮before字节。完整725模块基底hash一致，不影响上轮预瞄优化及更早实验。未运行浏览器候选，不发布、不提交。

不能把“计算次数79→1”当作整步性能结论。第二组比参考明显慢，当前证据不能把它归因于GC、调度、机器负载或算法开销中的某一项；不择优重复性能测试。

## 实现（仅留在冻结历史候选中）
在单次导航obstacles内惰性复用观察舰maxSpeed/速度长度；只接通私有host Worker默认关闭开关，不改变原生phase/forecast/index，也没有为原创舰开启额外几何快路径。遇到未知相位或速度读取回调前退出复用，后续恢复原每障碍实时计算。普通模式无变化。
