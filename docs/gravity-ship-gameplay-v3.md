# 万有引力号 · 完整玩法方案 v3

日期：2026-09-30。原创舰，沿用用户选定的原B偏置舰体和等体量场驱动尾段，不绑定其他IP。

**性质：本轮整套重设计与实施依据，不是整舰完成报告。** 用户确定的边界是无护盾、使用右键、保留G的独立作用、技能与武器共同产生深度；下述具体参数和连招为本轮设计，不能写成已经通过实战或用户逐项认可。工程状态单列于生产账本。

## 1. 一句话定位

无盾的引力操纵巡洋舰：改变敌人的路线、自己的航迹和实体弹的入射方向，让普通伤害武器获得原本没有的射击机会。

不做“强控＋免费反弹＋大招清屏”。基本功只需放井、射击、贴脸排斥；高上限来自站位、力的方向、保留动量和幅能余量，而不是新资源条、标记层数或长按/双击分支。

## 2. 操作定案

| 输入 | 职责 | 不做什么 |
| --- | --- | --- |
| 选中第1武器组，按住左键 | 矢量牵引器，捕获实际瞄中的一艘敌舰，鼠标移动有限速锚点；松手释放 | 不拖着全舰瞬移，不自动更换抓取对象 |
| 右键 | 以本舰成功释放位置为源，向四周传播一次排斥波 | 不开盾、不按鼠标点远程爆炸、不只推一个目标 |
| F | 在指针处部署一个固定引力井；再按收回 | 不跟鼠标免费拖动，不自动囚禁井内所有目标 |
| G | 惯性折转：将本舰当前速度向按键时的鼠标方向有限弯转 | 不瞬移、不无敌、不锁舰首、不凭空加速 |
| 其他武器组、移动、转向、V排散 | 使用宿主现有操作；质量炮与近防默认自动，可手动接管 | 不把左键牵引覆盖到每一个武器组 |

没有舰体护盾、相位或额外虚空盾。Shift+右键也不能隐藏地开出护盾；保留宿主快捷键语义，不在这条船上偷改为第二种排斥。

### 关键修订：排斥不再强制关闭引力井

v2规定一次排斥结束F，这会把控场和解围机械地互斥，削弱站位玩法。v3改为：
- F独立维持，右键成功只释放正在执行的手动牵引；须松开左键后才可重新捕获。
- 失败的右键不释放任何连接、不动F、不收取费用。
- 可以把敌人推向预先放好的井，也可以在井维持时给自己解围；同一对象的所有外力统一限幅，不按结算顺序无限叠加。
- G不主动取消F或牵引。但移动出维持距离、射界或遮挡仍正常断开，G不是延长射程的方法。
- 并行不是免费：维持F、牵引、射击和防守共用幅能；高负荷时应主动收井和停抓，而不是无脑同时按完。

## 3. 系统规则卡

以下是机制试验值，整舰规格和同DP平衡尚未冻结。距离均为世界单位，最终须按运行舰图和实际炮口标定。

### F · 区域引力井

- 1400部署/维持距离、520作用半径；0.35s启动，最多6s维持，0.15s收束，7s冷却。
- 240启动软幅能，180/s维持。每舰一个井，再按F收回，重部署遵守冷却。
- 多敌舰、多实体敌弹受到趋向井心的有限外力；中心软化，无奇点、无强制归零。
- 不拉友舰和普通友弹。专用质量弹仅通过自己的、经火控明确选择的有限借井规则进入；不是对所有友弹开放强拉。
- 正放是压缩队形，偏放是偏航。收井不会抹掉已产生的惯性。
- 过载、排散、死亡、撤离、相位、离线或脱离维持距离中断；模块按整舰质量抵抗。

### 右键 · 全向排斥

- 0.65s扩张至720、0.2s收束、11s冷却、800启动软幅能。
- 所有敌舰与支持的实体敌弹都可受影响，不是单目标技能；每对象每波一次冲量。
- 按质量、接触距离和总预算分配；拥挤弹幕可能处理不过来，重舰位移更少而非完全免疫。
- 保留敌弹伤害、所有权、年龄及寿命。推偏不是销毁；导弹能重新追踪，光束完全不受力。
- 支持明确标记的友方质量弹加速推送，普通友弹豁免。增加飞行速度不增加伤害，不补射程/寿命，不绕过宿主弹体限速。
- 正面按是解围，绕到侧面按是拆阵；站错边可能帮助敌舰撤退。
- 源失效停止尚未传播的波前，已获冲量不回滚。实际波前与画面必须一致。

### G · 惯性折转

不是又一个推敌人技能。它操作自己，让“排斥方向由站位决定”真正有可执行的机动工具。

- 按键时采样“舰心→指针”方向；之后移动鼠标不免费改道。短短一次按键，不增加模式切换。
- 试验值：0.8s作用，10s冷却，450软幅能；最多120°累计改向、150°/s角速率、240单位/s²横向加速度。三者同时限制，越快越难急转。
- 只有当前速度至少30、指针离舰心至少30且方向有实际差异时接受。失败无消耗；静止时用正常推进起速，不生成免费冲量。
- 单独作用只转动速度向量，保留其长度；不写位置、不改舰首、不返还因碰撞/推进/其他引力产生的速度变化。
- 实际横向力进入共享权威外力阶段，其他场可以抵消它；X制动、排散、过载、死亡、撤退、相位、动力熄火或系统离线中断。
- 不是持续追鼠标的自动躲弹，不提供命中无效或减伤。曲线仍经过真实障碍和攻击判定。
- 既可绕侧进攻，也可避开已承诺方向的重炮、离开光束持续照射线；无法保证躲掉高速跟踪光束。

## 4. 武器不是三种伤害颜色

### 1L · 矢量牵引器（绑定、可转动、零直接伤害）

- 暂定1100炮口牵引距离；0.25s持续对准捕获，最多2.5s持有，结束后1.25s恢复，180/s维持软幅能。
- 鼠标移动的是有限速锚点，不是目标本身；暂定锚点600/s。实际力封顶、按质量响应，敌人仍能推进/转向。
- 只精确操作一艘，因为群体由F/右键负责。可牵引战机；不抓友舰，不牵引炮弹或静态障碍。
- 舰体/模块/小行星真实遮挡，射界和转速由安装档案约束；超距、目标失效、离线、到时、排散等立即释放。
- 松手保留实际运动，不额外投掷伤害。任何中断须先松开开火输入再抓，切组或自动模式不能绕过。
- 锁定敌舰对象与鼠标锚点分开；默认质量炮优先捕获对象的真实位置，释放后短暂保留有效目标，绝不朝空锚点发射。

### 4M · 质量投射炮（输出＋有限动量）

- 首版正常实体直射必须可靠；暂定炮口有效距离1700、弹速约700，最终按完整舰尺度复验，不以舰心距离冒充覆盖。
- 命中带有限沿入射方向冲量；正常护盾/装甲/命中先判定，不穿一切，不把普通撞船变成额外爆炸。
- 选择自己的一个活动井，火控只在有限弯转确实可拦截时借井；每弹最多一次借井，累计实际路径扣射程。
- 玩家可先出炮再右键推送，缩短敌人的反应窗口；不追加“连招增伤”。波前必须追上/遇到在途弹，错过就是错过，不事后追授加速。
- 改变出射位置、入射角和到达时间才是收益；不是自动穿盾。借井没有可行解时正常直射。
- 打到实体障碍/护盾按真实命中处理，结束必须有匹配冲击/消散，不凭视觉径直消失。

### 6S · 偏轨阵列＋常规近防（分工防御）

- 偏轨阵列先预测将命中本舰的支持实体弹，施加最少足够的侧向力；有转向、处理数及每秒动量预算。
- 不把周围弹幕无差别吸向船，不持续360°无漏网防护；高动量弹或密集齐射可穿透处理能力。
- 常规PD负责真正击毁可拦截导弹/战机，补上偏轨后追踪回来和预算遗漏的威胁。
- 光束由走位、G、地形和队友遮挡应对。主动右键是爆发解围，偏轨是有限日常防护，不能用无限偏转恢复隐形护盾。

## 5. 生存、资源和插件

无盾不是去掉盾再把护甲翻几倍。基础生存为巡洋舰级结构/适中装甲，承担有限漏弹，主要靠中距控线、偏轨/PD、右键和G的错峰使用。最终DP、HP、OP、速度和耗散待安装尺寸与整舰对抗后冻结。

- 宽裕窗口：放井、抓一艘、集中炮火，必要时机动改角。
- 压力窗口：松抓、收井、保留800幅能用于排斥，利用G侧移脱离。
- 恢复窗口：右键/G冷却与V排散期间借距离/掩体/队友恢复；不能边排散边维持场。
- 不增加引力能量条，也不做回收敌弹无限补能。

**可选专属插件（相互排斥，具体OP待编译）：**
1. **场锚延伸器**：井部署/维持距离+20%，维持费用+25%；作用半径、拉力、武器射程不增。偏护航/控线，代价是难以长期边抓边打。
2. **惯性矢量器**：G横向加速度+25%（仍受共享对象上限约束），费用+35%；角度、速度总量和无敌性不变。偏近距拆阵，付出更紧的幅能窗口。

核心规则不藏进“必装专属插件”；卸下插件仍是一艘完整的引力舰。安装只修改舰实例的派生参数，禁止改共享注册表。两插件是待实施的有取舍规则，不伪装成已有内置功能。

## 6. 三条操作路线，而不是固定毕业连招

### 拆阵：把敌人推入火线

F放在护卫编队侧后方 → 牵引器让一艘护卫进入井边 → 松手 → G改变自己的切入轨迹 → 从合适一侧右键推送。

收益是空出保护位置、形成交叉火线；不是技能自动算伤害。敌人可转向推进抵抗，重舰只小幅偏航，站错边会把它救走。

### 弹道：改变到达角度与时机

质量炮直射或选择可行借井路径 → 右键在炮弹仍处于有效波前时推送 → 敌人处理不同到达时间/入射角。

不用该连招也能正常输出。提前收井或错误推送可能让炮弹失去原先拦截解，高阶不是每次强行曲射。

### 护航：救队友而不拖队友

F侧置干扰追兵/实体弹 → 本舰G绕到队友受威胁的一侧 → 右键推开追兵和来袭弹 → PD补漏。

友舰不受拉推，因此不会被强行踢离阵线。但队友在波前之外、光束照射和预算饱和依然可能受伤，不标成无敌保护圈。

## 7. 配装与舰体安装

- 沿用原B：长主干、小左舱、大右场发生舱、封闭场推进。保持完整尾部比例，不再加化学喷管。
- 初始账本仍是1L牵引器＋4M质量炮＋6S近防；0XL不是漏档。位置/射界/pivot/炮口必须等alpha运行图后标定，不把草案坐标冻结为成品。
- 攻势装：2S偏轨＋4S常规PD，质量炮较多交替/齐射控制，由G和右键争取开火位置。
- 控线装：4S偏轨＋2S常规PD，配场锚延伸器，较重炮雨防护但更怕导弹补漏不足/战机饱和。
- 所有可换武器严格同档；L绑定但转动，不能把“固定装备”误作“固定朝向”。不凭空加航空或模块。
- 两套OP/幅能上限/插件互斥/武器组须经过实际配装编译与保存读回；当前未证明合法，不给虚假OP总分。

## 8. 视觉契约

- 不让全舰笼罩在常亮大光圈下。正常无场时能看清舰体，场驱动不喷火。
- 牵引从真实炮口起，先捕获反馈，再有方向性的连接；连接至目标真实接触处，不从舰心拉一根装饰线。
- F有建立、维持流动、释放三阶段；收井后目标继续滑行，画面不能假装定住。
- 右键是一次传播波，效果只在真实波前触及对象时响应；没有满屏瞬间闪白代替传播。
- G在侧向场驱动硬件显示与实际施力同向的短促响应，不加与模型脱节的喷气或贴纸。
- HUD分别显示F维持、右键冷却、G冷却和牵引状态；无护盾条/盾角提示。仅G准备时显示短程航迹预测，不能用假预测当必中躲闪。
- 所有正式效果需有动态素材和状态验收。规则探针不配廉价几何占位，也不因此算特效已完成。

## 9. 实施顺序与验收门槛

1. 共享控制规格：F井/G折转/右键排斥/无盾；主线程和真Worker使用生产指令路由，失败不错误消费或关闭别的能力。
2. 共享外力：F、右键、G并行、按对象封顶；G单独运行不创造速度/瞬移，超速状态不被直接抹掉，X和失效正确中断。
3. 牵引器：真实炮口/遮挡/转角/拖锚/松手/右键成功互锁/AI有限计划；不生成零伤害假光束冒充牵引。
4. 质量炮直射与命中冲量 → 右键推送 → 可行借井。不能先用视觉曲线假装弹道已完成。
5. 偏轨预算、常规PD、专属插件实例隔离、两配装真实编译/读回。
6. 运行舰图/战损/炮塔安装/动态素材/目录到战斗的可玩链路。
7. 同DP自然对抗覆盖重舰、快速掠袭、光束、饱和导弹及双引力舰。记录控制位移、存活/结构损失、队友脱离时间、实际命中与幅能空窗；不只比较DPS。
8. 失败也验：静止G、无方向G、冷却右键、过载/排散、场外重抓、模块质量、多来源叠加、暂停、死亡/撤退、显示快照与受支持联机模式。
9. 自包含包资源/依赖/安装验收和分发许可单列；不在本轮发布生涯或其他工作。

这是原创Web扩展，不称为原版等价技能。宿主已有 `ShipSpec.rightClickSystemType`、`Loadout.defenseSystemId`、`CombatCommands.dispatchShipCommand` 及真实右键→shield命令路径；复用该入口，不重绑其他船。原版实机界面补验仍待许可，本轮不占用用户桌面。
