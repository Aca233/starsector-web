# 独占 Worker 火控查询域：验收记录（2026-09-25）

## 结论和正式入口范围
**保留候选，默认本地战斗 Worker 获得有效整步改善。** 200 Onslaught 的同轮配对：模拟均值 **59.329 → 52.024ms（-12.31%）**，P95 **70.250 → 61.825ms（-11.99%）**；Worker 往返+解码均值 **97.672 → 87.593ms（-10.32%）**，P95 **113.180 → 102.470ms（-9.46%）**。

这是一次固定场景配对的实测结果，不是任意舰队/机器的保证或形式化统计显著性结论。连续六个30tick区段的模拟和交付均值均改善，但这些区段不是独立复现实验。约52ms的模拟步仍明显超过16.67ms，不能声称已经达到60Hz。

入口核实：CombatView.tsx:71 对普通本地战斗调用 enableWorker，CombatSession → LocalWorkerHost.ts:70 加载本轮修改的 local-combat.worker.ts。**LAN 使用独立的 src/network/host.worker.ts（LanBattle.tsx:580），本轮没有给它登记所有权，因此不能宣称本次已加速联机主机或降低网络输入延迟。** 通用、inline、自定义可变引擎继续旧路径。这里没有完成任何呈现 Worker/GPU/多核火控迁移。

## 实现与因果边界
来源与编码前边界见 `worker-fire-query-source-notes-2026-09-25.md`。

- FireControlQueryRoster 增加模块私有 Worker 引擎登记；只有正式本地 Worker 的 init 和 restore 分支调用，没有 DTO 权限位或用户可注入回调。
- 独占路径省略通用对象的逐属性/逐武器描述符反射，不修正或移除旧通用路径的资格门槛。舰体/武器参数没有冻结或改写。
- 每舰完成运动、系统更新及维修后，仍重新检查当前原生读钩子、元数据、相位/伤害回调、runtime modifiers、父舰/来源、辅助系统和组件回调；无法证明安全则回退。
- 复用现有一次同步 pre-emission 查询域的目标资格/名单和阻挡索引。实际角色、射程、拦截、射界、几何、排序和发射前幅能预算仍独立检查；try/finally 在真正发射前关闭。下一艘船看到前船更新后的状态。
- 不缓存整帧世界、不修改实体数/精度/频率/RNG，不引入旧预瞄范围树。native 系统查询中的纯读取语义已经核查；SystemWeaponLauncher 的 isExecuting 只读其私有发射进度，独立相位定义不由炮塔瞄准写入驱动。
- 这是一条模块所有权契约，不是对同 realm 恶意原型修改的安全沙箱；若 Worker 未来支持可执行插件或导出可变引擎引用，必须重新审计/禁用登记，不能继续依赖本约定。
