# Windows 联机免安装分享包

在 Windows x64、Node.js 22+ 的开发环境中运行：

```powershell
npm run package:windows
```

脚本先执行正式构建，然后把 ZIP 和解压目录放进 `artifacts/releases/`。输出使用新时间戳，不覆盖、删除已有包。已自行完成构建时，可显式使用 `npm run package:windows -- --skip-build`。

包内有完整 `dist`、便携 `runtime/node.exe`、Node 授权、运行服务所需的源码/JSON 最小依赖集合、`ws` 运行依赖、前端运行库授权、默认联机与可选单机两个启动脚本与中文说明。不包含开发依赖、Git、实验目录、原版安装目录、浏览器资料或个人存档。运行不需要 npm、全局 Node 或原版安装，也无需联网下载依赖；异地联机仍需要互联网和额外配置的虚拟网络。

- **启动游戏.cmd**：默认 `0.0.0.0:32101`，浏览器打开 `/?view=lan`；这是一起玩的主入口。
- **单机试玩.cmd**：默认 `127.0.0.1:32100`，只监听本机；可选的独立试玩入口。
- 两者都保留控制台，不创建隐藏常驻服务、开机启动或防火墙规则。关闭控制台/按 Ctrl+C 停止；只关浏览器不会停止服务。
- 重复启动会通过服务类型、协议、构建号、包 ID 和模式识别并复用匹配服务。其他程序占用端口时仅尝试备用端口，不终止任何未知进程。
- 浏览器存储按 origin 隔离，两种默认端口和备用端口之间需要用现有 JSON 导入/导出搬运方案。
- 本地响应提供 COOP/COEP，以保留符合条件的单机 AI 多核路径；LAN 非安全上下文依然按现有能力门禁回退，不承诺公网或异地联机。

开发验证可直接调用包内 `runtime/node.exe server/portable-launcher.mjs --no-browser --port 端口`。这不是要求收件人使用命令行。

这是非官方 Web 沙盒，不是官方完整战役。技术上离线可运行不等于获得原版美术/音频的分发授权；公开发布前必须另行确认。启动说明不建议绕过操作系统或安全软件的警告。

## 异地联机

推荐先自行使用 Radmin VPN/Tailscale 等让玩家进入同一可信虚拟网络；本包不会下载安装组网工具或调整账号/防火墙。房主分享实际虚拟 IP 和当前端口，朋友用浏览器打开同一房主页面并输入房间码，不是各自启动独立房间。仅房主需要完整包，朋友初次加载资源仍依赖房主上传带宽。

这是现有局域网协议的虚拟网络使用方式，不是新增公网穿透。本机不具备相应虚拟网络时无法验证真实异地链路；公网中转需要独立服务器、域名/HTTPS/WSS、Host/Origin 配置与访问控制，未在本次自动部署。
