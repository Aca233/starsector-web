# 自动驾驶单舰入口按队规划：验收（2026-09-26）

## 候选边界

只在封闭Worker、原生CapitalShipAI.update、未提供fleetPlan的单舰补充调用中，生成本舰所属队的完整计划。CapitalShipAI读取本舰assignment；TacticalPositioning的盟友航线读取同队其它舰assignment，因此仍计算所有同队舰，而不是只算玩家。所有舰船仍参加readiness、本队可见敌人列表、影响力与评分；后续真正的舰队AI阶段仍计算全部队伍。两阶段状态不同，未缓存/复用旧计划。

每次live准入要求至少100舰、原生数学/读原型/向量、不可变spec与原生hooks、安全整数队号、全名单唯一ID。任一条件失败回完整planner，避免同ID跨队覆盖或非原生回调观察不完整Map。普通调用、非原生AI和显式传入计划保持原有行为；Owner的完整计划发布/校验不变。

来源见owned-team-planning-source-notes-2026-09-26.md；这仍是Web战术启发式，未声称原版AI等价，未做原版可见实机/画面验收。本轮不是GPU、WASM或多线程改造，不降频/精度，不减少参战实体/显示字段/真实权威校验。

专项98项检查、75份计划对照，其中62份按队；旧实现访问192个队伍规划循环，候选89个，只是工作量计数。覆盖随机两/四队、显式命令/手动舰/死亡与撤退、全部本队assignment及approachBearing、反转名单/不存在的请求队、重复ID/无效队号、小场景、自定义Math/向量/可见性/可变spec回退，公开getter顺序完全相同。

原生实际入口5项检查：未注册Worker仍完整；已注册原生单舰入口给出完整本队Map；正常planFleetAI仍给完整Map；显式计划保持引用身份且不重算；自定义AI收到完整Map。测试插桩只在既有test bundle，不进入性能构建。

## 预定性能与范围

修改前写performance-gate.json，两个预指定角色互换200舰Host实验，每臂150预热180测量tick；serial/before同码控制，六排列位置各60次。每轮三个实例全部用于轮内均值差异，两轮相对变化等权，不混合跨轮原始样本归因。要求两轮均改善、模拟至少−3%/交付至少−1.5%，超过同码差异1个百分点；主配对交付P95两轮不增，六个描述块各至少四块改善。

当前runner的控制sample明确autopilot:true，本候选的预期收益限于这条自动驾驶/单舰补充规划路径。手动驾驶通常不走此额外planner，不能外推相同收益。测量包含真实Host解码、ACK和交付，不包括屏幕渲染、真实WAN或input-to-photon。

两臂冻结完整323模块，仅FleetTactics.ts和CombatEngine.ts不同；起始候选无其它模块漂移。

## 结果：有小幅模拟收益，但未通过完整门槛，已撤回

均值纳入每轮全部三实例，方向为旧→新；P95遵循预写主角色配对：

| 指标 | 第一次 | 角色互换后 |
|---|---:|---:|
| 模拟均值 | 34.811→33.895ms（-2.629%） | 34.091→32.712ms（-4.043%） |
| 编码均值（未改） | 17.413→17.513ms（0.577%） | 16.745→17.313ms（3.391%） |
| Host呈现均值（未改） | 9.605→9.628ms（0.234%） | 9.671→9.638ms（-0.346%） |
| 本地交付均值 | 62.227→61.424ms（-1.290%） | 60.924→60.072ms（-1.400%） |
| 主配对交付P95 | 76.480→71.735ms（-6.204%） | 72.375→75.190ms（3.889%） |

两轮相对变化等权：模拟−3.336%、交付−1.345%。模拟达到−3%门槛，也超过同码控制最大差异0.834%加1个百分点；各轮6个时间块模拟均改善。交付未达−1.5%，也未超过控制差异0.742%+1个百分点；两轮交付改善块为5/6、4/6，第二轮主配对P95却+3.889%。如实承认模拟均值方向较一致，但这不是可保留的稳定端到端延迟收益；不能事后放宽门槛或把未改编码的+1.984%解释成某个已证明原因。

两轮各660次包/见证比对、662次完整显示对照及11个完整隐藏火控/权威/RNG检查点一致；各Host结束ready、pendingTransactions=0、tick=330。测量位置各60次，三臂均workers=0、freshBatches=0、invalidated=0；测量无profile/额外计数，无重试择优或丢弃实例。

生产两文件及两个测试入口均按修改前原字节恢复，SHA确认；新helper已归档并移出活动scripts。完整323模块与本轮基线无漂移，前几轮否决候选没有复活，已有有效优化和其它任务内容未覆盖。工件目录artifacts/owned-team-planning-20260926，包含候选源码、冻结图、先验计划、53场景验证、两轮原始数据、分析及acceptance。

本轮未增加保留的生产性能改动，没有提交/发布；全局优化目标仍active。该候选的工作量削减有证据，但后续若进一步研究，需要新的实质变化或更完整延迟证据，不能原样重跑换门槛。
