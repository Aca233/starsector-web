# 万有引力号 · 广义抓取与全向排斥方案 v6

日期：2026-09-30。用户最新要求：可以抓友舰、弹体或静态障碍；右键采用类似“神罗天征”的全向引力排斥。延续引力辅助实验舰、无盾、原B主体与场驱动尾段。本文核心规则已接入可玩工程版；实装数值、操作和验证范围见 `gravity-playable-v6.md`。人工长局手感、真人联机和最终平衡仍待验证。

## 四键核心

| 输入 | 能力 | 固定语义 |
| --- | --- | --- |
| 左键按住 | 万有牵引 | 捕获准星选中的一个实体，以有限外力牵引；松手保留实际动量 |
| F | 区域引力锚 | 在准星位置布置固定吸引场；再按安静收回 |
| G | 远端释放 | 从F锚向外传播较小的排斥波，结束该锚，保留当前牵引；没有锚时不可用 |
| 右键 | 全向排斥 | 从本舰成功释放的位置向四周传播一次强排斥波，可独立使用 |

右键取消v5的定向弹幕分流及更早的滑移。普通移动、舰首控制、武器组与V排散仍沿用宿主。左键是默认牵引器武器组的正常开火输入，切到自卫武器组仍可正常射击。

## 左键：抓取对象扩展

不再按阵营或“不是舰船”排除对象。准星明确选中对象后建立连接，一次只操纵一个实体；舰船模块按整舰根对象处理，不拆模块。

| 对象 | 实际作用 | 保留的边界 |
| --- | --- | --- |
| 敌舰 | 拉偏掠袭、撤退或保护位置 | 推进与转向继续生效；按整舰质量抵抗，不强制关盾/眩晕 |
| 友舰 | 拖出集火区、改变掠袭路线、送入有利位置 | 不自动接管舰首、火控和推进；大型友舰同样难以快速移动 |
| 实体炮弹/导弹 | 有限制动、改向，并可在成功捕获后反投 | 捕获前不能远程接管；年龄、射程、引信及耐久继续推进 |
| 小行星/散落残骸 | 移动掩体、清开射线、有限投送 | 按质量施力；保留真实遮挡/碰撞，不额外附加免费爆炸伤害 |
| 真正固定的障碍 | 建立锚定连接，有限反牵本舰 | 不移动无限质量地形；本舰仍经过实际碰撞，不穿墙 |

“当前静止”与“物理固定”分开：零速度的小行星可被加速，固定结构可抓住当锚点。不能只把障碍贴图拖动、碰撞留在原位。

### 捕获与操纵

- 对准星覆盖的真实对象优先，显示捕获轮廓和类型；小弹体可用有物理范围上限的瞄准辅助，不隔船抓后排，不因一个像素弹丸靠近就抢走明确选择的舰船。
- 捕获需要短暂对准、射界、炮口距离和遮挡检查。舰船/障碍捕获较慢，弹体窗口较短；数值须与弹速及实际命中率一起验证，不能要求玩家逐像素点击高速弹。
- 成功后锁定对象，拖锚从当前位置起步，有限速移动。目标位置不是鼠标坐标；超距、遮挡、失效或持有时间到立即释放。
- 弹体的牵引/制动需要实际时间和预算，不能一按就将任何重弹归零并悬停。场源持续耗幅能；当前牵引维持费用固定，受力按质量响应，并与其它来源共享冲量/加速度预算，不把所有对象当同一重量。质量差异目前体现在物理响应，不额外增加可变费用。
- 同一个准星承担拖锚与F放置；要到另一处布F先松手。右键使用舰心、G使用既有F锚，不另要求鼠标换目标，便于组合。

### 手动抓弹与反投

明确区分普通波前推偏与人工捕获接管：

1. 未被手动成功捕获的敌弹，被F/G/右键影响后仍保留原阵营与伤害，不自动变成友弹或回敬原发射者。
2. 只有单对象捕获完成后，该弹进入操纵状态并向本舰转移战斗所有权；保留原始发射者记录用于溯源。制导弹的原制导被接管，不能一边服从牵引一边无限修正回原目标。
3. 弹体仍能撞上障碍/其他实体并正常引爆，寿命、飞行预算、引信和耐久不暂停、不补充。不能在船边储存一堆永久鱼雷。
4. 松手沿实际速度飞行；右键可按它当时位于本舰哪一侧增加径向冲量。释放后首版采用实际航迹的无制导投送，不自动获得新目标或必中返航。
5. 所有权变更、捕获关系与剩余预算必须由权威端确认并进入实例状态/Worker/显示协议；不能只改颜色让敌弹看起来已经归我方。

## 右键：全向排斥

按下后本舰场驱动短促聚力，从成功释放位置向360°发出一圈迅速扩张的强排斥波，具有明确的近身空间清理与反投用途。名称可使用“全向排斥”，视觉追求用户所说的“神罗天征”式爆发感。

- 同时推开范围内敌舰、支持的实体敌弹、可移动环境物体；按接触侧、质量、距离和总预算响应。重舰小幅偏航，小物体反应更明显。
- 未被抓取的友舰和普通友弹保持豁免；玩家正在操纵的友舰/友弹可被主动释放并获得推送，以支持救援、投送和手动反投。不会因为救一艘船把整支友军阵型弹散。
- 成功时终止当前牵引、登记本次受操纵对象，再执行正常波前接触；必须松左键后才能重新抓。该对象仍须在波前范围内，不能隔地图远程发射。
- 普通兼容标定质量弹可借波前推送。已接管的弹体/环境物体按实际方位投出，不自动朝准星修正；想投向某处，要先把它带到本舰相应一侧。
- 不关闭独立F锚。可先布F，再靠站位用右键把敌人/物体推向井的范围；同一对象的全部来源统一限幅，不无限叠加。
- 每对象每波只受一次冲量；真实扩张波前检测接触，不按“仍在大圈内”逐帧重复加速。源失效停止尚未传播部分，已产生的运动不回滚。
- 光束、爆炸已结算伤害、无实体的特效不受力。波是短时主动行为，不是持续护盾、全屏删除或伤害无效。
- 失败启动保留牵引和F，不扣费；成功消费幅能并进入真实冷却，无按住连续重放。

当前工程基线：0.12s 建立、0.65s 扩张、820 世界范围、900 启动软幅能、11s 冷却；参数仍需人工实战调平衡。不增加额外蓄力模式或清屏大招分支。

## G与右键的区别

- G从提前布置的远端F锚释放，作用较小、代价较低，但必须先布场并结束持续吸引。适合远程拆阵、撤退路线阻断和精确布置后的环境投送。
- 右键从本舰释放，独立可用、范围/瞬时冲量更强、费用和冷却更高。适合贴身解围、主动救援和抓取后的近身反投。
- 两者都改变动量，玩家决定“远处哪个点释放”或“本舰站在哪里释放”。不能把所有对象瞬间推到指定坐标。

## 支援与实验路线

1. **救友舰**：左键抓住处于集火区的友舰，朝安全方向牵引 → 友舰位于本舰安全侧且在波前范围内时右键推送。舰首和推进仍由友舰控制，不保证大舰立即逃出。
2. **接弹反投**：左键捕获一枚来袭实体弹 → 通过有限制动/改向把它带到敌人方向的一侧 → 右键释放推送。原寿命继续倒计时，抓太晚或布置太久会来不及。
3. **移动掩体**：抓静止的小行星/残骸，拖到友军受攻击路线之间挡炮 → 需要开射线时移开；也可在合适站位用右键投出。碰撞与遮挡必须真实随物体运动。
4. **聚拢再拆阵**：F侧放吸引敌人/散落物 → 左键精调其中一个 → G从远锚释放，或本舰绕到另一侧用右键把对象推回F范围，选择结束控场还是继续维持。
5. **固定锚辅助移动**：抓住真正固定结构，用有限反牵改变本舰运动，借掩体调整支援位置。仍受维持距离/碰撞限制，不写位置或穿越地形。

装备已采用 1L 内置广义牵引器、4M 可替换标定炮、6S 可替换常规近防及有限偏轨，0XL。正式素材挂点、炮口与碰撞已标定；护航救援和阵地控场两配装已接入并通过合法性、界面和保存验证。主强度来自场与抓取；当前副炮每门 120 DPS，后续仍按辅助定位调平衡。

## 反馈与验收边界

捕获前给对象轮廓/类别；捕获后显示实际连接、可到达拖锚和剩余占空比。手动接管弹体有明确阵营/状态反馈，右键前可读出受操纵对象的径向投送方向。右键视效从实际舰体场设备启动，波前与实际受力同步，不以闪白或静态大圈代替传播。

当前已接入小行星受力、被引力管理的残骸实际运动/多边形碰撞/导航避让、固定结构反牵、弹体归属接管与原制导停止、引用有效性及显示/真实 Worker 状态。未被引力管理的宿主残骸维持原链路；固定物体采用显式标记，原版静态地形不会默认支持上述能力。

定向验收覆盖友舰正常控制、模块整舰质量、捕获失败、弹体寿命与归属、环境遮挡随动、固定锚反牵、波前单次命中、成功释放互锁、失败保留、暂停/失效及多来源限幅。主线程和真实 Worker 各 147 项通过；正式渲染与装配流程也已检查。仍缺人工长局手感、真人联机端到端验证与最终同级平衡；不能将受控检查解释为这些项目已完成。
