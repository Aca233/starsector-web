# 联机准备与应用合并（2026-09-20）

## 用户可见行为

- 客机只有一个主操作：有草稿时「应用并准备」，已同步时「准备」，已准备时「取消准备」。不再并排显示容易混淆的「仅应用配装」。
- 房主所有开战条件满足时可「应用并开始」；条件不满足时只应用，并明确显示缺少对手、有人编辑、未准备等阻塞原因。之后仍需房主主动开始，不排队、不在他人准备后自动开战。
- 改装底栏、角色技能页的主按钮以及各自的 N / G 快捷键共用同一个流程。技能页也显示同步/动作失败的反馈。
- 个人配装提交只取消自己的准备。其他人的准备状态保留，避免互相应用配装导致反复准备；队伍、玩家名单、房间规则与 AI 编成等共享变化仍需大家重新确认。
- 左侧自己的舰船列表即时预览所选舰体、配装名和舰长技能；未同步明确标为「本地预览 · 待同步」。不会修改服务端房间或让其他玩家看见未提交草稿，放弃修改会恢复已确认配置。
- 「另存方案」仍是独立保存到本机的操作，准备不会偷偷覆盖方案库。

## 保留的保护

- 先收到与请求匹配的 configure 回执，才进入 ready / start；仅收到房间广播不算确认。
- 房主使用最新房间状态再次校验开战条件。客机只操作自己的准备状态。
- 提交中锁定重复操作，快速双击不会连续触发准备与取消准备。
- 配装提交失败保留草稿且不准备；配装已成功、准备失败时，重试只发送准备，不重复应用。没有自动重试。
