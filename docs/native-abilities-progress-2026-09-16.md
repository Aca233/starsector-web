# 舰船系统与舰体插件：本轮可用性补完

> 2026-09-17 更新：29/63 个舰船系统具有战斗适配，另有1个相位线圈；50/129 项舰装有战斗效果，其中12项仍缺战役效果。**整体未完成，舰长技能树未实现。** 下面前半部分是上一阶段记录，最新增量见文末。

## 范围与边界

这不是“63 项系统、129 项舰装全部完成”的声明。本轮新增 14 项已接入战斗行为的系统与 7 项舰装；当前实际注册为可用的系统定义为 24 项（不含 NONE，也不含 Shield 单独实现的相位线圈），战斗舰装定义 35 项。系统仍采用 Web 战术 AI，没有宣称逐行移植原版 AI、专用音效或全部视觉效果。

源依据：本机 starsector-core/data/hullmods/*.java、ship_systems.csv、hull_mods.csv、shipsystems/*.system；decompiled/starfarer_api_source/com/fs/starfarer/api/impl/combat 与 impl/hullmods；decompiled/starfarer_obf 的 FAST_RELOAD/AMMO_RELOAD、BeamWeaponRay 和装甲结算实现。未运行全量导入器、未修改原版安装资源。

## 新增系统

- damper、damper_omega、cryoflux：原版全阶段减伤，欧米伽/变频的武器幅能修正，欧米伽维修速度修正。普通阻尼按舰级区别 0.33 / 0.5 承伤。
- microburn、microburn_omega、combat_burn：强制向前、时序、次数、关闭阶段保留加速度；欧米伽使用次数按原版舰级覆盖。
- dynamic_stabilizer：机动参数、三类武器射速、光束伤害、后坐力。
- temporalshell：平方效果曲线的时间倍率；玩家世界时钟反向补偿；光束伤害/视觉时钟使用发射舰时间倍率。没有添加源码中未使用的减伤常量。
- fastmissileracks：缩短不处于连发中的导弹冷却，不补弹。
- forgevats、forgevats_station：前者每次补原始武器容量，后者补满有效容量；不重置当前射击状态或冷却。
- entropyamplifier：初始锁定目标，护盾/装甲/结构/EMP 的动态承伤来源，系统结束或源舰死亡后失效并清理。
- acausaldisruptor：初始锁定，启动完成时造成固定 1 秒过载，不延长期间已开始的过载、不打断排幅。
- interdictor：实际禁用引擎组件，按贡献阈值选择；目标战机周围 200 范围内同阵营战机受影响。不使用假的减速状态代替。

CSV 时间、幅能、次数由 NativeSystemFactory 读取本轮的小型原版元数据，行为显式注册；元数据本身不能构成实现。

### 本轮机制
1. 统一 CombatSkills 登记和校验：系统专长、操舵技术、战斗耐力、冲击缓解、损伤管制、相场调制、实弹精通、导弹特化、极化装甲、军械专长、点防专精、目标解析、能量武器精通。以原版 .skill 实际启用的 effectGroups 为准，不启用废弃 Level 类。
2. 静态技能与舰装共用 flat/percent/mult 管道，不改原生 spec。动态修复、硬幅能装甲、零幅能推进进入 Ship/FluxTracker；系统次数/恢复/冷却/距离进入真实系统消费者，独立相位线圈不吃系统专长。
3. 命中时统一按来源武器类型、实际撞击位置、目标舰级和当前幅能计算加成；覆盖实体、光束、导弹拦截、近炸和弹丸爆炸。不把能量武器类型等同于能量伤害类型，不对 EMP 额外套普通伤害增益。
4. 点防技能按母舰传给初始和补充舰载机；其他自舰技能不误传。目标馈送只增益真正所属舰载机，母舰自己、友方其他航母不被强化；持续光束实时更新，母舰死亡/系统结束撤销。
5. MIRV 保存发射时 CR/系统倍率，零伤害母弹也能继承；子弹头技能倍率只应用一次，弹道子弹头不错误增加导弹生命。WeakMap 保存弹体发射来源，避免发射战机死亡被移出 roster 后失去技能，同时不把循环 Ship 对象写进联网快照。
6. 恒星防护层只减免 ENERGY 伤害，覆盖护盾/装甲/结构；其余三种伤害与 EMP 不减免。
7. 军械专长以实际武器 OP 为准；原生免费内置武器独立标记 builtIn，不能仅按 BUILT_IN 挂点类型判断。武器装卸、静态预览、实例构造都从基础数据重新派生。
8. 改装入口支持普通/精英选择，技能随方案 JSON 保存/解码/注册试战。改装 CR 不再固定70%，战斗耐力显示85%。舰队持久化/联网完整跨端方案生命周期不等于已全面验收，不能借方案往返检查宣称整个战役存档功能完成。
9. 无人机闪现使用原版200距离、3次、0.25次/秒恢复、5%基础容量硬幅能。沿用已有确定性安全落点，明确未模拟原版25距离随机散布和专用残影。
