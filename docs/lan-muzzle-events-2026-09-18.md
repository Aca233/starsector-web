# 枪口粒子事件同步与本地表现层（2026-09-18）

## 范围与结论

在已本地化导弹尾迹的基础上，只迁移 CombatFXSystem.spawnAuthenticMuzzleFlash / spawnLauncherSmoke 生成的枪口粒子。没有迁移简易 muzzleFlashes、命中粒子、爆炸、EMP、伤害、碰撞或 AI。普通单机仍走原生成路径。协议升到 24，房主、客机和中继需使用同一套构建。

这是表现层功能进展，不是联机卡顿已经解决。8/32/100 舰固定样本的平均快照字节分别再减少约 3.54% / 3.55% / 2.99%；不能说是相同幅度的总 CPU、带宽或 FPS 提升。

## 实现

- 房主只为可信深冻结的原生样式记录出生时间、事件 ID、坐标、速度、方向、样式与生成前 RNG cursor。客户端依据显示时钟生成并衰减粒子。
- 复用原生成公式，房主仍以原顺序逐次推进同等次数的原生随机 cursor，不生成这批粒子、不逐帧更新它们。不会更换世界 RNG，也不使用乘法跳步或 uint32 截断，保留长局大 cursor 的浮点加法语义。
- 事件窗口保留到最长粒子寿命后 2 秒，每帧携带完整窗口与批内样式字典；事件去重、未来事件等到显示时钟、过期事件不重播。跳过快照、时钟回退或重同步时可按年龄重建，避免重新喷一团烟。
- 上限：4096 个事件、512 个样式、65536 个展开粒子；客户端和中继都验证。客户端跨窗口积累也有上限。单个样式每类 count≤2048，实际最长持续时间≤30秒。
- 可变样式、未知向量/RNG 行为、队列满或不支持的参数回退到原房主粒子路径。这不是删除效果或减少舰船。
- 客户端用不进入快照的 WeakMap 渲染层，原同步粒子和本地粒子可同时显示；暂停跟随显示时钟，退出/失同步清理。自包含事件窗口的构造耗时计入 Worker captureMs。
- 没有更改物理 dt、AI/伤害规则、恢复预算、SnapshotPlayback 或 MotionPrediction。

## 下一批适合本地的内容（未实现）

1. 命中火花、爆炸烟尘和光效：只同步已确认命中/爆炸事件及位置、样式、种子；伤害和爆炸半径判定仍在房主。
2. 小型装饰碎屑：同步来源事件，本地生成、旋转和衰减；不能包含会挡弹的 hulkFragments 或小行星。
3. 护盾受击波纹：权威确认命中，客户端扩散/淡出；护盾是否挡住伤害、幅能和过载不本地决定。
4. EMP闪电形状：本地生成分叉/闪烁，端点和确认的EMP事件仍同步，瘫痪判定保持权威。
5. 伤害飘字动画：数值来自房主，仅动画本地。持久战损贴花还需要重连可重建基线。

镜头、HUD、插值、喷焰绘制、震屏偏移与音效播放已经在本地。不得关闭整个 CombatFXSystem：它还管理可碰撞残骸，且其他效果共享 visualRandom。后续迁移同样需要保留随机消耗顺序，或单独验证更换随机流不会改战斗。

## 实际双端验证

同机 Edge 两个真实浏览器页面、房间服务器、房主 Worker、WebSocket 和实际渲染路径。没有强制降低同步频率、放大恢复预算或换物理 dt。隔离基线构建 2026-09-18T08:45:20.012Z，最终候选 2026-09-18T08:46:50.112Z；两份构建均成功，只有已有大 chunk 警告。

- 候选8舰：20秒观察窗口仍running、tick1197、约0.9975×、0次恢复、361个快照；双方W按下/释放均经权威状态及ACK验证。随后客机刷新重连，W按下与释放再次成功（tick1884/1990），最终无恢复/错误。此短测通过，不代表两台物理电脑或长时间稳定性。
- 32舰相邻同源对照：旧路径10.507秒、tick567（Worker573）结束；候选11.537秒、tick624（Worker636）结束。双方都是两次恢复后第三次过载停止。不能把多存活约1秒当成已经提高稳定性的证据。
- 候选100舰：2.226秒、服务端tick43（Worker55）过载结束，4份快照、两次恢复；双方曾loaded。仍未达到百舰实时要求。

证据：artifacts/lan-muzzle-events-live.json。保留这次有界表现层迁移，结论是局部功能进展，不是联机性能总体完成。未替换3005（PID18988）或普通dist，诊断服务/浏览器均已关闭；要试新功能需另起这套同版本构建，刷新旧入口不会自动升级。
