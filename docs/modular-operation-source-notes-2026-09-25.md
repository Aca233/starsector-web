## 预期 → 当前差异 → 验证
1. 战斗选择有效受损部件 → 圆形碰撞半径与距中心排序会让母舰空白处抢选模块，免伤骨架也能锁定 → 真实轮廓优先、轮廓边缘容差、插值旋转与不可攻击过滤；用实际模块装配旋转/移动和骨架场景核对。
2. 母舰已有召回语义覆盖子模块 → 无母舰机库时拒绝指令、HUD 漏掉子模块联队 → 准入/回执/显示覆盖存活整组，死亡与其他母舰不受影响，暂停时立即同步。
3. 原位模块改装，不串编辑对象 → 同一部件重复选择重置面板、Shift 拖动释放修饰键后仍可能点击、Esc 直接退出 → 同路径选择无副作用；拖动不触发点击；Esc 先返回上一级模块。Esc 分层返回是明确的 Web 易用性优化，不冒充原版行为。
4. 保持既有方案/预算/整舰撤消 → 不改数据格式；缓存未变的模块上下文与几何，避免缩放/平移时重复编译。
