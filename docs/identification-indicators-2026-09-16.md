# 战斗敌我识别框 · 2026-09-16

## 问题与修复

用户参考图中的橙色菱形是敌方导弹/火箭的 FF indicator，不是调试框。原 Web 版本只有锁定目标的四角框，缺少常规识别标记。

新增独立 WebGLIdentificationPass 与 IdentificationVisuals：
- 所有存活敌舰（包括敌方增援/战机）均可显示识别菱形，不依赖当前选中目标。
- 敌方导弹、无制导火箭和空雷显示标记；己方导弹、诱饵、普通炮弹、光束和显式关闭标记的导弹不显示。
- 标记随实体插值移动，固定世界朝向；尺寸用真实碰撞/护盾规格，不使用尾焰或贴图长度猜尺寸。
- 采用原版橙色 [255,100,0]、1.3 倍菱形半径、三个内缩边带与普通透明混合；无需新贴图或资源导入。
- 相位改变标记透明度，不错误缩小尺寸。已移除实体不会留下标记；渲染按视口和对应实体图层裁剪。
- .proj 的 renderTargetIndicator（默认 true）经统一源加载器、WeaponSpec、挂点发射传到 Projectile；内容验证器检查其布尔类型。已有内置导弹未指定时使用原版默认值，不重跑生成器。
- 调试 markers 图层与本层无关。原有锁定目标四角框仍是独立语义，未在本轮重写。

## 原版只读依据

相对于 decompiled/starfarer_obf/com/fs/starfarer/：
- combat/entities/Missile.java:392, 780–784：max(sprite collision radius,15)、2.5 线宽、排除友方/诱饵/显式禁用标记。
- combat/entities/Ship.java:3145–3182：常规舰船基于护盾半径和中心的识别框；战机 3.5、其他舰船 5.5 线宽。
- renderers/OOoO.java：敌方菱形、友方方形、普通 alpha、0.3×0.37 透明系数、三个边带、1.3 外接半径和 1.414 内缩。
- O0OO.java / settings.json:textEnemyColor：敌方识别色 [255,100,0,255]。
- loading/WeaponSpecLoader.java:431–436,498：标记半径数据含义和 renderTargetIndicator 默认值。

原版实际导弹/舰船渲染路径会跳过友方框，不能因渲染器支持方形就给己方所有炮弹加方框。
