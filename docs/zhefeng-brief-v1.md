# 折锋级突击驱逐舰 · v1

更新：2026-09-29。状态：**当前工程已集成并通过定向可玩验收**。原创舰，无原作身份或官方设定宣称；14DP为初始设计成本，尚非最终平衡。未交付独立安装包。

## 定位与参照

- 14DP / 110OP，常规战术驱逐舰；近中距离抓敌方装填窗口破甲，不兼任远程狙击、航母或模块巨舰。
- 本机 `starsector-core/data/hulls/ship_data.csv` 静态参照：锤头10DP/95OP，5000结构/500装甲/4200载荷/250耗散/90航速；执法者9DP/110OP，6000/900/4000/200/60；破阵11DP/105OP，4000/250/7500/500/90。2026-09-29读取，精确原版版本未核实；不是原版实机对战证据。
- 已实际查看锤头与执法者原版舰体素材，采用低饱和暖灰装甲、厚薄结构层次和嵌入式炮座；新生成原创舰体，不是拼接原版舰体。
- 裸舰实际规格：5200结构、650装甲、6000载荷容量、350耗散、100航速、前向180°盾、0.9盾效率。基础数据为5000容量/400耗散，内置插件再加1000容量、减50耗散，避免重复计入。
- 单体舰、无机库/舰载机、无模块；舰体可见长300世界单位。四档是宿主安装规则，本舰只使用中、小两档，不为“高级”硬塞大/超大槽。

## 核心循环：断路反击

右键开前盾接近 → F启动 → 1.5秒承压 → 3秒无盾反击 → 1秒恢复 → 12秒冷却。

| 阶段 | 收益 | 代价与操作 |
| --- | --- | --- |
| 承压 IN，1.5秒 | 护盾承伤载荷×0.5，近防仍可工作 | 非近防停火，航速−30%；需已开盾、非排散/过载，启动花180软载荷 |
| 反击 ACTIVE，3秒 | 实弹射速×1.6，每发射击载荷×0.85 | 真实强制关盾并拒绝重新开启；不增加弹伤、射程、弹药 |
| 恢复 OUT，1秒 | 解除开盾锁定 | 实弹射速×0.6；玩家须右键重新开盾，不会自动抬盾 |
| 冷却，12秒 | 恢复常态 | 不能反复开关跳过阶段或刷新武器冷却 |

排散、过载、死亡中断收益；不返还180启动载荷、不补弹、不重置武器时钟。AI在前盾开启、低于45%载荷、有真实可达射击解且没有撤退/航点/绕障要求时使用。

核心选择：接住一轮火力后冒险关盾反打，还是保留护盾继续周旋。对手可后撤出射界、侧击，或保留齐射惩罚无盾阶段。高爆主炮负责抓露甲，不是无条件破盾。

## 素材、宿主与交付边界

- 经用户本地代理 `gpt-image-2.5` 生成一张原创舰体；源图 `output/imagegen/zhefeng/hull-v01.png`，提示词同目录 `hull-prompt.txt`。
- 实际源图1071×1468 RGBA，经透明背景及主轮廓清理、裁切和标定生成正式图 `public/game-assets/graphics/ships/web_zhefeng/hull.png`，282×512，217190字节。处理记录 `output/imagegen/zhefeng/production-art.json`。
- 正式舰体不烘进武器、尾焰或护盾；推进与枪火复用正式原版纹理。技能反馈依靠真实强化盾/关闭、阶段状态与开火节奏，不新增占位光圈。
- 注册舰体、4武器、技能、3插件、两套配装及资源清单，不依赖其他扩展舰。
- 最小宿主扩展 `ShipSystemDefinition.defenseEnabled` 为纯查询，连接现有 `ShipSystem.blocksShields`，同时影响按键和实际防御，非仅隐藏盾图。新系统纯数值加入可信统计路径；AI世界扫描没有冒充可缓存纯函数。
- 当前工程可直接选舰；隔离注册表测试仅证明数据依赖闭合，不证明ZIP安装、自定义规则自动加载、跨版本兼容或多人。没有打包、公开发布或修改其他舰船数值。
- 原版资源仅用于本机开发/测试；本轮未取得重新分发许可，不能据“能读取”推定能公开发布。
