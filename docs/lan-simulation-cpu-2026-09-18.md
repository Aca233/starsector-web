# 联机真实模拟 CPU 优化：二维距离（2026-09-18）

## 状态

合入 `src/engine/math/Vector2.ts` 的距离计算优化和 `src/network/CombatSnapshot.ts` 的快照采集优化，**尚未解决大规模联机过载**。

用户指出模拟变慢不能靠显示平滑掩盖后，已撤回本轮新增的 HostMotion 本机运动通道、HUD 和 SnapshotPlayback 泛型改动；没有将它部署到 3005。其 artifacts 构建和诊断只保留为撤回记录，不是交付版本。两名子代理的首次调用均因 429 未开展工作。退避后重试的快照子代理成功完成局部优化，主线程审查并进行合并验收；未返回工作的火控子代理不计入成果。

## 正式改动

`length()` 和 `distanceTo()` 在原生数学函数环境中使用缩放后的双参数范数：以较大绝对值为缩放系数，计算 `sqrt(1 + ratio²) × max`。避免通用可变参 hypot 的额外处理，仍保留溢出、次正规数、NaN、Infinity、正负零的语义。

- 没有改变物理步长、舰数、AI 频率、武器或碰撞规则。
- 坐标读取顺序不变；调用前先读取 Math.hypot，保留 getter/自定义回调的时序。
- 启动时遇到自定义 hypot/abs/sqrt 时不启用快路径；运行中替换 hypot 也回退，并保留 Math 接收者。后续替换 abs/sqrt 不影响原生 hypot 的语义。
- 当前 Node / Chromium 的边界和回放样本逐值一致，不将其表述为所有 JS 引擎的形式化浮点证明。

## Worker 墙钟验收（含真实采集/编码，不含绘制和网络转发）

每组至多运行 12 秒，自动消费快照，保持标准 1/60 步长和原过载保护。

- 8 舰：旧约 0.996×、新约 1.000×。
- 32 舰：旧约 0.994×、新约 0.999×。
- 100 舰：旧在约 10.55 秒过载终止；新完成 12 秒窗口，但约 0.935×，且发生过载恢复。

推进率由最后发布的 tick 和墙钟估算，不是控制响应时间，也不是端到端多人浏览器验收。百舰候选仍不满足实时运行要求，**不属于修复通过**。
