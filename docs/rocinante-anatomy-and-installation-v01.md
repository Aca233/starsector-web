# 罗西南特：结构与六炮安装研究 v0.1

2026-09-29 · **多视角参考与安装设计，不是完成的舰体图，也不是可玩舰船。**

**后续进展：**普通内置实弹炮的宿主分层已按本文接入，见[实现与验收](rocinante-depth-implementation-2026-09-29.md)。本文多视角证据不变；正式六门PDC的Web标定及生产渲染验证见[任务书§27](rocinante-development-brief-v01.md#27-六门pdc正式安装数据与工程验收2026-09-29)。完整军械和可玩舰仍未交付。

目标：解决腹面、喷口、鱼雷出口和六门PDC的俯视表达，避免先画错再靠特效遮掩。玩法与数值只维护在[任务书](rocinante-development-brief-v01.md)，本文不另立一套参数。

## 1. 本次结论与修正

- **六门PDC不漏装**：R04同人模型可见四门侧炮，以及背、腹各一门。六门全部保留在设计账本；不表示原作版本考据全部完成。
- **腹炮不搬家**：腹面后段中轴炮从真实底部位置发射；炮体、枪焰、初始弹体都应受自身舰体投影遮挡，不能把炮口挪到船边。
- **单个主喷口**：尾部研究视图可见一个圆形主发动机腔；不改成几根普通战斗机火尾。RCS是独立小喷口，不冒充另几个主发动机。
- **撤回舰艏结构误认**：两条前伸结构暂不命名。仅凭外形不能把它们当作轨炮双导轨；后装轨炮的部位仍需对应改装版本证据。
- **撤回左右鱼雷位假设**：R04作者将中央上层前斜面的一组盖板区域标为“Torpedo tube”。先核实，不另画左右两个大导弹座。

## 4. 腹炮：最小可实现视觉契约

### 4.1 当前缺口

已经查看的生产路径：

- `src/engine/render/webgl/passes/WebGLShipPass.ts`：舰体先画、武器后画；HIDDEN跳过可见武器，不是腹面层。
- `src/engine/render/webgl/WebGLCombatRenderer.ts`：shipPass之后才绘制projectilePass，因此单独调炮塔层级仍会让枪焰/子弹盖到顶面。
- `src/engine/render/webgl/WeaponInstallationRenderer.ts`：提供承座与固定前景，不是对整舰轮廓的弹体遮罩。
- `src/studio/InstalledWeaponArt.tsx`：renderBarrelBelow只交换枪管/底盘次序，不让武器落到舰体下面。

**以上记录实现前的差异。** 后续已完成实际渲染投影/Worker核对并接入首版支持，不是只加字段；范围限普通内置实弹炮，见实现档案。

### 4.2 拟议发射流程

1. 权威发射入口按腹炮当前枢轴、指向和真实炮口产生一发弹体；立即成为世界坐标弹体。弹药、冷却、碰撞、伤害正常结算，不等待视觉露出。
2. 腹炮和枪焰属于本舰下层；枪焰是否随炮口运动沿用效果契约，不能让已经射出的弹体继续跟舰体转。
3. 初始出射阶段的弹体、可见曳光和拖尾受**本舰当前插值姿态的轮廓/深度遮罩**裁切，隐藏被上方船壳覆盖的部分；不简单按中心点整颗开关，避免边缘突然弹出。
4. 完全离开初始遮挡区域后进入普通弹体显示；解除的是显示关联，不改变轨迹、伤害或余下寿命。关联解除后不重新吸附母舰。
5. 首帧已在轮廓外可直接显示；持续重叠不能以固定毫秒数强制露出。舰体转向、暂停、提前命中、死亡或移除时要正常清理，不凭空生成补发弹。
6. 本舰视觉遮挡和敌舰/护盾/地形的物理碰撞是两个问题；不得借此赋予穿盾、穿敌舰或忽略残骸能力。

可先评估按拥有者局部合成/遮罩的实现，而不是把所有弹体永久放到所有舰体下面。下层只影响相关武器，旧舰默认绘制顺序保持不变。原段为设计契约；后续选择了“所属舰体之前绘制原有弹体效果”的合成方式，不新增全局着色器遮罩。算法细节及实际通过项见实现档案。

### 4.3 改装与设计页

- 腹面实体按真实深度显示；遮住就是遮住，不往顶面描一门假炮。
- 内置位始终列在安装清单，命名“腹面内置近防炮”；允许通过清单/独立选择标记查看。标记是编辑器辅助，不是战斗贴图。
- 选中时展示位置/射界和内置锁定状态；重叠挂点仍可分别选择。腹面示意不能替代战斗中的实际分层。
- 保存读回、武器说明图、损坏/禁用状态与同一稳定槽ID对应。

## 5. 进入素材制作前的限制

可以沿R01–R04建立材质和部位参考，但还不能宣称完成原作还原。需要：

1. 后装轨炮的对应版本图片与位置交叉证据；不要将Tachi舰艏结构误认为改装炮。
2. 两个鱼雷出口的版本证据及出射方向；现阶段不冻结左右或上下布局。
3. 确定可用的正式素材路线：自制2D/合法授权模型离线烘焙均可。R04不可下载、许可未明确，不能当作免费模型源或直接截成舰体图。
4. 获得正式母版后统一舰长、轴向、枢轴、alpha轮廓、全部承座/炮口/喷口；再填安装坐标。

不新增可玩目录条目，不生成占位spriteURL，不用另一个同人低质量缩略图填空。玩法规则的无视觉开发可独立继续，并不被美术等待全部阻断。

## 6. 舰船最终验收清单（本舰未执行；宿主子集结果见实现档案）

| 场景 | 必须满足 |
| --- | --- |
| 正常/近景；舰体0°/90°/180°/斜角 | 侧炮贴合；背/腹不互换，枪管与实际出射线同轴 |
| 腹炮朝左右及允许射界边缘射击 | 从真实位置出弹，逐段露出，无顶面枪焰、无船边瞬移 |
| 高速平移与急转中开火 | 离膛弹体轨迹不跟船转；遮罩跟当前显示姿态，不能用滞后一帧位置 |
| 暂停/恢复；炮坏/舰毁/对象移除 | 无延迟补发、孤立枪焰、悬挂遮挡引用或卡住的子弹 |
| 设计页选择与保存重开 | 六个内置近防位全在；重叠位可分别选中，未漏腹炮 |
| 敌盾、残骸、战机、近防目标 | 正常物理规则不变，视觉遮挡不改判伤与射程 |
| 至少一艘旧舰回归 | 原有武器、弹体、安装前景的绘制行为不被新接口改变 |
