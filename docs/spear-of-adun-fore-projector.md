# 亚顿之矛：前部轴向聚焦器制作契约

2026-09-27。明确的 Web 改编武器方案，不声称这是原作炮名、太阳射线实体炮塔或原作开火动画。

## 角色与安装

- 标志性的舰体内置专武，绑定唯一武器身份；不是默认可拆的推荐装备。
- 固定舰首轴向发射，不将整组机构当作炮塔跟随鼠标旋转。左右原生机构可以开合，装备锁定与运动能力分开定义。
- 定位为需要对准、预判和暴露窗口的对大型目标聚焦攻击，不承担全向近防。开放的其它武器槽负责补足压力和盲区，而不是所有炮同质化。
- 作为武器保留编组、手动/自动开火；不借用 F 技能键绕开配装与武器状态机。
- 它不取代原作“指定路径的三道太阳射线”等舰体级能力；不把原生骨架的12个控制段映射成12门炮。

## 状态契约

1. 待机：原模型闭合姿态，保留原金蓝材质。
2. 展开：两侧围绕原控制骨展开，各12度。动作由真实骨架渲染，不对二维整图做假旋转。
3. 蓄能：保持开合位置，提高该机构原贴图中已有能量面的发光，固定舰体与核心不跟着闪烁。
4. 有效发射：后续使用固定轴向束。释放过程中始终服从舰体姿态，不伪装全向炮；当前没有完成光束贴图或命中表现，不用通用粒子填空。
5. 收束和回位：沿骨架收回，回到同一闭合轮廓。

展示序列的1.5秒只是美术预览节奏，不是已批准的武器射速；运行时展开/蓄能/有效发射/回位应由真实武器状态驱动，不能自动循环。蓄能前失去有效射界要能取消并回位；实际中断、幅能和光束结算需接入后验证，不在此宣称实现。

## 当前实物

`output/spear-of-adun-art/fore-deployment-v01/`：

- 可编辑 `fore-deployment.blend`，原始核心动作在此派生场景中固定为第0帧。
- 16个设计关键状态；保存动作后重新打开 `.blend`，以30fps从真实骨架插值渲染46张128×160局部贴图。不是图像插值或重复静帧。
- 同坐标固定舰体底图及带2px边缘延拓的图集。底图挖掉动画区域，不能把局部动画覆盖在仍带闭合机构的完整舰体上，否则会残留双影。
- `animation-art.json` 保存局部坐标、图集帧矩形与阶段区间；这些是离线美术资产，不是已注册游戏武器。
- `deployment-preview.gif`、无损动画WebP与关键状态对照供审阅。

## 已修正的具体制作问题

前轮拆分后的静态渲染可以对齐，但 Blender 更换网格数据时会清空复制对象的顶点组。首次动作检查发现轮廓完全不动；现已显式重建每个段的真实骨骼组与单位权重，并在保存后重开场景验证全部2432顶点仍有绑定、展开时实际几何边界变化、回位边界一致。不能用“设置了关键帧”代替动作验证。
