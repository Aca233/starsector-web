## 1. 玩家承诺：亲手改变一场交战的形状

**万有引力号不是后排奶船，也不是引力近战猎杀舰。它是能站在前线、操纵局部交战几何的舰队支点。**

- 实验：有常规舰不具备的强干预能力，同时需要明确的建立时间、持续负荷、反应窗口和失稳恢复；不靠随机故障体现“实验”。
- 引力：改变运动、轨迹、空间分布。控制不是百分比减速，协同不是直接乘伤害。
- 辅助：创造原本不存在的射击机会，拆开敌阵，救出关键队友；收益主要由舰队共同兑现。
- 战列舰：具有正常自卫火力、稳定的前线生存底盘。大体量和较慢机动仍是代价，不能一边强控场一边无限瞬移。

一句话核心：**把“堵住的射线”打开，把“集中的弹幕”分开，把“被困的友舰”拖出来。**

## 2. 独特机制：一个投射器，三种场形

不堆两个需要同时照看的独立场，不储存炮弹，不要求等待友舰特定齐射。整艘舰只有一套共享投射阵列，玩家在以下用途间分配它：

1. **圆形透镜**：自由移动，局部聚拢/排斥与弹道弯曲，是日常操作。
2. **援护牵引**：集中资源主动改变一艘友舰的运动，是救援操作。
3. **线性剪切**：把圆场展开为一条有限潮汐轴，收束或分开战线，是创造火力窗口的战术操作。

三者共享距离、幅能和恢复约束。援护与剪切不能同时满功率运行。选择其中一个，意味着放弃另一个的即时收益。

## 3. 操作设计

| 操作 | 能力 | 玩家实际操作 | 明确代价 |
| --- | --- | --- | --- |
| 左键按住 | 引力透镜 | 准星指定目标位置，场心有有限移动速度；在敌阵、弹道交汇点和友舰附近持续调整位置 | 距离、建立时间、持续幅能、对象共享预算；放手解除 |
| 右键点按 | 极性换向 | 吸引/排斥切换；输入立即接受，受力经过短暂连续过渡 | 不产生额外免费冲量，不重置对象预算 |
| F | 惯性接力 | 指定场附近的一艘友舰，再用移动场把它牵往安全方向 | 占用主要舰体受力预算，削弱敌舰控制；最长短时维持，不能成为永久拖船 |
| G按住、松开 | 潮汐剪切 | 按住锁定当前场心，用鼠标定潮汐轴；松开展开有限时长的线场 | 占用投射器并固定位置，承担明显启动/维持负荷；不再同时拥有自由移动圆场 |

### 3.1 左键：引力透镜

**吸引**用于把轻舰拉出掩护、收束散开的敌阵、改变经过场的实体弹轨迹；**排斥**用于拆开密集接近、推偏弹幕和制造距离。

- 场的建立与移动不是瞬间完成。界面同时显示准星命令点和实际场心，不能让显示已到位而物理还在旧位置。
- 敌舰按真实装配根质量和推进抵抗，轻舰更容易被改变航迹；重舰逐渐偏移，不定身、不任意摆放。
- 弹丸、导弹和可移动环境物体受有限力。光束不改道，固定环境不被搬走。
- 普通友舰不自动受力；只有 F 明确指定的对象接受援护。弹体的方向变化不改变所属阵营。
- 取消旧的固定 1200 DPS 牵引伤害。操纵场本身不持续扣血，也不因为“引力”默认穿盾。

### 3.2 F：惯性接力——主动把队友拖出来

这不是“给队友放一个自动护航圈”。

1. 把圆场放到受压友舰附近；F 以明确锁定友舰为优先，没有锁定时只选择场心很近、界面已高亮的一艘友舰。
2. 接受指令时保存该装配根 ID。后续移动场指向撤离路线，持续施加有上限的牵引加速度。
3. 友舰继续转向、射击和推进，不改位置、不赋予无敌、不自动修复。AI 可配合撤离方向，但不能永久覆盖舰队命令；真人友舰有拒绝援护/退出的机制。
4. 最长维持约 3 秒。再次 F、松左键、目标失效、脱离距离或本舰负荷不足时结束；结束后保留已经获得的实际速度。
5. 只在吸引极性可建立。右键成功改为排斥时先正常结束援护，不能把一次救援默默变成甩飞友舰。

与主体的取舍：接力期间，大部分舰体受力预算给这艘友舰，敌阵控制明显下降；不能同时把敌舰全部拉住又全速救队友。

可以选择本舰作为援护对象，但仍按自身质量和推进约束；不是额外的瞬移技能。救重型友舰通常只是提供关键的速度修正，不承诺几秒内搬走整艘战列舰。

### 3.3 G：潮汐剪切——改变场的几何，不只是加大力度

按住 G 时，圆场心暂时固定；鼠标从“搬场”切为“设轴”，出现细的方向预览。松开后才提交位置、轴向、极性与费用。未接受的启动不能销毁已有合法场。

线场是一个投射器生成的成对受力区域，不是两个独立可操纵场：

- **排斥剪切 / 开道**：轴线两侧的敌舰逐渐向外偏移，打开原本被护卫或密集阵型遮住的射线；偏离轴线的实体弹向两侧分开。
- **吸引剪切 / 合流**：两侧目标向轴线靠拢，形成可集中施压的交战带；进入线场的实体弹获得有限的横向收束。

与圆场不同，它主要施加垂直于轴线的力，不把所有东西拉向同一个点。位置和轴向选错，会给敌人打开射线、收束敌方弹幕或让本舰失去保护。

线场持续约 3 秒，之后需要恢复。期间不能继续移动场心，不能叠加 F 援护。可提前取消，但不返还已付费用；重新建场不继承此前工作预算。极性可换向，但不会刷新持续时间或重新支付一份对象冲量。

**G不直接爆炸、不扣一圈血，也不要求友弹恰好经过才有价值。它首先能拆阵/合流，然后武器利用这些变化。**

## 4. 武器体系：提供压力，利用自己制造的窗口

### XL：内置引力投射器

承担三种场形、极性、对象预算和动态负荷。没有额外假炮弹；仍参与实际武器损伤，失效后场退出。它是舰队几何的组织者，而不是另一门无视盾甲的输出炮。

### M：两种同平台实体弹武器

不再让四门合计只有 480 纸面 DPS 的旧自卫炮承担全部单独作战。建议同一中型平台提供两种弹药版本，默认各两门：

| 武器 | 正常作用 | 与引力联动 | 不允许的捷径 |
| --- | --- | --- | --- |
| 质量校准炮 | 动能实体弹，持续压盾，稳定中程射击 | 可计算圆场/线场中的有限修正路径，从已打开的射线施压；帮助迫使敌舰改盾或走位 | 不因经过场而重置射程、加单发伤害或自动绕盾 |
| 质量崩解炮 | 高爆实体弹，攻击裸露装甲，提供正常破甲手段 | 在合流后的目标分布、开道后的侧向窗口中接上破甲火力 | 不用船内必中、无限贯穿或无条件范围伤害冒充破甲 |

安装类别仍为现有 M 能量位所允许的 ENERGY；“发射实体弹”不意味着擅自把槽改为弹道位。

**协同火控**只改变实际瞄准路径：当当前场与目标之间存在可行路径，本舰质量炮尝试利用场；射界、炮口、总飞行预算或最大转角不满足就正常直射/等待。不能凭空把射击起点搬到场心。

这一预测必须用与权威物理一致的场模型。若实现不了正确预测，先保留正常射击并明确标记“协同火控未完成”，不能画弯曲轨迹却仍在旧直线上结算。

### S：偏转阵列与实体近防

- 偏转阵列提供有限的本舰近身偏转，处理少量危险实弹，不替代主场。
- 实体近防负责真正击毁可拦截弹药，弥补偏转只能改道的不足。
- 支撑玩家把注意力放在战线，但不能自动形成无敌防空。

### 友军协同

不是自动让友军炮口都瞄向你的场，也不夺走友弹或队友控制权。你改变目标/射线/经过场的轨迹，友军按自己的火控继续攻击。

本舰专用质量弹可以有明确的较高可校准额度；普通友弹只接受较低、有累计上限的修正，且多人需可拒绝协同。不能按“友方”直接增加伤害或无限制导。

线场中的敌方实体弹也有机会利用合流/通道：打开射线不等于单向无敌屏障。这是必须让玩家看懂的风险。

## 5. 真正可玩的战斗流程

### A. 拆开屏护，而不是绕盾必中

敌方护卫堵住后方主力，友舰炮火频繁被截住：

1. 圆场排斥干扰护卫接近，自己的质量炮维持压盾。
2. 沿友舰到敌主力的方向画 G，排斥剪切把护卫向两侧推开。
3. 本舰和友舰利用新射线射击。敌人可以撤退、换位、转盾，或反用通道还击。
4. 窗口快结束时决定继续持场还是撤回保护本舰。

收益不是技能直接杀人，而是让一轮原本打在护卫身上的火力真正威胁主力。

### B. 让散开的目标进入同一条火线

敌方驱逐舰分散接近：

1. 用吸引圆场改变其中一侧的路线，而不是同时控制全图。
2. 画吸引剪切把这一局部战线收束到队友的射击带。
3. 动能炮压盾，高爆炮攻击暴露目标；队友的穿越射线也更容易获得机会。
4. 如果敌弹正在沿此方向进入，合流可能反而危险，要提前换向或撤场。

### C. 真正救援

前线友舰过载，敌舰与导弹正在接近：

1. 圆场排斥先偏转局部来袭实体弹，争取一点时间。
2. 转吸引，把场放到友舰附近，F 指定援护。
3. 将场向掩体或本舰方向移动，给友舰有限撤离速度；本舰质量炮和近防掩护。
4. 放弃这段时间的拆阵能力。光束仍可能击中，救援不保证成功。

### D. 没有队友时

本舰用混合质量炮正常交战；圆场干扰敌舰接近/实体弹道，G制造自己的射击窗口，F可有限修正自身运动。没有友舰不意味着两项技能永久失效，也不要求环境中碰巧有石头。

新手可以先只使用圆场和正常炮火；熟练玩家通过场的位置、剪切轴、换向时机和援护路径扩大贡献。基本战斗不能被锁在一串五步连段之后。

## 6. 逻辑边界、反制与失败

- 力只改变速度/角速度允许的部分；不用目标位置写回实现“牵引”。不凭空关闭推进或替敌人自动转盾。
- 模块舰按装配根总质量及真实接触处理，不重复推每个模块，也不把附着模块撕走。
- 使用统一的对象和投射器预算；多个场、反复进入、换极性或重新绑定不能刷无限增量。
- 角度、冲量、速度、作用时间与数量都有限。友弹修正额度按弹体生命周期累计，不因进出场或换场清零。
- 保留弹体原始归属、伤害、寿命、引信、剩余飞行预算与拦截属性。一般导弹继续原有制导，不能被悄悄变成我方导弹。
- 无效、衰退、地雷、诱饵、船体爆炸以及弹道光束不冒充可操纵飞弹。
- 光束舰是明确反制：主场不能拦光束，必须靠拆阵、射线遮挡、本舰抗打底盘和援护机动应对。
- 重舰推进、远程火力、拉开距离、有效障碍和集中攻击本舰都能降低收益。G固定线场可被绕开。
- 普通友舰受力必须显式授权。多人支援是有拒绝机制的合作，不是允许操作者强制拖走他人。
- 本舰排散、过载、撤退、死亡或投射器损坏时，相关状态完整退出，不留隐形牵引或幽灵修正。

这里的选择性场投射是原创游戏技术设定，不声称现实引力能天然识别阵营、无反作用推进或任意转移能量。

## 7. 资源与初步规格

### 只使用幅能，不增加储弹库存或第二条资源

圆场空载维持成本低；实际影响的对象越多、质量与修正工作量越高，负荷越高。F/G有额外启动和维持费用。对象预算满时收益分摊，不能通过“影响更多对象”白赚输出。

负荷不足时场安全退出并进入短暂恢复，不随机炸船。开空场、换向、失败选择不能重复扣费用；主动取消不返还已经使用的工作量。

### 暂不冻结最终数值

以现有 60 DP / 280 OP、1 内置 XL / 0L / 4M / 6S、无盾无相位无航空为基线。先验证能力的实际价值，再决定装甲、幅能及部署成本；不先靠大幅加血遮住机制问题。

供首轮原型使用的候选，不是已平衡规格：

| 项目 | 候选目标 | 待验证原因 |
| --- | --- | --- |
| 圆场 | 约 1400–1500 炮口维持距离，约 450–500 半径 | 与现有约 668 世界单位舰长、前线距离和实际轮廓匹配 |
| 场心移动 | 有限速度，约 500–650 单位/秒 | 足够介入但不是鼠标瞬移护盾 |
| F | 最长约 3 秒，结束后约 6–8 秒恢复 | 重舰位移应有限，不能永久拖带 |
| G | 约 0.35–0.5 秒展开，约 3 秒线场，约 8 秒恢复 | 留出应对窗口，不能常驻双向控场 |
| 两型 M 炮 | 各约 250 纸面 DPS，候选 18 OP | 4M合计约1000，补足独立破盾/破甲；不是引力场另送伤害 |
| 主场直接伤害 | 0 | 移除旧牵引 DoT 与范围坍缩，把预算给控场和协同 |

## 8. 观赏性：看得见的战场变化

不以巨大光圈、激光连线或虚假弯曲炮弹作为主体。

- 圆场：稀疏物质流和星光折射显示真实场心、方向与边界。吸引/排斥主要靠流动方向区分，辅以低饱和双色，不只靠颜色。
- 援护：细的受力方向提示连接被援护舰与真实场心；航迹逐渐弯曲，不能画已经救走但舰体仍在旧位置。
- 剪切：可读的潮汐轴和两侧短方向纹；展开时场由圆形拉长，物质流随极性分开或合流。对称圆环不能冒充线场。
- 弹道：用实际弹体位置历史形成弧线，击中位置与轨迹一致；不画一条好看的导引线代替真实飞行。
- 负荷：靠收缩/不稳定程度、幅能 HUD 和简短状态表现；失稳有可识别退场，不突然无声失效。
- 暂停完全停止演出；关闭特效仍保留正常武器/舰体和必要操作提示，不隐藏实际状态。

预期高光：友舰从险境中带着速度退出来；敌护卫逐渐被分开，一条射线被打开；实体弹幕在剪切两侧形成真实弧线，己方随后利用窗口。

## 9. 为什么这版 F/G 不同于前面的方案

## 10. 实现可行性与现有证据

源码核实，不等于新玩法已完成：

- `src/engine/content/GravityArmory.ts:11–18`：当前 XL 是单实体牵引器，附带1200 DPS；M旧炮为120 DPS。需要真正替换规则，不能只改文案。
- `src/engine/extensions/ship-systems/GravitySystems.ts:119` 起：当前 F 是固定圆井，G是3200/800能量坍缩，右键本舰排斥。旧技能不是本方案的新 F/G。
- `src/engine/simulation/systems/GravityFieldPhysics.ts:16`、`:23`、`:124`、`:143` 起：已有质量响应、装配根、限幅、对象共享预算和实体弹操作，可复用同一个受力聚合器。
- 当前友弹圆井校准仅面向本舰 `MASS_DRIVER`，最多0.65秒/45°。不能声称已经支持普通友军协同；扩展后须保留更严格的生命周期累计限制。
- `src/engine/simulation/systems/GravityDamage.ts:57`、`:81` 起：旧 DoT 和坍缩损伤需要退出新舰运行路径，但保留历史探针/旧版本兼容所需边界。
- `src/engine/simulation/Weapon.ts:365`：现有弹体绑定状态只是有限圆井校准；多形态场、援护根ID、剪切轴及累计额度需要真实权威状态和快照支持。

需要新增/调整：

1. 单投射器状态机：建立 → 圆场 → 援护 或 剪切瞄准/展开 → 恢复；同一实例只有一个权威生产者。
2. 共享场几何/采样：受力、火控预测、AI决策、UI范围与正式渲染共用，不各画各算。
3. 友舰援护授权与意图；多人拒绝/退出机制先于开放强制受力。
4. 本舰质量炮的场路径预测，友弹生命周期累计预算，有限数量和确定性排序。
5. 实际 Worker和网络快照编解码；不把新字段留在主线程或临时WeakMap中。
6. 两型武器的真实规则、同平台素材标定与新默认配装。未生产的新资产不能用错配占位代替。

## 11. 分阶段验收：先证明核心价值，不一次堆满

### 第一块：圆场和本舰武器

验证移动场、极性、有限力和质量炮正常射击。看自然交战中能否通过移动场改变命中/位置，而不是仅增加微小速度。这里不好玩就停下来改核心，不用再加F/G掩盖。

### 第二块：剪切与火控协同

在同阵型同武器条件下对照：无场时被护卫遮住的射线，剪切后是否真实打开；本舰能否实际利用；敌人是否能绕开或反用窗口。实际弯曲弹道、命中点和纸面输出分开测。

### 第三块：援护

对照同样过载/弹幕条件：援护是否提供可测的撤离速度和脱离时间；是否丧失相应进攻预算；被援护舰是否保持控制；取消、拒绝和目标失效是否安全。

### 集中验证节奏

完整实现一块后集中做一次类型检查、改动文件lint和相关既有引力场景；只有具体失败才定向复查。随后才做正式资源无头画面、实际Dedicated Worker、AI自然实战与真人试玩，不逐行反复跑全套。

证据分开报告：规则/源码、生产场景、Worker、自然实战、画面、真人单局、真人多人、单舰包安装。新版本未验内容不能拿 v8 59项检查或45秒录屏顶替。

**方案成功标准：单独交战可成立；加入舰队后价值显著扩大；高手通过场位、轴向和救援选择改变交战走向；敌人有看得懂、做得到的反制。**
