# 无损Object行补丁候选：来源与边界

依据字段审计：200舰稳定Object行只有7.31%字段改变，假设稀疏行可减少74.40%图有效数字单元。这只是可验证的优化假设。

候选仅本地render通道启用新增ObjectPatch格式；UI/LAN仍发原完整Object行且拒绝补丁。LOCAL_COMBAT_PROTOCOL由14升15，不接受异构Worker构建/旧恢复记录。全新/重入/布局变化、补丁不比全行更小时仍发原格式。全量采样/精度/频率不变。

Decoder独立保留已接受Object标量行（字符串存实际值，不存每包索引）；补丁先复制并修改私有行，验证完整值、引用、可达图、预算和根，再分配/写入。预算按重建完整行计算；每条变更Object仍写全部字段，保留覆盖消费者改动的原语义。拒绝包不更改已接受行/图/版本；typed-array替换仍解析到新对象。

一次集中typecheck、改动文件lint、相关既有Decoder场景与定向补丁合同。真实Host只做一轮未插桩200舰150预热180tick串行对照，两臂同一最新冻结图，只差本候选。显式codec-pair规范化包格式进行无损全字段核验，并保持完整显示图/别名、权威witness/检查点、Host map/deployment审计。主指标Host完整交付，额外记录编码/呈现与六段稳定性；无净收益则撤回候选。

不改玩法和UI、不碰原版安装、不启动子代理/桌面/可见浏览器、不提交/发布。
