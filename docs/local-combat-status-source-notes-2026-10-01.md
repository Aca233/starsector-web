# 模拟战右上角数据（2026-10-01）

## 编码前对照

- 用户要求补上联机右上角已有而模拟战缺失的数据。现有 LanBattle.tsx 的工具栏包含阵营舰船数量、服务器延迟、绘制 FPS、关键/完整同步 Hz、战斗时间倍率；TacticalHUD.tsx 只有 debug 模式底部 FPS/JS Work，正常模拟战不可见。
- 原版显示证据仅限已有素材/界面研究，不足以证明原版有同样的网络诊断栏。本项是用户明确要求的 Web 扩展，不替代原版战斗控制台、不改其按键/布局。
- CombatSession.render 成功提交才算画面帧；FixedTimestepScheduler.simTicks 记录完成的逻辑步，session.read.combatTime 是权威战斗时间，DeploymentView 是包含后备/损失状态的只读舰船编成。直接使用这些来源，不把 RAF、固定 60Hz 目标或相位时间倍率当作实际测量值。
- 实现：提取共享数值显示，保留联机原有网络字段；模拟战常驻右上显示本机计算、阵营舰船数量、实际 FPS、本机逻辑 Hz、实测战斗倍率。500ms 采样，重启/暂停/后台切换重建测量基线，暂停明确显示暂停，无网络字段造数。
- 验证：一次类型检查、修改文件 lint，以及隔离无头浏览器中真实模拟战（Worker）的运行/暂停/恢复、低帧率限制、舰船计数、战术地图与窄窗口。保留用户当前页面和存档；不打包或发布。

## 结果

- 模拟战右上常驻数据栏已接入 CombatView：本机计算、各阵营在场舰船、实际绘制 FPS、逻辑 Hz、每现实秒的权威战斗时间倍率。联机复用同一个数值组件，仍显示自身真实的网络/关键/完整同步字段。
- 模拟战的部署账本为空，不等于场上没有舰船：计数改读 HUD 中真实的 capitalShips，不计舰载机/模块、不虚构总编成。启用完整舰队账本的本地战斗才显示场/总/后备。暂停切换不沿用前一状态的倍率，后台切回会重建采样基线。
- 地图原有右上指挥面板给新状态栏留出顶部空间；560px 窄窗口将状态栏置于地图说明下面，避免遮住指挥按钮。操作结构和控件没有替换。已查看 1440×960 运行图与 560×900 地图图。
- 最终 tsc -b 通过；五个修改 TS/TSX 文件 oxlint 通过。真实 Worker 场景验证空模拟战己方 1 艘、部署敌方 1 艘后自动更新、30 FPS 画质上限正确反映为约 30 FPS、暂停时间不推进且显示暂停、恢复后时间/读数推进、窄地图状态栏不与指挥面板重叠；pageErrors=[]、缺失素材=[]。
- 验证脚本初版发现部署账本不适用于模拟战，已修正读取来源。脚本调用增援后还须执行 CombatView.onDeployed 的资源准备步骤；补齐后暂停/恢复验证通过，未因此修改权威部署或暂停规则。部分早期截图写到 URL 未解码的路径，已修正脚本；最终证据统一保存在 `artifacts/local-combat-status-20261001/`。
- 用户页面/存档未操作，没有启动可见测试浏览器；没有打包、发布。联机本轮只提取共享显示格式，没有声称真人多端联机复验完成。
