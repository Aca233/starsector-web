# 战斗操作规则（2026-09-17）

## 唯一执行入口

离散动作由 engine/runtime/CombatCommands.ts 分派；系统可用性来自 ShipSystem.activationFailureReason，独立防御和排幅来自 Ship.defenseFailureReason / ventFailureReason。键盘、HUD、LAN主机及Worker实验不再各自实现一套开关。

## 模式边界

- 手动驾驶：鼠标默认瞄准并引导船头，镜头平滑偏向鼠标；默认 A/D 与 Q/E 横移、X 制动；按住 Shift 暂时关闭鼠标转向、恢复 A/D 转向。持续推进/左键只在战斗运行且手动驾驶时接收。
- 自动驾驶：AI接管推进、射击、系统和防御。按 U 接管时清除所有旧输入；手动按 F/V/右键会提示先接管，不与AI抢操作。编组设置、目标和召回仍是玩家指令。
- 普通暂停：停止持续推进/开火，保留显式的编组和目标修改；系统与防御的启动指令在下一模拟步开始推进。打开菜单、对话框、失焦、标签隐藏和资源未就绪都清除持续输入。
- 战术地图：地图拥有自己的投影与键盘处理，Tab/地图 R、F、V 不穿透到驾驶层。HUD按钮的键盘焦点不再吞掉后续战斗快捷键。
- 联机菜单不暂停别人；该模式不支持单机自动驾驶切换。主机只执行经过服务端验证、递增ID去重的动作。

## 快捷键

| 输入 | 唯一含义 |
| --- | --- |
| 左键 | 发射当前选定编组 |
| 右键 | 优先独立防御槽；无独立槽才是护盾/相位开关 |
| F | 主舰船系统，不复用右键 |
| V | 主动排幅，经过统一禁用/过载/配置校验 |
| R | 锁定指针下可见敌舰；同舰或空白处再次按下取消 |
| 1–7 / 小键盘 | 选择原方案对应编组，不重编号 |
| Ctrl+数字 | 只切换该编组自动开火 |
| Shift+数字 | 只切换该编组齐射/交替（Web快捷键） |
| Z | 当前舰船联队召回/出击，不改变其他航母 |
| U | 单机切换自动驾驶 |
| Space / Tab | 单机暂停 / 战术地图 |

Ctrl/Alt/Meta 的未声明组合留给浏览器。Ctrl+F不发动系统，Ctrl+R不锁定。双Shift和方向键别名不会因释放其中一键而错误清除另一个仍按住的键。滚轮缩放上下限及步进在单机/联机共用。

## 不变量

1. 目标锁定不移动鼠标瞄准点；取消或失去视野后不会下一帧自动锁回最近敌舰。AI和自动火控仍可自主寻敌。
2. 系统通过activationInput保存按键当刻的世界坐标、起点、速度、朝向和目标。蓄力型落点不会被随后鼠标移动改写；MineStrike、PhaseTeleporter、MoteControl、ConvulsiveLunge和DroneStrike已接入。LAN的每条动作携带独立aim，服务端检查格式、有限值和范围；不被下一批移动包的aim覆盖。
3. 主槽和防御槽对同一帧待扣幅能共同预留，不允许各自通过校验后合计透支。
4. 有效的toggle关闭返回成功；不扣次数、不再次产生激活事件。
5. 编组选择、自动开火和交替模式是三个不同动作。初始选择第一组真实有武器的编组，不停留在不可见空组。
6. 新增舰船能力通过定义/实例声明规则，不在键盘或网络分支按舰体ID补丁。
7. 相位OUT/COOLDOWN拒绝新开关且不播放成功音；普通盾请求状态包含等待收拢完成的pendingRaise，排幅会取消该待开盾请求。
8. 进入文本输入/对话框、窗口失焦、标签隐藏时清空持续输入；鼠标离开战斗canvas停止左键，两种战斗模式一致。
9. PPT/CR敌情查询与R显式锁定无关；取消锁定不会冻结峰值时钟。
10. 重开战斗清理旧独立能力回调与世界舰装作用域，不允许旧场次实体/回调串入新战斗。

### 鼠标方向镜头（2026-09-17）
- 普通战斗镜头采用舰船插值位置 + 独立鼠标偏移，不再把舰船永久锁在屏幕中央。偏移只由 canvas 中的屏幕坐标计算，不以含镜头偏移的世界瞄点反馈追逐。
- 来源：CombatState.java 694–703 行、combat/O0OO.java、prototype/Utils.java 的矢量跟随。普通模式增益 2，目标更新阈值为 14 × 视野缩放；偏移速度 25 + 距离，按时间积分以保持 30/60/144Hz 一致。
- 单机与 LAN 使用同一个 CameraController；CSS 位置、canvas backing pixels、缩放统一换算。该变更仅是视角，不改动鼠标转向开关、目标锁定或武器组语义。
- 首次进入不使用预设瞄点制造假偏移，收到真实 canvas 鼠标输入才开始。重开/切舰/新遭遇清空旧偏移；视觉实验室镜头锁定仍优先。
- Space 暂停仍允许平移视角。地图、部署、菜单、文本输入、失焦/标签隐藏以及鼠标移入 HUD 时冻结鼠标偏移；返回后由新的战斗区域鼠标输入恢复，地图保持自己的投影和平移逻辑。
- 无测试文件的内存回归验证方向、稳定边界、回中、微动阈值、30/60/144Hz、偏移 canvas、DPR/缩放、禁用/恢复及重开清零；正式构建与定向 oxlint 通过。
- 正式包浏览器：初始 offset 为 0；鼠标右上移动后舰船偏到左下、船头朝向不变；Space 暂停后移回中心 offset 回 0；菜单与地图中移动鼠标不改变驾驶镜头，控制台无 error。LAN 通过类型/共享算法检查，本次未组织多客户端实机对局。
- 本次仅处理普通鼠标视角；不把原版独立的目标观察模式凭空绑定到 R 锁定。

### 鼠标转向默认值（2026-09-17）
- 默认开启船头跟随鼠标；单机、LAN 控制执行和 Worker 手动实验使用同一默认常量。
- 单机设置仍可关闭，保存后重进保留；Shift 始终反转当前设置，Q/E 始终横移。
- 偏好升级为 v2：旧版初始化自动保存的 false 不再覆盖新默认，之后明确保存的 v2 false 继续有效；浏览器存储不可用时默认开启。

### 输入所有权回归修复（2026-09-17）
- 鼠标转向模式与指针有效性分离：尚无真实鼠标输入或失去输入所有权时不再朝预设/旧瞄点自动转向；不会因此更换 A/D 和 Shift 的含义。
- 模拟继续运行时，地图、部署、其他弹窗、文本输入与失焦也在固定逻辑步阻挡手动输入；自动驾驶保持独立。单纯 Space 暂停保留有效瞄点。
- 联机 v9 显式传输 pointerActive，主机不再把零按键的新包当作有效鼠标操作。复现与验收见 bug-audit-2026-09-17.md。
