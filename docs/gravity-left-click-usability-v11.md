# 万有引力号：左键易用性修正 v11

2026-09-30，针对用户反馈“左键难用、看不清是否抓住”。

## 改动前核实

- 引力抓取是本舰原创 Web 机制，原作没有本舰的等价交互；本轮不改原版操作或舰体。原版实机不占用用户桌面，未补验。
- 当前 `GravityTractor.ts` 的普通舰船/环境捕获每帧重选，0.22 秒内鼠标或目标位移可重置进度；只有弹体拥有近指针的短暂锁定。
- 选取以真实船体内部优先，但外部仍使用包围圆距离。细长舰体的空白区域和邻近实体容易混淆；容错应针对实际轮廓边缘而不是扩大整个包围圆。
- `AuthenticTacticalConsole.tsx` 的抓取状态只在左下角小字；`WebGLTacticalOverlayPass.ts` 只有 HOLD 阶段的世界单位小十字，缩小时不明显。
- 原有 `TargetShipHUD.tsx` / `ContactLayout.ts` 已支持常量屏幕像素框线、状态标签与背板。本轮沿用 HUD 投影/框线语法，不把新抓取提示说成原版复刻。

## 预期修正与验证方法

1. 第一次合法选中后，CAPTURE 黏住同一对象直到原捕获计时结束；鼠标可提前拖动。松键、目标失效、遮挡、距离、射界及其他中断仍有效，不跨障碍自动抓取，不偷偷切对象。
2. 手动选取允许靠近实际轮廓边缘；真实内部优先于所有宽容边缘，重叠候选保持确定顺序。AI 不扩大瞄准容错。
3. 目标旁显示捕获进度 / “已抓住”及剩余秒数；固定屏幕粗细的框角，HOLD 时明确拖锚与实体的连接。提示不依赖粒子/折射特效，不改变右键、F、G。
4. 用户随后提供截图指出准星常驻说明框遮挡视线，已取消这一设计：IDLE 完全隐藏场上标签，失败/冷却说明仍在原左下角武器状态。CAPTURE 只显示目标外侧的“捕获中 xx%”小标签，HOLD 只显示“已抓住 · 剩余秒数”；不再有两行操作说明、大背板或拖锚文字。标签不捕获鼠标事件，未选择主控、自动驾驶、战术图或输入阻塞时隐藏。
5. 在既有主线程/真实 Worker 规则场景覆盖快速拖动、轮廓边缘、重叠优先、取消与遮挡；在既有正式模拟器/画面场景观察 CAPTURE→HOLD→释放及关特效状态。实现完成后集中做类型检查、定向 lint 和相关场景。

## 用户追加：加范围，不加伤害

用户明确“主要是加范围，伤害还可以”。本轮只把左键捕获/牵引及拖锚上限从 1450 提高到 **2000**（约 +38%）；单体潮汐伤害仍为 1200 能量/秒，牵引强度、费用、5 秒保持及 1 秒恢复不变。F 的半径/维持距离、G 半径和伤害规则均未改。存档武器 ID 不变，不覆盖配装。

权威捕获、拖锚限位、潮汐伤害合法性及宿主 AI/射程提示均读取原有武器射程接口，没有另加只改画面的假范围。本轮核对了相关源码和实际超旧范围捕获/越界拒绝；没有重跑长局 AI 或宣称最终平衡。
