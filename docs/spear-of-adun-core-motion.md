# 亚顿之矛：中央环旋转恢复

2026-09-27。用户澄清“不会转”指舰体中央的环，不是前部炮。上轮关于修改炮的瞄准方式的回复属于误解，不作为修改授权；本轮不改炮的射界、绑定或旋转设定。

## 证据 → 差异 → 修正 → 验证

- 用户下载模型的 `scene.gltf` / `[Action Stash]` 含 `Ctrl_Core_Outter_1`、`Ctrl_Core_Inner_2` 两组真实旋转通道。作者为 Catholomew；不能把该下载模型的调整版动画称为暴雪未经修改的官方动作。
- 源采样覆盖 0–49.5 秒。Blender 导入场景为24fps、曲线末帧1188；本工程前部动作场景为60fps。合并时必须以秒对齐，不能直接复制帧号造成2.5倍速度。
- 两组骨骼沿舰体纵轴转动；内外环方向相反、速度不同。`Object_7` 虽权重名是 `Object8549_0`，该骨骼为外环控制骨的子级，因此也随外环运动，不能误判成固定舰体。
- 根因：前部动作脚本调用整个骨架的 `animation_data_clear()`，只重新制作了前部通道。整个演示的核心被固定在第0帧，这不是贴图方案不支持旋转，也不是模型没有动画。
- 修正：只复制源动画的8条核心四元数曲线，按24→60fps换算时间，保留前部的独立通道。保存后重开Blender，通过实际蒙皮顶点变化与世界旋转轴检查，不只检查关键帧存在。

## 源动作与新增部分的边界

0–49.5秒内的源关键帧数值不变。下载动作末尾尚差约3.36°外环转角才闭合；增加0.5秒回到物理等价初始姿态的尾段，形成50秒循环。这个闭合尾段是本工程的修正，不冒充源动作。四元数终点选择最近等价符号，避免穿过零四元数。

没有新造圆环，没有程序粒子，没有俯视平面旋转整张贴图，也没有改变模型几何。真实遮挡、阴影和反射由Blender在每个姿态渲染。

## 实装边界

当前没有修改 public 资源或旧v05运行版，没有宣称游戏已显示新环。本轮完成合并母版与真实运动审阅；运行还需要环的独立分层/局部覆盖与前部重叠区域处理，避免两份动画贴图覆盖同一像素，最终资源预算和战斗时钟（暂停/恢复）验收后再接新舰。

此处核心位于独特模型结构，属于Web改编资产制作，不对应远行星号原版舰船机械；不据此新增原版战斗规则。源许可署名保留，仍只进行本地制作，不发布。

## 本轮集中验证结果

- 8条通道共23,768个源关键帧分量逐个核对；数值不变，时间换算的浮点最大误差为0.000123帧以内。
- 保存重开后，四个核心网格都有实际顶点位移，固定舰体抽查不动；两根转轴经世界空间核对沿舰体纵向。
- 临时冻结核心导出前部时，核心矩阵变化为0，前部开合矩阵仍变化；隔离测试没有保存回母版。
- 144张真实姿态的可见像素全部不同。独立渲染循环终点，与起点合成后的RGB平均误差小于0.000018/255；几何回位误差小于0.00001模型单位。
- 已查看整舰/环部放大预览版式以及多个旋转姿态。没有游戏代码变更，未启动游戏或占用用户浏览器；不把离线结果当作运行验收。
