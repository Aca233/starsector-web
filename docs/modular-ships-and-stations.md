# 模块化舰船与空间站

## 已接入

- 13 种母舰舰体、15 套原版编组：攻势 Mk.I、低科/中线/高科三级空间站、余辉中枢完整/受损方案、废弃勘探母舰和模块测试舰。
- 离线导入解析 `STATION_MODULE` 挂点、`moduleAnchor` 和 `.variant` 的数组/对象模块映射；武器、幅能投入、已支持插件和联队使用各模块自己的原版装配。
- 舰船实体保留母子关系和稳定模块 ID；挂接位置使用“挂点减去旋转后的模块锚点”，再应用母舰世界变换。`INDEPENDENT_ROTATION` 模块保留自己的转向。
- 模块独立开火、选敌、防御、幅能、装甲/结构受击、死亡与联队运行；同一组装体不互相刚体推挤。模块碰撞将冲量施加到母舰，空间站不被推移。
- 空间站不平移，轴向自转；`vastbulk` 骨架免疫结构/引擎损伤；所有有效作战模块损失后核心和余下附件失效。作战模块按原版 OP、武器组、机库判据分类，装甲/装饰不延迟胜负。
- `shared_flux_sink` 按原版公式将损失作战模块耗散的 50% 按权重分配给存活作战模块，额外耗散的 20% 用于硬幅能。
- 模拟器/后备部署按母舰计费；附属模块不成为独立舰队成员，不重复报告战损。空间站后备部署进入战区内而不是停在地图边界外，拒绝撤退命令；机动母舰撤退/死亡会传递给模块。
- 联机快照传递模块状态和对象引用；挂点在接收端从静态配置重建，不从快照接受新的挂接定义。仅完成快照级验证，并未以两台真实设备开展网络实测。
- 改装主视图绘制完整模块舰体与装备。点击模块实体（按舰体多边形命中，透明区域不拦截）或模块清单，在整舰原位改装：只高亮选中部件并显示其挂点，右侧切换该部件的武器、武器组、幅能投资、插件、联队与独立预算。所有模块仍保持原来的位置和朝向，切换模块/母舰不会重置缩放、平移或重建舰体显示节点。支持只清空/恢复当前模块、整舰撤消；保存和模拟入口始终针对整舰。模块裸舰体不进入独立舰船列表。
- 方案只存发生改动的模块，以挂点 ID 为键，避免同型号模块互相覆盖。旧方案不带模块覆盖时保持原版装配；JSON、联机白名单、AI 配装判重保留递归模块配置。禁止非法挂点、替换舰体、错用原版子方案、过深编组与独立部署模块。

## 内容更新

`npm run import:content -- --modules-only` 只更新模块相关舰体、方案和状态；保留原有非模块舰体与武器记录，避免一次功能更新意外刷新其他历史导入。无参数依然执行完整内容导入。

`remnant_station1` 在当前原版安装中缺少独立模块方案，因此不虚构编组或将空核心放进可部署列表。

## 当前边界

这不是原版空间站系统的全量逐行移植：已提供模块级装备改装，但不能自由替换模块舰体、增删挂点或重新拼装结构。尚未完整复现所有脱离/残骸策略、舰长技能继承与未支持的特殊插件。切换整舰原版方案会采用该方案的模块配置，可撤消恢复先前改装。导入状态继续显示基础模拟/未适配原因，不声称全部原版特性等价。

## 找不到舰体时

- 改装左侧新增“空间站 · 11”和“模块化 · 13”快捷分类；点击时清除名称、势力过滤，避免旧筛选隐藏新舰体。
- 联机房间 → 添加 / 批量管理 AI → 选择舰船，提供“全部 / 空间站 / 模块化”快捷筛选。
- 模拟部署的舰级下拉框可选择“空间站 / 模块化舰体”，自动切回完整目录；“原版模拟预设”是较小的原版短名单，不代表全部可用内容。
- 搜索支持“空间站”“星堡”“模块化”“高科 空间站”等别名，高级站不再只匹配原始名称“作战基地”。
- 已导出的便携目录/ZIP 不会随着源码或 `dist` 更新。使用旧包时，需要重新打包；也可使用当前工作区的开发/预览页面。

- 同型号双模块只改一个，另一模块与原版模板保持不变；恢复当前模块可回到原版。AI 配装签名区分装备改动，忽略模块名称/时间。
- 拒绝未知挂点、错配舰体/原版子方案、独立模块部署、原型污染键、循环对象和超深传输方案。
- 改装后高科站运行 180 个战斗 tick，卸下的武器未生成；快照往返保留模块武器、修改后的耗散、母子引用与作战模块属性。未以两台真实设备实测。
- 浏览器实际点击空间站图形模块、打开武器挂点、安装武器、增加幅能、清空此模块、撤消、返回母舰并再次进入模块，改动保持；保存装配方案仍保存母舰及其模块覆盖。

- 模块武器提示卡定位到当前挂点侧边（不是整张模块图），挂点按下后捕获指针，避免提示卡在按下/松开之间遮挡并吞掉点击。

## 整舰原位改装（2026-09-18）

- 不再进入单模块画面：始终绘制整舰编组，点击模块或母舰轮廓切换当前编辑对象；选中模块以黄色边框高亮。模块清单仍可用于选择被遮挡或较小的附件。
- 武器挂点与射界使用完整模块路径、锚点偏移和累计旋转，重名挂点只操作当前模块。武器、插件、幅能、联队等仍按模块独立预算保存。
- 选中带机库模块也不挪动整舰视图；滚轮缩放（最高 4 倍）、Shift + 左键拖动或中键拖动平移、「重置视图」仅改变观察视角。选择其他部件保持当前视角。
- 整舰模式缩小挂点标记；模块装备悬浮信息不拦截鼠标，避免密集挂点被旁边武器的提示卡挡住；F2 仍打开可交互的武器详情。

验证：在 1200×800 与 940×560 的 4175 预览页面检查整舰显示节点、边界框及模块数量在切换前后不变；验证带机库模块切换、视角缩放/平移保持、清单自动收起、母舰轮廓选择、换装/撤消/保存。180°、60°、-60° 模块的挂点坐标和射界方向与组装变换一致；相同型号兄弟模块不会被误改，F2 详情可正常打开。类型检查、lint 与生产构建通过（Windows 输出目录占用时以 `--emptyOutDir false` 保留资产目录并更新产物）。

## 攻势装甲模块贴图 / 边界对齐（2026-09-18）

原因：原版 `.ship` 使用「前 / 左」局部坐标和逆时针角度，Web 引擎使用「前 / 右」和顺时针角度。此前直接使用原版横向坐标，左右装甲既挂到了相反一侧，边界也相对贴图镜像；对称母舰外形掩盖了这个问题。

- 在内置舰体和原版模块方案两个数据入口统一转换横向坐标及角度，包括碰撞边界、武器 / 系统挂点、引擎、护盾中心、模块挂点与锚点；递归处理完整组装体。
- 原始生成 JSON 继续保留原版坐标，不重新导入或改写历史舰体 / 装备数据。贴图、尺寸和像素 pivot 不动，没有攻势专用偏移。自定义 Web 规格和已编译方案不再次转换。
- 改装、模拟及 AI 战斗共用转换后的规格；仍在整舰上原位选择模块。

验证：263 个内置舰体校验通过；15 套原版模块方案（156 个模块）在原版加载、改装覆盖与 JSON 保存往返后几何一致，无重复镜像。左右装甲碰撞多边形内的可见贴图覆盖分别由约 19% / 20% 提高到 98.64% / 98.03%（原版碰撞轮廓并非逐像素描边）。攻势与低科站在四个母舰朝向下共检查 40 个姿态、981 个可见装甲点的战斗碰撞，推进 180 tick 正常。4175 生产预览实际鼠标点击两侧装甲均能原位选中且视图不动；低科站 6 模块及旋转部件显示正常。类型检查、lint、生产构建通过；构建日志见 `artifacts/onslaught-alignment-build.log`。
