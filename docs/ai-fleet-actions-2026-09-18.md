# AI 编成快捷操作（2026-09-18）

本次只调整 AI 编成界面与共享配装浮窗的可选操作，不改战斗 AI，不改后端编成协议。

## 少走几步
- A / B / C 等队伍改为可见页签，显示 AI 和真人数量；支持左右方向键、Home / End 切队。
- 添加数量常驻顶部，提供 1 / 5 / 10 艘快捷值。配装浮窗每一项提供明确的「添加 N 艘到 X 队」，无需选中后再回到底部添加。
- 点配装主体仍然只选配装、不改房间。直接添加成功后浮窗保持固定，可继续添加其他配装；底部原有添加入口保留。
- 已有编成精简为数量加减、改装、复用配装与更多操作。点缩略图查看配装。
- 「更多操作」中可整组复制 / 移动到其他队伍；只有两个队伍时直接提供对方队伍，三队以上需明确选择目标。
- 复制保留原队、沿用同一份已确认配装；移动才会移走原队。已有相同配装时合并数量，不把不同配置的同型舰合并。
- 「复用配装」仅选中方案，随后可切队、改数量、改装或添加；不会暗中复制舰船。
- 最后一艘点减号进入删除确认，不再给一个不能点击的减号。整组删除仍需确认。
- 改装返回恢复选中队伍、方案、添加数量、搜索与目录 / 编成列表的滚动位置。

## 保留的边界
- 所有修改仍走 LanAiSync 的房间、requestId 与编成 revision 校验；并发提交期间锁定按钮，不自动重试添加。
- 快捷添加按钮对错误配装 / 非法数量禁用；只读客机没有快捷添加按钮，数量及编成修改控件禁用。
- 个人战仍每艘独立成队，不提供移动到友军队伍的操作。
- 共享浮窗的新 action 是可选项；没有 action 的模拟部署与只读场景继续只选配装。
