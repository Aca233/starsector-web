## 1. 对象与采用原则

- 用户已确认对象：《星际争霸》的休伯利安号（Hyperion），不是其它作品的同名舰。
- 用户进一步明确：不是只能参考一张图。因此采用**多张图按部位/用途共同参考**，不要求选唯一主图、不设固定张数上限。
- 拟以 SC2 形象为主，具体版本与允许的改编范围仍待确认；不能混同普通战巡、特定旗舰和各模式能力。
- 前轮的大和炮、跃迁、航空和结构建议仍是 Web 设计草案，不是已验证的原作定案。

### 已证实的差异

- 两份模型共同呈现：较窄横向舰艏、长窄连接主干、后半段最宽横向肩区、左右双圆形结构、中央厚重动力段。
- 旧候选却将最宽体块放在前半段，把双侧大圆形结构改成中轴圆件，并把艉部改成顶视明显的一排五管。这是结构误读，不是仅需增加纹理。
- R02 尾部喷口具有上下层次，不能从侧上预览推定“水平并排五喷口”；具体发动机接口仍待几何定稿，不能把截图孔洞全部自动算喷口。
- 旧任务书“宽前肩”和对应分区挂点表冻结，历史提示词只保留追溯，不能继续复用。

### 精度和来源边界

- 两份参考均为 perspective/FOV 1°，视线偏离垂直约 1.15°，属于近顶视、低透视近似，**不是数学意义上的正交渲染**。官方公开 API 未查到正交切换；不冒充已验证支持。
- [记录文件](../artifacts/hyperion/model-views/capture-metadata.json)保存了相机位置、目标、真实输出尺寸、显示模式和来源。Matcap 渲染失败，未提供或宣称存在去材质几何截图；R03 本身是白模。
- R02 页面标示 CC Attribution-NonCommercial，上传者自述来自游戏并修改过材质/动画；这不证明原作资产的再分发许可。R03 是同人复原。所有截图仅本地参考，不加入舰船运行包。
- 本轮只取得、对照模型视角并修正文档；没有再生图、修改游戏代码或完成实装。
