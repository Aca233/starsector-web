# 四档二维武器制作与安装规范

2026-09-27。适用于玩家舰船包；本轮是既有字段的制作约定，不另起三维运行引擎或新配装规则。

> 2026-09-28生产规范补充：四档与现有字段保持不变；材质贴合、无占位、动态姿态/战损及机载武器对位，统一按[舰船生产手册v1.2的5.5–5.7节](ship-creation-production-playbook.md)执行，并填入[任务书17–19节](ship-creation-brief-template.md)。下文2026-09-27的样板验收是历史记录，不代表后续版本完成度。

## 原版证据 → Web约定 → 验证

- 本机原版0.98a-RC8 `starsector-core/data/weapons/hellbore.wpn`：turret/hardpoint贴图和枪口offset分别定义；`tpc.wpn`：hardpointSprite为空、另有glow/offset。固定外壳可以属于舰体，不意味着没有武器，也不能重复叠一套底座。
- 原版WeaponAPI只有S/M/L；本项目 `src/engine/content/WeaponSizes.ts` 已有S/M/L/XL四档，XL为Web扩展。`weaponFitsSlotSize()`严格相等，不能把原版下装习惯重新引入。
- `WeaponInstallation.ts` 已有舰体侧固定承座及可选固定前景；`WeaponArtCalibration` 已有武器显示尺寸/归一化枢轴。`weaponArtLayout()` 对旧图保留原尺寸/居中默认；不要求3D源文件。
- 当前差异：此前v06固定点校验器把开放候选档位写死成三档，尽管运行系统已有四档。本轮允许四档，XL当前开放候选数仍为0，不能借修校验器偷增炮位。
- 验证：既有亚顿之矛检查脚本覆盖四档、16对同档矩阵、2D默认/显式尺寸枢轴，以及局部XL候选夹具。真实XL安装另按模型几何、源骨骼和保存重开检查；不是实战验收。

## 唯一尺寸规则

| 显示 | 序列化值 | 换装 |
| --- | --- | --- |
| I / S / 小型 | SMALL | 只接受SMALL |
| II / M / 中型 | MEDIUM | 只接受MEDIUM |
| III / L / 大型 | LARGE | 只接受LARGE |
| IV / XL / 超大型 | EXTRA_LARGE | 只接受EXTRA_LARGE |

武器类型、内置身份、炮头运动、尺寸是四个独立维度。XL可以是可换炮塔，也可以是内置固定炮；不能把“内置”当作第四档。安装尺寸按实物标定，**不能把24/42/68/96的回退值当作四档必须画成的像素大小**。不按档位推导伤害/射程/OP。

## 玩家最低制作门槛：二维图片＋标定

不论手绘、生成、原有贴图还是模型烘焙，都使用相同的运行字段：

1. 透明武器PNG/WebP，准确的显示宽高和旋转枢轴（`spriteWidth/Height/PivotX/PivotY`）；默认单张贴图。只有真正形变才需要动画。
2. 舰体槽位的稳定ID、四档尺寸、类别、局部位置、朝向、可动射界和必要的内置绑定。固定座用已有 `installation`，没有独立承座就不虚构一张空图。
3. 炮口相对炮头的位置及实际出射方向。不能用图像中心/骨骼中心代替枪口。
4. 以空座、朝中、两侧极限、实际战斗缩放验收；至少换装另一件同档2D武器。**当前新v06尚未完成最后一项，不能宣称四档任意换装美术已通过。**

3D母版、骨架、UV和源模型许可证仅是采用3D制作路线时的工作文件，不是普通2D武器必须上传的文件。可发布包需要最终贴图、运行配置、依赖闭包和合法来源；本轮没有生成发布包。

## 避免“贴在船上”的三条规则

- 固定承座跟舰体，不跟炮头转；炮头与枪口共享同一运动变换。已发射弹体进入世界坐标，不继续拴在舰船上。
- 已画好完整转动座的旧武器，舰体侧只做安装接缝/适配边，不能叠第二个巨大炮盘。只有确实被固定装甲遮住时才制作前景。
- 模型烘焙素材也不默认导出96角度。常规炮塔优先单图；方向性光影严重不一致时，再选有限方向帧或重做适合旋转的光照。不能以方向帧替代碰撞/射界验收。

## 亚顿之矛本轮四档样板

- S/M/L：三处固定骨骼上的独立炮头，是真实部件重组和新增几何；仍为离线样板，未量产到12个候选位置。
- XL：前部原生12段护臂＋固定主干上的单轴发射光学件，整体一套EXTRA_LARGE内置专武候选。护臂开合不带着枪口乱偏，也不复制一座大型转盘压在舰体上。属于Web改编，不声称原作炮型/炮数。
- 环上仍无常规武器。XL档存在不意味着必须在环上或旧版XL01/XL02上补炮。
- 旧v05的26槽、四档武器、默认配装和存档没有改变。新样板的美术认可、最终射界/火力预算、运行坐标转换和完整v06接入仍待完成。
