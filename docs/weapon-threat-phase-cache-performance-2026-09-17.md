# 武器威胁阶段缓存复核（2026-09-17）

## 结论

保留本轮“原生 AI 阶段内复用敌舰武器参数”的候选。常规百舰完整工作耗时在两轮配对测量中分别减少 **7.7% / 10.4%**，P95 同向改善；密集百舰布局仅减少 **1.9%**，不能宣称密集混战已经明显变流畅，更没有达到百舰 180 FPS。

本轮基线包含此前已保留的弹丸威胁 BVH。没有回退既有优化，没有重新引入此前撤回的渲染实验，也没有降低画质、特效数量、AI/物理频率或威胁预测时长。

## 从无效尝试到保留方案

最初只缓存敌舰的整体最大射程/炮口包络和最大速度，百舰完整均值 140.281 → 138.762 ms（约 1.1%），P95 169.5 → 174.3 ms，收益不足。远射程武器使整舰包络过宽，该版本已被替代，不能用它的证据代表最终版本。

最终版本在同一阶段额外复用符合条件的挂载引用、射程、DPS、与旋转无关的炮口最大偏移和运动属性。使用保序的平行数组，避免每个挂载分配一个记录对象。保守整舰包络只排除原先每挂载边界也必然排除的敌舰；仍有可能构成威胁的武器继续执行原有炮口、转向、装填、接近、弹道时间和伤害累计计算。

## 生命周期和行为边界

- 缓存只在已核查的原生 AI 阶段存在，不跨帧，不加入引擎序列化状态。
- 原生引擎和 AI 入口身份、舰船伤害读取路径、主/辅助系统和舰体射程插件均通过检查后才启用；少于四个阶段 AI 不创建缓存。弹丸 BVH 仍另有 128 枚阈值。
- 每艘舰船执行 AI 后立即使自己的缓存失效；后续观察舰能看到刚刚启用的射程/机动系统状态。
- ECM 在阶段开始之前更新；命令推进、舰船/武器模拟、系统事件分发位于阶段结束之后。无论正常返回还是抛出异常，`finally` 都关闭两个缓存。
- 核查了原生 AI、防御/导航辅助和系统 AI：该阶段对缓存相关状态的修改限于当前执行 AI 的舰船。`yieldFireLane` 只读取友军并构造自身速度；航母系统在此只选择/激活自身系统；瞬移、装填及影响其他实体的系统事件通过后续 `dispatchEvents` 执行。今后新增原生系统若改变此约定，必须重新核查或禁用快路径。
- 非有限/负预测窗口、自定义相关钩子和关闭后的缓存回退；异常边界值不作为排除依据。
- 回退保留原 `for...of` 对数组引用及实时长度的行为，不改为缓存长度的循环。任意 JavaScript 方法/accessor 猴子补丁不在全面纯函数认证范围内，不能宣称所有运行时篡改都已覆盖。

## 配对完整负载测量

Chromium / ANGLE D3D11，NVIDIA GeForce RTX 5060，2560×1440，DPR 1。相同种子 `0x51180`，各 360 个固定 1/60 秒模拟步，前 60 步预热、后 300 步统计。两个隔离生产构建页面逐步交替先后顺序；复测翻转交替顺序。未与构建、剖析或重型验证并行。

密集布局将水平间距由 3200/1500 缩为 1000/500、纵向由 850 缩为 650，并调整相机保持同屏。只做了一轮密集配对测量，其小幅收益不作稳定保证；不同布局、不同轮次报告的绝对耗时不能拼接计算累计加速。所有七组配对的最终引擎状态哈希匹配，存活舰数一致，页面和 WebGL 错误为零。

**上述是脚本化工作耗时，不是实际 requestAnimationFrame 或显示器 FPS。** 180 Hz 展示预算为 5.56 ms，60 Hz 固定模拟预算为 16.67 ms；当前百舰两个主要部分仍远超各自预算。因此这次可重复的局部改善，不会使最拥挤场景产生体验上的质变。

## 正确性与实际执行验证

- 3200 组随机/异常参数场景，每组比较首次缓存、修改后失效及关闭回退，合计 **9600 次完整威胁评估精确对照**。涵盖正常/极小/极大坐标、NaN/±Infinity、异常窗口、禁用/无弹挂载、可变射程/炮口、光束、DPS 异常和系统/ECM/运动参数变化；3200 次缓存身份检查。
- 百舰 240 步完整模拟，8 个全状态检查点一致（只排除墙钟 `kernelMs`）。实际缓存查询 1,188,000 次，命中 1,140,720 次，未命中 47,280 次；失效 23,760 次，关闭 240 次。
- 4 类非原生阶段回退检查通过；注入查询异常后，武器缓存和弹丸索引都被关闭。
- 另三种十舰组合各 180 步，共 18 个全状态检查点：替换为原生 Lidar 系统的 Onslaught、Onslaught/Paragon、Doom/Harbinger。失效诊断看到 4320 个已有缓存项、8 次阶段内实际射程增加；**没有观察到阶段内速度变化**，不将此诊断当作实际速度激活覆盖。
- 自定义目标伤害回调修改敌方射程/位置，14 次回调下与基线结果一致。
- 自定义伤害回调在武器遍历期间追加、替换、截短武器数组，三种回退精确一致；追加武器确实被处理，替换数组未改变已经开始的原数组迭代。
- `npm run typecheck`、`npm run lint`、`npm run build` 通过，既有大 chunk 提示仍存在。当前 `dist/` 已重新构建。
- 当前构建十舰浏览器冒烟、WebGL 上下文丢失/恢复、资源重建和释放通过，无页面/GL 错误。当前全部冻结源码与最终候选一致。
