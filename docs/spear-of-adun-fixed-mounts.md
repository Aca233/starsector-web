# 亚顿之矛 v06：固定武器安装与旋转环分离

2026-09-27。用户认可：旋转环不装通用炮，常规武器只装固定结构，原生前部机构独立作为内置专武。本轮完成的是安装布局、模型绑定和制作期校验，不是换装了新炮的战斗舰。

## 最小证据对照

- 原版0.98a-RC8：`starsector-core/data/hulls/onslaught.ship:105–107` 用 `builtInWeapons` 绑定两门TPC；`data/weapons/tpc.wpn` 的 `hardpointSprite:""` 与独立glow/offset说明炮身可属于舰体。它只为内置身份和图层分工提供参照，不证明亚顿之矛的炮位或活动环结构。
- 当前宿主：`ShipSpec.ts` 的 x/y、`WeaponInstallation.ts:installationPose()` 都按固定舰体局部坐标变换；没有支持沿纵轴翻转、逐帧改变遮挡的环上炮座。不能直接沿用静态26槽来覆盖新图。
- 源模型证据：依据实际有效骨骼权重及完整父链分类，而非对象名或画面上的圆洞。40个固定网格、4个旋转核心网格、12个拆分后的前部控制段。原始前部是1个网格；12段不是12个武器。
- 容易漏判的例子：`Object_7` 的权重名为 `Object8549_0`，父级实际是外环 `Ctrl_Core_Outter_1`，必须归为旋转核心；固定晶体/隐藏在环内的结构即便属于固定骨骼，也不自动成为可装炮的表面。
- 本轮预期：开放候选点必须由固定骨骼支撑；环转动和前部开合不能让承座悬空或被运动件覆盖。武器射界、炮管/炮口的几何净空另验，不用视觉可见性代替可开火判断。

## 已执行的检查与修改

1. 对实际可见网格建立三角形BVH，按正交相机向模型发射探测射线，记录真实支撑表面、骨骼祖先、模型坐标和表面法线。
2. 初稿两个尾部候选点在镂空处，中心射线未命中。已从 `[233,869]` / `[279,869]` 移到 `[220,828]` / `[292,828]` 的实体装甲，未通过增画假甲板掩盖问题。
3. 72个环周期姿态 × 前部闭合/展开，共144个组合。每个承座按中心及两圈共33个点采样；当前12个位置全部落在固定结构，命中位置不随环漂移。
4. **这只是离散采样支撑检查**，不等于连续体积碰撞证明、不等于整个炮身安装验收，也未验证炮管扫掠、炮口射线、最终射界。
5. 在新Blender母版里按固定/旋转/原生机构分集合，将12个非渲染作者标记绑定到对应固定骨骼；标记不是替代武器素材。保存重开后核对绑定及多个姿态：最大模型坐标漂移小于0.0000005，投影误差小于0.000046像素。
6. 制作期校验器拒绝：环上开放座、伪装成固定面但来源为Object_7的承座、活动骨骼祖先、改位置后沿用过期证据、重复ID、采样未通过、给尚未完成的专武填写占位ID。

## 四档安装样板补充（2026-09-27）

安装系统是S/M/L/XL四档，不是三档。已做的三处开放安装样板为S/M/L；新增XL离线样板采用原生前部护臂与固定光学主干。档位与是否内置、是否转动分别定义，普通2D武器不要求3D制作。

S/M/L实物含贴合斜面的固定座、独立炮头和实际光学口；共1180个离散姿态检查通过。首轮舰首小炮向内的发射线会击中舰首装甲，现有样板测试区间改为朝外的-115°至-15°，不是给所有小炮统一指定此射界。XL在54个姿态中核对源护臂开合/核心转动、炮头与舰体交叠及出射线，并保存重开核对固定骨骼绑定。检查不等于连续碰撞证明。

离线四档摘要见 `spear-of-adun-four-tier-fit-v06.json`，统一二维制作约定见 `weapon-art-four-tier-workflow.md`。S/M/L空座及转向对照在 `output/spear-of-adun-art/weapon-fit-v01/`；XL及四档合并母版在 `output/spear-of-adun-art/xl-fit-v01/`。没有复制到public、没有新运行武器ID、未改变v05。

旧布局和支撑证据保留为原始候选阶段快照，其中前部“枪口未定”表示当时的状态；新XL光学口的独立证据在四档样板摘要。最终美术认可、第二件同档二维武器换装实测、射界/预算和完整新舰接入仍未完成。
