# Starsector Web v0.2.4

## 本次更新

- Steam / 局域网共用联机性能日志：每秒记录房主、relay、客机的快照速率、耗时、队列与背压，并记录断线/重连/房间关闭等事件。
- 桌面端自动异步写入 network-performance.jsonl，通过「帮助 → 打开联机性能日志」查看；限制文件大小并保留一份轮换记录。
- 战斗 Esc 菜单、诊断面板、房间侧栏和联机入口均可一键导出最近约 10 分钟的本页面诊断记录，断线后仍可导出。不会记录密码、令牌、昵称、IP、SteamID 或世界快照。
- 恢复悬停资料卡的真实锁定进度条；计时期间也能移入阅读，修正鼠标穿透、跨窗口间隙误关闭，以及进度完成后窗口不收起的问题。
- 联机 AI 舰船选择和舰队增援选择统一使用修复后的悬停行为，保留点击/键盘立即打开。

## 使用提示

定位 10–20 Hz 问题时，请房主和低 Hz 客机在同一场高负载对局中各导出一份日志。报告年龄不是网络 RTT；还原 Hz 不是渲染 FPS；此更新增加可追踪诊断，不宣称已经解决所有高负载联机延迟。

联机双方请使用同一发布版本。浏览器内存日志会在刷新/关闭页面后清空；桌面自动写盘日志会保留。

## 发布范围

本次提交当前非生涯改动。**不包含未完成的生涯模式**：生涯源码、服务、入口、构建入口配置、测试/导入/启动脚本、文档以及生涯工作中的共享字体拆分，均留在本地未提交。
