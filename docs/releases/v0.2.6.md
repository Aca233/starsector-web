# Starsector Web v0.2.6

## 更新内容
- LAN / n2n / Steam 联机链路优化：共享快照格式、无损差分和 motion-reference 支持，Steam 二进制桥接及后台快照准备，保留接收确认、限量排队与完整性校验。
- 多人中转共享相同快照及压缩结果，减少重复计算；固定录制测试中，LAN / Steam 差分传输量进一步减少约 6%（不是所有战斗或网络环境的保证）。
- 主机快照捕获与二进制编解码优化，减少重复遍历、类型判断和数组回调；不降低物理步进、数值精度或用重复帧冒充接收 Hz。
- 完善整次游戏会话的网络日志、n2n / Steam / LAN 诊断、实际生成/发送/接收/应用频率及拥塞指标。
- 包含本次待发布的非生涯模式改动，包括服务端权威支持、相关战斗工具和验证脚本。未完成的生涯模式代码、入口及其专用新增字体不在此发布中。

## 已知限制（请务必阅读）
- **尚未实现大规模战斗下稳定的客机 60Hz。** 不限速本机测试仍可能受主机模拟、捕获和编码的 CPU 预算限制；32 艘船测试存在过载/失同步案例。本版不承诺消除所有延迟、掉线或过载。
- 既有 Steam 压测记录中仍有三个未解决的压力场景：旧传输九人共享链路从 8Mbps 降至 256Kbps；实验性 Sockets 长时拥塞/停顿恢复吞吐；实验性 Sockets 九人健康链路吞吐。实验性 Sockets 并非默认传输。本版不将这些场景标记为已修复。
- 局部编解码、无头浏览器及理想带宽模型测试，不等于真实多账号 Steam / 双机 n2n / 公网稳定性验证。发布工作流保留全部检查结果；如 Steam 检查失败，自动流程仅生成草稿，须核对后再人工发布。
