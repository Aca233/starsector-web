# 单舰包宿主 ABI 1

## 本轮边界与依据

这是 Web 扩展的内容组合与安装工作。原版参考沿用现有荣光女王、罗西南特来源记录；不改原版规则或 UI，不改变本舰数值、美术、ID、槽位、用户旧配装。原版实机没有启动。本轮只做单舰包接入，生涯模式及发布不在范围。

编码前对照：当前 ModManager 拼接舰船/军械，DesignModel 拼接改装元数据，BundledHullTemplates 重列舰体，ExtensionVariantCatalog 用舰体分支连接配装。目标是包描述提供这些数据，宿主从一个目录读取；包先预检后持久保存，刷新启动时完整激活。验证要涵盖隔离宿主、真实页面安装、改装保存及 Worker 模拟。

## 已实现接口

- `ShipPack`：稳定包 ID/版本、主舰、舰体/军械、基础舰体、改装/航空目录、配装、素材所有权、来源及可信行为 ABI。
- `BundledShipPacks`：唯一内置包列表。荣光女王与罗西南特配装已经迁入各自描述；其余舰船的专用配装工厂仍是兼容路径，不能声称全部舰船已完成可安装交付。
- `.ship-pack`：gzip 压缩的 JSON，包含规格及素材字节；不解压文件系统路径、不执行包内 JS/TS。声明公共宿主素材；包内自有目录资源必须实带，逐文件校验 SHA-256、数量、大小和类型。
- 启动：读取 IndexedDB 的安装配置，验证和挂载全部启用文件，通过后才导入 App。安装过程不原地替换战斗或用户方案。
- 操作：指挥中心 → 游戏设置 → 舰船包 → 安装/启停/卸载 → 应用并刷新。错误预检不写安装配置；保存采用 revision CAS 防止旧页面覆盖。
- 启停和卸载检查方案、草稿、备份、舰队和中场点引用。升级保留旧数据、要求稳定 ID/槽位兼容；未提供跨结构迁移时明确拒绝。
- Worker：随权威内容快照传送相同包目录与配装，重新建立改装/模拟目录，内容指纹包含包元数据。协议升为 16。

## 兼容声明

`ship-pack-host-1` 是本轮代码提供的宿主能力。`gloriana-1` 与 `rocinante-1` 行为已编译在兼容宿主内；安装文件不能向旧宿主追加任意新技能源码。新机制先增加受审的宿主行为能力，然后包声明对应能力。包无需另一艘船；公共物理、渲染、声音和原版公共装备由宿主提供并声明依赖。

本轮可安装文件针对浏览器本地设计/模拟与实际 LocalWorkerHost。自选内容暂阻止进入 LAN/Steam，直链同样阻止；多人包协商和权威宿主安装尚未完成，不承诺联机。默认内置内容的联机路径保留。

私有生成命令：`node scripts/package-ship-pack.mjs gloriana`、`node scripts/package-ship-pack.mjs rocinante`。产物在 artifacts/ship-packs；不提交、推送或公开发布。包包含已有来源记录的主题资产，生成文件不作新的分发许可声明。

## 本轮验收

- 类型检查、改动文件 lint 与生产构建通过。构建保留现有大 chunk 和背景路径提示；未作启动性能改善声明。
- 两份独立安装文件已生成：荣光女王包含 12 个舰体实体（核心、8 模块、3 飞机）、9 种武器、21 份自有素材；罗西南特包含 1 舰体、4 武器、7 份自有素材。分别声明 27/18 个公共宿主素材路径；素材字节和 SHA-256 在对应 inventory 中。
- 独立无头浏览器分别停用所有内置包，只安装一个文件，经真实设置页→改装→Ctrl+S 保存→页面刷新→模拟器→真实 LocalWorkerHost。目录只有该主舰；保存数据读回一致。荣光女王恢复 8 模块/14 架默认飞机，罗西南特保留 9 个武器挂点。
- 缺失包内素材被拒绝，安装 revision 与记录不变；重复安装被拒绝；方案引用阻止停用；结构兼容升级至 1.0.1 保留 localStorage 保存内容的原始字节。测试的升级文件仅用于隔离验收，交付版本为 1.0.0。
- 生产 WebP 构建的真实页面独立安装荣光女王，57 个改装图层从包内 Blob 加载；保存刷新一致；真实 Worker 启动战列敕令，回执 accepted，65 次步进后 ACTIVE/effect=1，8 模块/14 飞机正确，pageErrors 和失败素材请求均为空。
- 复用既有 `only Gloriana hull/weapon records suffice` 场景通过。原检查脚本的 esbuild raw JSON 入口缺少 loader，验收时在临时产物中补 loader；未修改检查源文件。该脚本未筛选的旧断言要求默认 230OP，而当前已有默认为军械 260OP，因此不能报告整个旧检查集通过，也没有改期望值制造成功。
- 证据：`artifacts/ship-packs/installation-verification.json`、`production-verification.json` 与对应截图。检查使用隔离无头浏览器，没有读写玩家浏览器配置或操作桌面，没有公开发布。
