## 试玩与操作

在设计页搜索“万有引力”，应用“潮汐攻坚”或“引力控场”，进入模拟器部署。左键主控为第 1 武器组的内置潮汐投射器；以下为默认绑定，技能快捷键可沿用宿主绑定设置。

| 输入 | 当前真实行为 | 关键限制 |
| --- | --- | --- |
| 按住左键 | 捕获一个合法实体，移动鼠标拖动真实锚点；松开释放，保留实际动量 | 原捕获、质量响应、距离、遮挡、费用与 5 秒保持上限不变 |
| 点按右键 | 切换唯一的吸引/排斥极性；同时影响单体操纵及本舰唯一 F 场 | 不松抓、不消耗场、不产生额外波；起始为吸引 |
| 按住 F | 建立/接管唯一的区域场，以有限速度追随指针 | 中心移动上限 650 世界单位/秒；半径 650，部署/维持距离 1700 |
| 松开 F | 场停在最后真实位置短暂驻留；再次按住接管同一实例 | 松开后最多 3 秒，且不超过原 7 秒有效期；接管不重付启动费、不刷新实例或总寿命 |
| 点按 G | 独立的本舰全向紧急排斥，始终向外；成功松抓但保留 F | 不要求先有 F；失败不松抓或删场；最大半径 1050，2800 启动幅能、8 秒冷却 |

右键极性切换使用 0.05 秒激活 / 0.12 秒冷却，仍受系统离线、排散、过载等宿主限制，不是无条件切换的作弊输入。F 建立 0.25 秒、有效期 7 秒、启动幅能 900、ACTIVE 维持幅能 250/秒、冷却 8 秒。驻留也照常消耗有效期和维持费用。

### 同一鼠标的仲裁

- 合法 F 正在按住操纵时，鼠标优先控制区域场，不再发起新的单体捕获。
- 若此前已按住左键抓住对象，单体锚点停在最后实际位置，但真实受力、保持时间及费用继续推进。
- 松 F 后恢复单体锚点的有限速拖动，不会瞬移到鼠标；松左键则立即释放既有对象。
- 无效/冷却中的 F 不抢占单体控制。失焦、指针离开战斗画布、暂停/界面阻塞及自动驾驶切换清除持续输入；死亡、撤退、过载、排散、离线沿用中断清理。

### 力、对象及反馈

- 排斥只反转位置施力项，不反转稳定阻尼；全场与单体仍共享原有对象级外力限幅。
- F 不新增范围伤害，不接管敌弹阵营，不补充弹体寿命/伤害，不无条件影响普通友舰或任意友弹。原有本舰质量校准弹的受场上限保持。
- 左键原有敌舰潮汐伤害 1200 能量/秒保留为这轮输入改动的试验基线，不能据此宣称已完成“辅助舰”最终数值平衡。
- HUD 显示目标类别、极性、操纵/驻留及剩余时间；真实锚点/场中心小十字不依赖场景特效开关。场粒子与折射方向来自权威状态。
- AI 的 F 仍是自主部署场。紧急 G 按舰体表面间距、撤离/幅能状态或逼近的受支持弹幕触发，不为了远距对射测试强行乱放。

## 旧配装与运行链路

`GravityControls.ts` 将默认系统设为 F 区域操纵 / G 紧急排斥 / 右键极性反转。`DesignModel.ts` 只在编译出的运行规格上迁移万有引力号旧默认组合 `[WEB_GRAVITY_BATTLE_WELL, WEB_GRAVITY_COLLAPSE]` 加旧右键 `WEB_GRAVITY_BATTLE_REPULSOR`；不重写存档武器，不覆盖自定义右键选择或其他舰型。旧系统 ID 保留用于明确的历史组合及回归场景。

本地控制样本和 LAN 控制加入逻辑 `GravityField` 按住位，独立于 F 或鼠标侧键重绑定；网络使用新增 bit 8（256），对应输入掩码验证扩到 511。LAN 权威端在离散技能命令之后应用同 tick 的按住状态，过期/无指针输入不会遗留操纵。极性、按住及场实例状态进入本地投影和实际 LAN 快照/显示恢复。

这些链路检查不等于完成真人联机、所有运输层端到端或多核预测支持。沿用宿主现有支持/回退边界。
