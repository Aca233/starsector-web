# 本地联机重快照卡顿：第一轮定位与修复

## 现象与原因

用户截图为 127.0.0.1:3001 的守护者舰队交火，顶部约 3 ms RTT，并显示“主机正常”。旧提示只检查 Worker 内的物理步耗时，不覆盖快照复制、编码/解析、还原或画面帧率，因此不能用它判定整个联机客户端流畅。

隔离场景使用 8 艘守护者，保留原有配装/模拟/特效。进入交火后采到 1,212,112 字节的完整快照：world 约 801 KB（弹丸约 311 KB、连续尾迹约 309 KB、FX 约 155 KB），ships 约 411 KB。不是在进行资源文件大小审计，这些是运行中的网络消息数据。完整状态仍会按自适应频率重复发送；低 RTT 不会消除 CPU 编解码成本。

该场景阶段采样中模拟约 3.33 ms/步、GPU 约 2.73 ms，而对象图复制、重复 JSON 编码、解析与还原在重快照抵达时会叠加阻塞前台。此结果是独立复现，不是对用户当时那一局的直接采样。

## 本轮改动

- host.worker：在 Worker 中只编码一次 JSON，并提供真实 UTF-8 字节数。向前台传字符串而不是整个深层对象图；同一份 JSON 直接用于网络发送。编码成本纳入自适应预算，诊断单独显示。
- Worker 至多保留一份等待前台确认的普通快照；前台忙时不无限积压旧对象。确认后采集最新状态。最终结算帧允许优先发送，物理步长和结算权威不变。
- LanBattle / LanConnection：移除房主为了统计体积和发送网络而再次编码世界的重复工作；客机也不再为了显示大小重新 stringify。仍校验完整报文的 16 MiB 字节预算。
- applyCombatSnapshot：复用显示端 Vector2、兼容的 typed array、数组和 Map/Set；删除消失的条目。缓存一份 activeShips，避免对每艘船重复构建列表。保留 Ship/组件原型、静态规格及禁止字段检查。
- LAN server：真正有可接收的目标时才编码广播。只有房主和 AI 的练习场不再为了无人接收的广播额外 stringify 世界。
- UI：顶部显示真实画面 FPS，把“主机正常”改成明确的“模拟正常”。菜单 → 操纵与联机说明 → 性能与网络诊断显示帧间隔、绘制提交、GPU、快照采集/编码/解析/还原，避免把网络延迟当作总性能。

## 验证

没有创建测试文件或测试运行器，使用临时 stdin / 浏览器脚本。

1. 同一份 1.21 MB 交火快照、90 次处理微基准：
   - 旧前台路径平均 25.23 ms，P95 32.8 ms。
   - 新前台路径平均 7.10 ms，P95 10.4 ms。
   - 单独还原平均 4.18 → 3.76 ms。
   - 此微基准模拟复制与编码成本，不等于整场 FPS 提升倍数；编码工作仍需在 Worker 完成。
2. 新旧还原器输出的 ships/world 一致；原始静态舰船规格未被修改。
3. Unicode 报文往返一致、超限报文拒绝、拥塞跳帧通过。Worker 故意不确认 350 ms 时只交付 1 帧；确认后下一帧已推进至 tick 21，字节数与 JSON 内容一致。
4. 同机两个独立 Edge 客户端，D3D11 / RTX 5060、各 1600×1000，真实本机 WebSocket，双方守护者加 6 艘 AI：建房、应用配装、开战、tick > 1200、客机刷新重连通过；只房主创建战斗 Worker，无未捕获页面错误。观察时约 79–96 FPS，样本最大快照 1,597,559 字节。不是旧版与新版整场 FPS 的受控对照。
5. 类型检查、lint、隔离生产构建、服务端语法及 diff 空白检查通过；Vite 保留既有大分块提醒。

## 尚未解决

这不是完整的带宽/快照优化。重场景的快照仍可能超过 1 MB；实测同步频率曾降至约 5 Hz，因此即使画面 FPS 高，状态更新、输入确认及部分特效运动仍会受影响。仍需继续收紧仅供显示的投影、处理大量尾迹/粒子历史，并进一步改进呈现插值；不能承诺百舰稳定流畅，不能把本轮结果当作真实 Steam 跨网性能验收。

## 本地预览

为避免打断用户正在运行的 3001，对现有 dist 和进程不做替换。隔离产物位于 artifacts/lan-performance-preview；本地预览地址为 http://127.0.0.1:3004/?view=lan，后台只监听 127.0.0.1，仅供同机对照。

源码已更新；原 3001 页面不会自动获得这次优化。需要结束当前对局，再重新构建和重启对应的联机后台才能把修复用到原入口。


第二轮针对用户在 3004 的“高 FPS 但像慢动作”反馈，见 [连续呈现时间轴与主机预算](lan-motion-2026-09-17.md)。新预览另开 3005；保留 3004 基准和当前对局。
